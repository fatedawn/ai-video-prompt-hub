# 未来主义动漫空战

*Futuristic Anime Aerial Combat*

> 一段高质量的剧场版动漫动作提示词，讲述了一名赛博格与一个机器人伙伴在沿海空中城市展开快节奏战斗的故事。

## 提示词（日本語）

```text
1:1 スクエア、15 秒、劇場版アニメ品質のハイスピードアクション。舞台は晴れた午後の近未来的な沿岸空中都市。青空、海、巨大な白いデッキ、ガラス張りの廊下の外壁、空中交通路、連絡橋、ターミナルの屋上、ビル間の 3D 構造物、展望デッキの間を高速で切り替える。閉鎖空間や、同じ場所での単調な戦闘は避けること。

[参照画像] [image_name] を使用し、サイボーグの女性 1 名とパートナーロボット 1 体の外見を固定すること。女性は上半身、ロボットは全身を優先し、顔、頭部、腕の武器、背中、脚部のパーツは補足的に扱う。アウトライン、白背景、見出し、複数の視点、表情、顔・脚・武器の詳細などを、導入カットや構成として再現しないこと。最初から完成されたアニメの世界観で 2 体を動かす。女性とロボットは同じ戦いの味方だが、前半から中盤までは独立して行動し、最後のみ同じ大型の敵に集結する。顔、髪型、体型、アーマー、武器、背中の構造、配色を維持すること。衣装・アーマー・ユニットの変更、変形、合体、巨大化、複製、色替えは禁止。敵は黒鉛色の非人型小型ドローンと、最後に登場する大型の黒鉛色無人航空機。背景の空中交通は民間機であり、戦闘には参加しない。

[画角と動き] ワイドからウルトラワイドを基準とする。1:1 でも窮屈さを感じさせないよう、空、海、都市、建築物、余白を残すこと。クローズアップは一瞬のみ使用する。動きはフォトリアルな滑らかさではなく、「強い構え → 短い溜め → 画面遮蔽 → 別の地点での強いポーズ → 接触 → 短いヒットストップ → 大きなリアクション」という連鎖で表現する。長距離の走行や飛行は避け、弧を描く動き、斜めの交差、急反転、高低差、X 字、S 字、ビル間の跳躍を用いる。カメラも大胆な斜めへのダイブ、急上昇、交差、ビル間の隙間、素早い反転を活用する。

[エフェクト] エフェクトに青い光の線、ビーム、レーザー、オーロラは使用しない。@image1 のメインカラーとアクセントカラーを、明瞭な輪郭を持つ不透明な色面として使用し、太いストロークマーク、長く伸びる尾のような糸、飛び散るカラーチップ、斜めのカラーブロックで表現する。すべての動き、出現、衝撃には、引きずった絵の具のような疾走感のあるエフェクトを伴わせること。

[構成] 0.0-1.5 秒：沿岸都市のウルトラワイドビュー。複数の方向からドローンが侵入。廊下の壁から女性、下層デッキからロボットが別々に展開。ロボットが弧を描いて一撃をパリィし、都市に衝撃波が走る。1.5-3.3 秒：女性パート。色面が前景を覆い、廊下、通路、屋上を切り替える。構え、斬撃、着地リアクションのキーポーズのみを、強い糸のエフェクトと共に示す。3.3-5.1 秒：ロボットパート。デッキの端や橋を利用した三日月状の軌道と、ドローンを吹き飛ばす重い一撃。5.1-6.9 秒：女性パート。ビル間の垂直空間。遮蔽物の後、異なる角度から瞬時に現れ、高さを変えて連続攻撃を行う。6.9-8.7 秒：ロボットパート。高い構造物を利用した壁面反転と、ドローンを突き抜けるダイブ。8.7-10.2 秒：大型 UAV が進入。ターミナルに巨大な影が差す。女性とロボットが異なる方向から飛び込み、敵に集結する。10.2-12.2 秒：ハイスピードコンボのクライマックス。ロボットが弧を描いて装甲を破壊し、視点が切り替わって上空から現れた女性が弱点を斬り裂く。長い組み合いはなし。12.2-15.0 秒：大型ユニットが爆発。火の玉ではなく、不透明な色面と鋭い破片として表現。カメラは瓦礫を抜けて展望デッキへ。2 体は異なるタイミングで着地し、再び加速して去っていく。都市は祝祭の煙と機能回復で反応する。最後は都市の全景と、遠くまで続く軌跡で締めくくる。

[オーディオと禁止事項] 高密度な劇場版アニメ風の BGM。衝撃、斬撃、破壊には強いダイナミクスをつける。安っぽいテレビアニメ風の音、一定速度の動き、長いスローモーション、UI、字幕、武器の合体は避けること。
```

[参考图像] 仅使用 [image_name] 来固定一名赛博格女性和一个伙伴机器人的外观。优先展示女性的上半身和机器人的全身；脸部、头部、手臂武器、背部和腿部细节作为补充。不要复制轮廓、白色背景、标题、多视图、表情，或将脸部/腿部/武器的细节作为开场镜头或构图。从一开始就让两人在完整的动漫世界中进行动画演示。女性和机器人在同一场战斗中是盟友，但在前半段到中期独立行动，仅在最后汇合攻击同一个大型敌人。保持脸部、发型、体型、装甲、武器、背部结构和配色方案；禁止服装/装甲/单位更换、变形、融合、巨大化、复制或颜色互换。敌人是石墨色的非人形小型无人机，最后出现一架大型石墨色无人驾驶飞行器。背景中的空中交通为民用，不参与战斗。

[视野与运动] 以广角到超广角为主。即使在 1:1 的比例下也不要让人感到局促；留出天空、大海、城市、建筑和留白。特写镜头仅作瞬间使用。运动不应是照片级的平滑，而应表现为一系列动作链：强力姿态 -> 短暂张力 -> 遮挡画面 -> 另一地点的强力姿势 -> 接触 -> 短暂打击停顿 -> 大幅度反应。避免长距离奔跑或飞行；使用弧线、对角线交叉、突然转向、垂直高度差、X 形、S 形以及在建筑物间跳跃。摄像机也使用大胆的对角线俯冲、突然爬升、穿梭、建筑间隙和快速反转。

[特效] 特效不应是蓝光线条、光束、激光或极光。使用来自 @image1 的主色调和强调色，表现为带有清晰轮廓的不透明色块、粗笔触痕迹、长长的扫尾状线条、飞溅的色片和对角线色块。每一次移动、出现或撞击都必须伴随类似拖拽颜料般的快节奏特效。

[构图] 0.0-1.5 秒：沿海城市的超广角镜头。无人机从多个方向入侵。走廊墙上的女性和下层甲板上的机器人分别部署。机器人以弧线格挡攻击，冲击波席卷城市。1.5-3.3 秒：女性部分。色块覆盖前景，在走廊、交通通道和屋顶之间切换。她仅展示姿态、斩击和着陆反应的关键动作，并伴有强烈的线条特效。3.3-5.1 秒：机器人部分。利用甲板边缘和桥梁进行弧形轨迹移动和重击，击飞无人机。5.1-6.9 秒：女性部分。建筑物间的垂直空间。在遮挡后从不同角度瞬间出现，改变高度进行连续攻击。6.9-8.7 秒：机器人部分。利用高层结构进行墙面反转并穿过无人机群。8.7-10.2 秒：大型无人机进入。巨大的阴影掠过航站楼。女性和机器人从不同方向跳入，汇合攻击敌人。10.2-12.2 秒：高速连击高潮。机器人以弧线击碎装甲；视角翻转，女性从上方出现并斩击弱点。没有长时间的缠斗。12.2-15.0 秒：大型单位爆炸，不是火球，而是不透明的色块和锋利的碎片。摄像机穿过残骸来到观景台。两人在不同时间着陆并重新加速离开。城市以庆祝的烟雾和功能恢复作为回应。最后以城市全景结束，轨道延伸至远方。

[音频与禁忌] 高密度剧场版动漫 BGM。在冲击、斩击和破坏时具有强烈的动态感。避免廉价的电视动画风格、恒速运动、长时间慢动作、UI、字幕或武器融合。
