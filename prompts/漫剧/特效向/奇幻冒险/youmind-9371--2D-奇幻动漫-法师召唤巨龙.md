# 2D 奇幻动漫：法师召唤巨龙

*2D Fantasy Anime Wizard Dragon Summoning*

> 一个复杂的日语提示词，用于制作 15 秒的奇幻动漫短片，讲述了一位年轻法师从魔法书中召唤星辰巨龙的故事。

## 提示词（日本語）

```text
15 秒間の高品質な 2D ファンタジーアニメ。添付画像の若い魔法使いを主人公とし、ボサボサの黒髪、丸眼鏡、青灰色の瞳、濃紺と水色の魔法使いのローブ、革ベルト、魔法の本、杖、小柄な体格をすべてのカットで厳密に維持すること。繊細な線画、水彩画風の彩色、幻想的な青と金の光、劇場版アニメのようなクオリティ。

[0～4 秒]
夜明け前、雲海に突き出した古代の天文台。強風の中、少年が両手で大きな魔法の本を開く。カメラはローアングルから素早く接近する。ページが激しくめくれ、書かれた星座が青白く発光する。髪とローブが風になびく。

[4～10 秒]
魔法の本から無数の星の粒子が噴出し、少年の周りを渦巻く。カメラは少年の周りを大きな半円を描くように移動する。星の粒子は空中で巨大な半透明の星のドラゴンへと姿を変え、翼を広げる。少年は驚いた表情で、眼鏡越しに空を見上げる。

[10～15 秒]
巨大な星のドラゴンが少年の頭上から雲海に向かって飛び去り、雲を切り裂いて夜空を日の出へと変える。少年の顔のアップ。去りゆくドラゴンが瞳に映り込み、最後に少年がわずかに微笑む。壮大で感動的な余韻。滑らかなアニメーション、自然な体の動き、完璧な指の描写、文字や字幕はなし。
```

```text
15 秒高质量 2D 奇幻动漫。以附图中年轻法师为主角，在每个镜头中严格保持其凌乱黑发、圆框眼镜、蓝灰色双眼、深浅蓝色魔法长袍、皮带、魔法书、法杖以及矮小身材的特征。线条细腻，水彩风格上色，呈现梦幻般的蓝金色光影，具备影院级动漫质感。

[0-4 秒]
黎明前夕，一座古老的天文台矗立在云海之上。狂风中，少年双手打开一本巨大的魔法书。镜头以低角度快速推进。书页剧烈翻动，书写的星座发出蓝白色的光芒。少年的头发和长袍在风中飘动。

[4-10 秒]

[10-15 秒]
巨龙从少年上方飞向云海，拨开云层，将夜空转变为日出景象。镜头特写少年的脸庞，离去的巨龙倒映在他的眼中，最后少年微微一笑。营造出宏大而动人的余韵。动画流畅，肢体动作自然，手指细节完美，无文字或字幕。
```

A 15-second high-quality 2D fantasy anime.
