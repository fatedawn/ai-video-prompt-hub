# 高速魔法战斗动画

*High-Speed Magic Battle Animation*

> 一个用于电影级 2D 魔法战斗场景的精细提示词。详细说明了角色一致性、特定魔法效果以及包含传送和弹幕战斗的九分镜编排，场景设定在浮空遗迹中。

## 提示词（日本語）

```text
参照画像のキャラクターを主人公とし、全編を通して同一人物であることを維持してください。参照画像は、顔、目の形、虹彩の色、ハイライト、まつげ、眉、鼻、口、頬、顎、年齢、髪型、髪色、服装、装飾品、体格、キャラクターカラーを固定するためのデザイン素材としてのみ使用します。参照画像の背景、部屋、家具、レイアウトは再現しないでください。

[世界観] 月光に沈む浮遊遺跡を舞台にした、幻想的で高密度な高速魔法バトル。ハイエンドな 2D 手描きアニメ MV スタイル。全 9 カット固定、追加なし。1 カット目から高出力の魔法光が炸裂し、長い待ち時間やフェードはなし。各カットでメインとなるアクションを明確にし、魔法媒体、魔法陣、テレポート、防御、衝撃、キャラクターの表情を高速でつなぎます。

[キャラクターのルール] 全編を通してキャラクターの一貫性を維持すること。服装や髪型の変更は禁止。クローンや余分な人物の登場も禁止。テレポートでは、キャラクターが消失してから同一人物として再出現する様子を描写すること。

[装備] 光の閃光、回転、発射に適した細身の杖、剣、またはロッドを使用すること。参照画像にない場合は、キャラクターのスタイルに合わせた魔法の杖を 1 本追加してください。2 つ目の武器や召喚ツールは使用不可。

[アートスタイル] 参照画像のような密度と発光を伴う、ハイエンドな 2D 手描きアニメーション。映画のようなキーアニメーション、高品質なコンポジット、透明感のあるライティング。細く繊細な線画（太い輪郭線は避ける）。影は多層的で柔らかいもの。3DCG やプラスチックのような質感は禁止。

[シーン]
カット 1：魔法媒体の先端の極端なクローズアップ。キャラクターカラーの光が即座に炸裂。閃光の中に主人公の瞳が反射する。カメラが素早く引き、アクションポーズを見せる。
カット 2：主人公が魔法媒体で斬りつける。鋭く輝く弧が魔法陣を形成し、画面をワイプして遺跡内の新しい場所へ切り替わる。
カット 3：主人公がテレポートして反対側へ移動。影の投射物を受け止める。高速のカメラアングルシフト。
カット 4：魔法媒体を回転させる。3 つの魔法陣が投射物を弾き、光の道を開く。
カット 5：カメラが光の道に入る。主人公が柱の上にテレポートし、前方を見据える。
カット 6：核が影の投射物を発射。主人公が魔法陣を描き、複数の減速アレイを展開。投射物が光の破片へと分解される。
カット 7：ターゲットを見据える瞳。魔法媒体が複数の魔法陣および核と一直線に並ぶ。カメラがその軸を追う。
カット 8：高密度のビームが魔法陣を貫き、核に命中。爆発はせず、魔法の紋様が広がり、核に亀裂が走る。
カット 9：亀裂が花びらや羽のようなモチーフへと溶けていく。最後にカメラの近くでヒーローポーズへテレポート。髪と衣服がなびき、シーンが終了する。
```

```text
[世界观] 设定在月光笼罩的浮空遗迹中，进行高密度、高速度的奇幻魔法战斗。采用高端 2D 手绘动画 MV 风格。固定 9 个分镜，不得增减。第 1 帧即爆发高输出魔法光效；无需漫长的等待或淡入淡出。每个分镜清晰展示一个主要动作，高速衔接魔法媒介、魔法阵、传送、防御、冲击和角色面部特写。

[角色规则] 确保角色在全片中保持一致。不得更换服装或发型。不得出现克隆人或多余人物。传送时必须表现出角色消失后，在另一处以相同形象重新出现。

[装备] 使用适合闪烁、旋转和发射光束的纤细魔杖、剑或法杖。如果参考图中没有，请添加一根与角色风格相符的单体魔杖。不得出现第二武器或召唤工具。

[艺术风格] 具有参考图密度和发光效果的高端 2D 手绘动画。电影级原画，高质量合成，透明光影。线条精细细腻，避免厚重的轮廓线。阴影采用多层柔和处理。严禁 3DCG 或塑料质感。

[场景]
分镜 1：魔法媒介尖端的极近距离特写。角色配色光效瞬间爆发。主角的眼睛映照在闪光中。镜头迅速拉回展示动作姿态。
分镜 2：主角挥动魔法媒介。一道锐利的发光弧线形成魔法阵，扫过屏幕切换至遗迹中的新位置。
分镜 3：主角传送到另一侧。吸收一枚暗影弹幕。高速镜头角度切换。
分镜 4：旋转魔法媒介。三个魔法阵偏转弹幕并开启一条光之路径。
分镜 5：镜头进入光之路径。主角传送到柱顶并向前瞄准。
分镜 6：核心发射暗影弹幕。主角画圆部署多个减速阵。弹幕分解为光之碎片。
分镜 7：双眼锁定目标。魔法媒介与多个魔法阵及核心对齐。镜头沿轴线移动。
分镜 8：高密度光束穿过魔法阵，击中核心。没有爆炸，魔法纹路扩散，裂纹在核心上蔓延。
分镜 9：裂纹消散为花瓣或羽毛般的图案。最后传送至镜头前的英雄姿态。场景结束时，头发和衣物随风飘动。
```
