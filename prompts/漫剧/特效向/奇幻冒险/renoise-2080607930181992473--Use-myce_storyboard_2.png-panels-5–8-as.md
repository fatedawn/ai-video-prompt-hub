When creating DR ads like Meta ads, it’s much smoother to start by writing the script first.

So this time, I created the script while consulting with Claude.
That said, I did not leave everything entirely to Claude.

The workflow was:

1. First, have Claude create a rough draft
2. Have a human review, revise, and refine the content

[Thread 2] ② Character Sheet / Product Sheet Generation

This time, I gave a single image two roles: a character sheet and a product sheet (an image that summarizes product information).
By preparing this one image, it becomes easier for AI to consistently recognize the character’s and product’s features, which also helps maintain consistency in later image and video generation.

Here is the actual prompt used, along with the image generated from it.↓

---------------------
Create a Pixar-style 3D reference sheet in a 2×3 grid layout,

Background: soft neutral light-gray studio backdrop. Even, consistent lighting across all panels.
Each panel labeled with a small bold number (top-left inside frame).
TOP ROW = character turnaround. BOTTOM ROW = product turnaround.

=== CHARACTER (top row, keep 100% identical across the 3 character panels) ===
A friendly 34-year-old Japanese woman, Pixar/Disney 3D animation style.
Shoulder-length dark-brown bob with a few soft loose strands, warm almond eyes with a
gentle expression, natural light makeup, soft rounded cheeks. Cozy beige knit top.
Rounded appealing Pixar proportions, soft subsurface skin shading, gentle bloom lighting.

[Thread 1] ① 脚本生成
