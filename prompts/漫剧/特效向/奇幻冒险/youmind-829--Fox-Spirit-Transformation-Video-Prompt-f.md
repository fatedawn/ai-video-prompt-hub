# Fox Spirit Transformation Video Prompt for Seedance 2.0

> 一个用于 Seedance 2.0 的提示，生成一段关于狐妖在月光竹林中幻化成美人的奇幻视频，强调水墨画和 CG 插画的视觉风格，并着重表现幻化过程和角色随后的动作。

## 提示词（中文）

```text
[蜕变] 狐狸 A：火红的皮毛，狡黠而敏捷，卧于青石竹林中。蜕变过程：白光笼罩，红毛褪去，身形变得纤细，面部特征女性化。美人 B：容貌惊艳，素白汉服，眼眸清澈，玉簪挽发，疑惑地看着自己的双手。场景：月光竹林，斑驳月影，鹅卵石地面，远处亭台若隐若现。动作：狐狸卧下 -> 白光 -> 蜕变 -> 美人站起 -> 疑惑地看手 -> 轻抚发丝。镜头：从狐狸眼睛特写开始，逐渐拉远，环绕竹林中的美人。氛围：神秘、唯美、奇幻、飘渺、宁静、雅致、梦幻。风格：水墨画 + CG 插画，轻柔淡雅，写意流畅，朦胧光影，古典东方韵味。
```
