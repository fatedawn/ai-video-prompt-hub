# 电影级凤凰召唤序列

*Cinematic Phoenix Summon Sequence*

> 一份详细的 15 秒动漫风格召唤巨型凤凰的提示词，包含火焰逐渐演变的过程及电影级的灯光效果。

## 提示词（日本語）

```text
# リファレンス

メインキャラクター = @image1: 顔の特徴、髪型、髪色、目、肌や毛皮の質感、服装、装備、アクセサリー、体格、シルエット、色、雰囲気、そしてキャラクターのアイデンティティを維持してください。リファレンス画像に存在しない服装、装備、身体的特徴を追加しないでください。

# スタイル

フルカラーの日本のアニメスタイル。派手でシネマティックなファンタジー PV。メインキャラクターが夜明け前の森で火の魔法を生み出し、炎を段階的に変化させ、最終的に巨大なフェニックスを召喚します。

順序は固定です：手で空気と光を集める → 火種 → 横に走る炎 → 垂直に噴き上がる炎 → 渦巻く圧縮 → 大きな火の卵 → 卵のひび割れ → 小さな火の鳥 → 成長 → 巨大なフェニックス。手順を飛ばさないでください。

# 設定 / 背景

夜明け前の森の開けた場所。高い木々、朝霧、苔むした地面、湿った土、小石、木の根があります。背景を真っ暗にせず、青い森の奥行き、霧の層、木漏れ日を見せてください。地面は濡れており、炎の光を反射します。火花、灰、舞い散る落ち葉、そして判読不能な抽象的な魔法のルーン文字が空中に現れては消えます。

# 時間 / 季節 / 天候 / 光

早朝。晴れ。最初は冷たい青色の薄明と霧。魔法が始まると、炎の温かい光が主人公の顔、髪や頭部、服装、手、そして地面を照らします。炎が大きくなるにつれて、オレンジと黄金色の光が霧、木の幹、枝葉、地面に広がります。巨大なフェニックスが現れると、朝の逆光、強い炎の光、陽炎、地面の反射が強く同時に発生します。

# 視覚的詳細 / 質感

指先、手、服の端、髪や毛皮、装備、アクセサリーの質感を見せてください。髪、毛皮、服の裾、生地、装飾が熱風で自然に揺れます。炎は火種から、横に走る炎の帯、垂直に噴き上がる炎の柱、渦巻く炎、脈動する大きな火の卵、ひび割れる殻、小さな火の鳥、成長する火の鳥、そして巨大なフェニックスへと変化します。最後のフェニックスは、翼、頭、くちばし、胸、尾羽が明確に識別できる雄大な火の鳥です。

# カメラ / フォーカス / 構図

カットの平均長は 2 ～ 3 秒。全編を通して単一の構図を使用しないでください。手のクローズアップ、上半身、顔と手、森を含むミディアムワイド、そして最後のローアングルからの見上げを使用します。正面を向いた「パワーポーズ」は避けてください。45 度の角度、ローアングル、前ボケ、オフセンターの構図を使用してください。炎が横に走るときは水平トラッキング、垂直に噴き上がるときはティルトアップ、卵の形成中はオービット（旋回）、巨大化中はスケールを見せるために少し引くカメラワークを使用します。

# オーディオ

壮大でシネマティックなファンタジー BGM。歌詞なし。最初は神秘的で、中盤はストリングスと重厚なパーカッション、最後はクライマックスに達します。

効果音には、布や装備が擦れる音、手から発生する風切り音、着火音、炎が横に走る音、炎が噴き上がる音、渦巻く燃焼音、卵の低い共鳴音、殻が割れる音、小さな鳥の火の翼が羽ばたく音、そして巨大なフェニックスの爆発的な炎の音と重厚な羽ばたき音を含めます。台詞はありません。

# シーン

この 15 秒間で、主人公は森の中で手の中に空気と光を集め、小さな火種を生み出します。炎は横に走り、垂直に噴き上がり、渦巻いて大きな火の卵になります。卵が割れて小さな火の鳥が生まれ、主人公の周りを旋回しながら成長します。最後になって初めて巨大なフェニックスへと一気に変身し、翼を広げて森と主人公を包み込みます。

# 制約事項

字幕なし。画面内のテキストなし。ロゴなし。判読可能な UI なし。判読可能な文字による魔法文字なし。魔法のシンボルは抽象的なルーン文字やパターンであること。

@image1 の顔、髪型、髪色、目、肌や毛皮の質感、服装、装備、アクセサリー、体格、シルエットを維持してください。リファレンス画像にない帽子、リボン、マント、杖、服装、装備を追加しないでください。同一人物の複数を表示しないでください。

背景を真っ暗にしないでください。変身の段階を飛ばさないでください。カット 3 で形成された大きな火の卵のサイズと位置を、カット 4 の開始時にも維持してください。カット 4 の開始時に卵を小さくしないでください。最後に巨大なフェニックスを明確に見せてください。暗転なし。通常のフレームで終了してください。

# タイムライン

カット 1: 0 ～ 2 秒。夜明け前の森。主人公の上半身と手。主人公は片手を前に出し、もう片方の手を重ねるように近づけ、空気と光を集めます。霧、光の粒子、落ち葉が手に引き寄せられ、指先に小さな火種が灯ります。手元のクローズアップ、45 度の角度。BGM 開始。布や装備が擦れる音、風切り音、着火音。

カット 2: 2 ～ 4.5 秒。火種が手の中に浮かびます。主人公が両手を左右に開くと、炎が鋭く横に走り、炎の帯になります。片手を上げると、炎は中心に戻り、垂直に噴き上がる炎の柱になります。水平トラッキングからティルトアップへ。火花、鋭い燃焼音、重厚な燃焼音。

カット 3: 4.5 ～ 7 秒。炎の柱が霧と木々を照らします。主人公が両手を内側に寄せると、炎が渦巻いて圧縮され、主人公の上半身と同じくらいの大きさの大きな火の卵が作られます。卵は胸から顔の高さにかけて、手の少し前に浮かびます。卵は脈動し、表面を抽象的なルーン文字が走り、最後に明確なひび割れが入ります。卵の周りを旋回。低い共鳴音。

カット 4: 7 ～ 9.5 秒。カット 3 で形成された火の卵のサイズと位置を維持した状態から開始。主人公の顔、頭、服装、手が見えます。卵は胸から顔の高さにかけて、手の少し前に大きく浮かんでいます。卵が割れ、殻が火花となって爆発します。中から小さな火の鳥が生まれます。小さな鳥は卵より明らかに小さく、卵の中心から現れ、出てきた後に主人公の手の周りを一度旋回します。主人公は驚きと喜びを感じ、両手で小さな鳥を導きます。殻が割れる音、小さな羽ばたき音。

カット 5: 9.5 ～ 12 秒。森を含むミディアムワイド。小さな火の鳥は主人公の周りを旋回しながら成長します。手のひらサイズから上半身サイズ、そして人間の胴体サイズへと大きくなります。翼と尾羽が伸び、炎の軌跡が森の中に大きな円を描きます。髪、毛皮、服装、装備、枝葉が熱風で揺れます。カメラは少し引きます。BGM はクライマックス直前まで盛り上がります。

カット 6: 12 ～ 15 秒。森の開けた場所。中サイズの火の鳥が最後の一瞬で巨大なフェニックスへと変身します。翼を広げて画面を埋め尽くし、頭を高く上げ、長い尾羽をなびかせます。火花、灰、霧、落ち葉が衝撃波のように外側へ広がります。主人公は達成感のある表情で巨大なフェニックスを見上げます。ローアングルからの見上げ。爆発的な炎の音、衝撃波、重厚な羽ばたき。翼を広げた巨大なフェニックスの通常のフレームで終了。
```
