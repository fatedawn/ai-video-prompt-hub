## 提示词（中文）

```text
无限城 BGM 一响，
缘一 VS 百鬼  ⚔️💥
纯粹的战斗爽感！

Seedance 2.5
Prompt 🔽

【基础设定】

30秒，16:9。暗色幻想绘画动画风格，粗粝厚涂笔触、硬边明暗、概括色块、清晰人物剪影。

人物、敌群、建筑、武器统一为具有立体空间感的绘画动画。

高速运动中保持人物、刀锋、命中位置清楚。

头发、衣摆、碎木、灰烬具有真实惯性与重量。

整体色调以墨黑、灰青、旧木褐为主，人物暗红服装作为主要识别色。

【参考图绑定】
图片1= 战场建筑与空间结构参考。
仅采用悬空木平台、栏杆、回廊、阶梯、大殿及上下交错建筑关系。
图片2 = 敌群外观参考。
提取不同体型、皮肤、眼睛、獠牙、长爪、破旧衣物与异化轮廓，扩展为高密度敌潮。
图片3= 主角唯一身份与服装参考。
锁定脸型、长发、暗红外衣、敞领、腰带、宽裤、绑腿与鞋履。

【角色规则】

全片始终只有一名主角。
始终使用同一把实体刀，刀鞘固定腰侧。

右手主握，重斩时左手辅助同一刀柄。

人物面部克制，视线始终寻找下一处敌阵缺口。

所有攻击必须由真实身体动作驱动：

蹬地 → 转髋 → 挥刀 → 回腕 → 连续落步。

高速移动过程中人物本体始终连续可追踪。

禁止瞬移。

禁止实体分身。

禁止第二把刀。

【敌群规则】

敌人数百只。

中央平台、两侧回廊、远端阶梯与建筑阴影始终存在大量敌人。

前景使用肩背、头部、爪子压住画面边缘。

中景多排敌人包围人物移动路线。

背景敌群一直延伸至建筑深处。

敌人必须持续：

扑入、夹击、绕侧、封路、补位。

人物移动到哪里，新的敌群就从前方与侧翼压入。

人物经过之后才允许留下局部缺口。

24秒之前禁止大面积清空战场。

【核心战斗逻辑】

模式：

流光割草 + 极限连招密度。

全片以：

高速穿群
移动旋斩
横扫
反手斩
斜劈
短跃下劈

作为主要动作。

目标约26组短连招。

每组动作必须：

起手 → 接招 → 收招，无缝连接。

上一刀的收刀方向，直接成为下一组攻击的起始方向。

禁止攻击后站住重新摆姿势。

禁止三刀打一组然后停顿。

人物始终边打边移动。
【空间规则】
主平台远端阶梯 = 北。
入口 = 南。
左右两侧分别为东、西。
人物移动路线：

南部
→ 东侧
→ 中央
→ 西侧
→ 北部。

摄影机始终朝向尚未清除的敌群推进。

人物身前必须持续存在新的敌阵。

身后逐渐形成已经战斗过的路径。

空间、建筑地标、人物方向必须保持连续。

【镜头结构】

全片10个镜头段。

每段约3秒。

Shot 1｜0–3s

Wide，高位斜俯视追踪。

人物直接高速切入右侧敌群。

突入横斩
→ 反手回切
→ 移动回旋
→ 再次斜切进入下一排。

没有登场。

没有拔刀。

没有蓄力。
第一秒直接进入战斗。
Shot 2｜3–6s
FS，贴地侧前跟拍。
人物沿东侧战区高速向北推进。

连续横扫、反手斩、斜劈。

敌人从正面和侧面不断补入。

摄影机倒退跟拍，同时保留前方大量敌群。

Shot 3｜6–9s

Wide，升高斜俯视追踪。

人物从东侧切向平台中央。

连续三组移动旋斩。

每一次旋转都改变人物所在位置。

禁止原地转圈。

镜头展示人物身后逐渐形成的战斗路线。

Shot 4｜9–12s

FS，低位跟进。
人物进入中央最密集敌阵。
横扫
→ 反撩
→ 斜切
→ 上挑
→ 踏进压斩
→ 短跃下劈。
上层回廊与地面敌人同时压入。

人物必须同时应对上下两个方向。

Shot 5｜12–15s

FS，侧面短弧环绕。

人物折向西侧。

移动旋斩
→ 短跃
→ 下劈
→ 落地反手横扫。

完成后立即进入下一群敌人。

禁止落地停顿。

Shot 6｜15–18s

Wide，斜俯视折返追踪。

人物切进西侧敌阵后向北折返。

连续横斩、反斩、回旋压斩。

新的敌群从西侧回廊持续补入。

北侧阶梯始终作为远处空间地标。

Shot 7｜18–21s

MS → FS。

先短暂靠近人物。

展示一次真实的近距离攻防：

敌人双爪封路。

人物低身闪开攻击，同时转髋反切。

随后镜头立即拉开。

继续展示范围穿群动作。

禁止变成单挑。

Shot 8｜21–24s

Wide。
人物进入北部中央区域。
沿敌潮内部连续折线移动。
斜切进入
→ 回旋扫开
→ 反手穿出
→ 再改变方向。
东西两侧残余敌群继续向中心补位。
Shot 9｜24–27s

FS → Wide。

人物切入最后的大规模密集敌阵。

横扫
→ 反手斩
→ 压斩
→ 回旋
→ 反撩
→ 前冲斜劈。

镜头逐渐拉开。

明确展示人物已经打通的路线，与前方最后敌阵的位置。

Shot 10｜27–30s

FS → Wide。
人物冲入北阶前最后一批敌人。
27–28秒完成最后一组连续攻击。
28秒后停止攻击。

刀尖自然随收势垂下。

镜头缓慢后拉。

展示整个已经清理完成的平台。

主角成为画面中唯一站立的人物。

衣摆、长发、灰烬、碎屑继续自然运动。

【摄影规则】

摄影机必须跟随：

人物移动路线
攻击方向
敌群变化
空间地标。

远景与全景负责展示敌潮规模。

中近景只用于短暂展示身体动作与刀锋。

禁止长期贴脸。

禁止把范围战斗拍成逐个单挑。

禁止依靠疯狂切镜制造速度。

速度必须来自：

人物移动
敌群运动
身体动作
前景掠过
摄影机追踪。

【声音】

No dialogue.

No battle cries.

No subtitles.

No background music.

保留：
脚步声
挥刀声
撞击声
木构破裂声
环境空间回响。
```
