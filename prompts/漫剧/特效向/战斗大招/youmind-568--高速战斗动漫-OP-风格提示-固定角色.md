# 高速战斗动漫 OP 风格提示（固定角色）

*High-Speed Battle Anime OP Style Prompt (Fixed Characters)*

> 这是复杂提示的固定角色版本，旨在生成高速战斗动漫开场序列，特别侧重于保持八个输入角色在依次出现、执行标志性动作并快速切换时的连贯性。此版本旨在复刻经典动漫开场序列中主要角色快速接连登场的场景。

## 提示词（日本語）

```text
高品質で超高速な日本のバトルアニメ。
参考画像の画風に合わせる。
入力画像に登場する個性的なキャラクターたちが、青空を背景に、画面右側から超クローズアップで次々と現れ、左に向かって移動する。彼らは、それぞれのユニークな武器を使い、強烈で派手なエフェクト（火、水、雷、土、光、闇、デジタルなど）、魔法陣、発光を放ち、様々なシャープでアクション性の高い動きで繰り出される必殺技で画面全体を埋め尽くす。彼らは素早く右奥に消え、次のキャラクターが正面から現れて交代する。
各キャラクターは、インパクトの瞬間に一瞬だけ静止し、超クローズアップの決めポーズをとった後、高速移動で素早くフレームアウトする。画面は衝撃で揺れる。
カメラはアークショットを行い、旋回しながら飛び回り、高速のドリーインとドリーアウトで各キャラクターに素早く焦点を合わせ、ダッチアングルでダイナミックに捉える。
1キャラクターに割り当てられる最大時間は 0.5 秒。
入力画像に登場する各キャラクターが少なくとも 1 回は現れるようにする。
すべてのキャラクターの顔、体型、服装は、入力画像と寸分違わず維持する。
最後のキャラクターが究極の技を繰り出し、シーケンスを締めくくる。
動きの速度に変化をつけ、シャープな演出を用いる。
```

```text
一部高质量、超高速的日式战斗动漫。
匹配参考图像的艺术风格。

每个角色在冲击瞬间只停留片刻，摆出超特写决定性姿势，然后通过高速移动迅速移出画面。屏幕因冲击而震动。
摄像机进行弧形拍摄，围绕并飞旋，通过高速推拉镜头快速聚焦每个角色，并以荷兰角动态捕捉他们。

确保输入图像中的每个角色至少出现一次。
保持所有角色的面部、体型和服装与输入图像中完全一致。
最后一个角色施展终极技能，结束整个序列。
运用锐利的导演手法，并变化移动速度。
```

```text
Match the art style of the reference image.
```
