# 精细化 Gacha 游戏抽卡动画

*Detailed Gacha Game Summon Animation*

> 一份详尽的专家级提示词，用于制作包含复杂转场、UI 叠加和稀有度展示的专业 Gacha 游戏“召唤”或“抽卡”动画。

## 提示词（日本語）

```text
参照画像はあくまで参考用であり、開始フレームとしては使用しない。ソーシャルゲームのガチャ演出スタイル。アップテンポでエキサイティングな BGM に、電子音、抽選音、確定音などの効果音を合わせる。おしゃぶりをした少女は一切話さず、口も全く動かさない。すべてのトランジションは、インパクト、フラッシュ、UI の発光を伴う派手なエフェクトとする。開始直後、以下の演出が始まる。超高速トランジション。空間が歪んでガラスのように砕け、破片が光に変換されて吸い込まれる。強いホワイトアウト。直後にカット切り替え。暗い空間の中に、参照画像の特徴を極端に誇張した「異常で奇妙なガチャマシン」が既に存在している様子を描写する（例：キャラクターの髪色、モチーフ、世界観が機械化されている）。巨大な構造、非現実的な回転機構、浮遊パーツ、発光するパイプやエネルギー経路、神秘的かつクールな動き。装置内部でエネルギーが循環し脈動している。中央に「TAP」、「PULL」、「OPEN」といった操作 UI を表示。UI はネオン調で、強く発光し、わずかに振動させる。操作すると、装置が暴走するように振動、回転、発光する。エネルギーが臨界点に達し、一点に収束する。カット切り替え。排出：参照画像に関連する「コンテナ」が装置から排出される（例：カプセル、卵、クリスタル、箱、缶、巻物、食べ物のようなオブジェクト）。形状、質感、色は参照画像に基づいて決定する。コンテナは一度バウンドし、床や空間に当たった後に転がる。その瞬間、ひび割れて発光し、内部からエネルギーが漏れ出す。レアリティ判定：高レアリティの場合、虹色、プリズム、光が画面全体に拡散する。コンテナが振動し、徐々に浮き上がる。カット切り替え。コンテナが爆発的に開く。内部から光と粒子が噴出し、参照画像の特徴を誇張したシルエットが現れる。強いフラッシュ。カット切り替え。参照画像の背景の雰囲気を継承した空間が既に存在している様子を描写する。光のビーム、霧、粒子、気流。中央にキャラクターが登場。カメラ：足元から顔への急速なパン、回転するクローズアップ、ダイナミックな動きに満ちたキャラクター、スローモーションから加速へ。参照画像に基づいた属性エフェクトがキャラクターの周囲で発生する（例：火、水、雷、氷、光、闇、機械、自然）。属性マーク（エンブレム）が背後または頭上に現れ、発光しながら回転する。同時に、巨大な粒子、レンズフレア、衝撃波、光の筋が画面を埋め尽くす。中央に巨大なテキスト：「SSR」、「UR」、「LEGEND」のようなレアリティ表示。続いて、外見から生成された「異常に誇張されたタイトル」を表示。キャラクター名も生成して表示する。UI：下部に豪華なカード UI、枠はゴールドや虹色に輝き、星が次々と飛び出し、カードが回転してスライドする。ステータス：HP/ATK/DEF/SPEED が急速にカウントアップする。スキル名を生成して表示する（例：「次元崩壊ブレイク」）。レアな追加要素：背景の変化、画面の揺れ、粒子の増加。最終カット：キャラクターがクールなポーズで静止する。ハイセンスなデザインロゴで「タイトル」と「名前」を表示。背後に属性エンブレム、エネルギーが循環。UI が淡く発光し、ループ可能な状態で終了する。スタイル：シネマティック、ガチャゲーム UI オーバーレイ、超詳細、高コントラスト、ファンタジー召喚マシン、ダイナミックライティング、ボリュメトリックライト、グロー、粒子、モーションブラー、レンズフレア、インパクトフラッシュ
```
