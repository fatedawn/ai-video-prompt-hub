The idea behind this format is simple

❶ Observe the image
❷ Fix everything that doesn’t change with the same ★ this is the core
❸ Write only the movements that can naturally happen from the current pose
❹ Quality stability + continuity rules

the more things you lock in,
the higher the quality of the moving parts

make a back-facing subject turn around

This format can be used for anything as long as you have an image
