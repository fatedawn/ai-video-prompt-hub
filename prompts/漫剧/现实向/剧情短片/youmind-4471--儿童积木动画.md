# 儿童积木动画

*Children Building Blocks Animation*

> 一个用于 Seedance 2.0 的多场景动画提示词，描绘了散落的积木从不同摄像机角度自发组合成特定形状的过程。

## 提示词（English）

```text
Language: Japanese
Subtitles: None

Scene 1:
Children's building blocks are scattered.

Scene 2:
Different angle.
The blocks spontaneously form the shape
```
