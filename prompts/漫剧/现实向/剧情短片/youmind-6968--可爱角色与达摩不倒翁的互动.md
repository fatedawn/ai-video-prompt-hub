# 可爱角色与达摩不倒翁的互动

*Cute Character and Daruma Doll Interaction*

> 一个特定的动画提示词，描述角色在达摩不倒翁和镜头之间反复切换视线，并伴有可爱姿势和“闪闪发光”的表情。

## 提示词（日本語）

```text
だるまを見てからカメラを見つめ、再びだるまを見てからカメラを見るという動作を繰り返します。カメラを見た瞬間に、かわいいポーズをとってください。これを高速で数回繰り返します。カメラを見るたびに、だるまを頬に当てて「キラ〜ン」とささやきます。
```

## 其他语言版本（上游仓库提供，非本仓库翻译）

[位置](https://github.com/YouMind-OpenLab/awesome-seedance-2-prompts/blob/8d327403a6bcf70c4464970df08a75676ba037c2/README_zh.md#L2944)

```text
反复看向达摩不倒翁，然后看向镜头，再转回达摩不倒翁，接着再次看向镜头。每当看向镜头时，摆出一个可爱的姿势；如此高速重复几次。在看向镜头时，将达摩不倒翁贴在脸颊上，并轻声说出“Kiraan”（闪闪发光）。
```

### YouMind 提供的English版本（README.md）

