# 从分镜脚本到动漫烹饪视频的 Prompt

*Storyboard to Anime Cooking Video Prompt*

> 此 Prompt 旨在将粗略的铅笔分镜脚本转化为高质量、全彩的日本 2D 动漫风格烹饪视频，同时保留原有的构图与动作。

## 提示词（日本語）

```text
ラフな鉛筆画の絵コンテを視覚的なリファレンスとして使用してください。絵コンテは、構図、カメラアングル、手の動き、食材の配置、調理の連続性を維持するためにのみ使用します。最終的な動画は、高品質なフルカラーの日本のアニメ風料理動画に変換してください。白黒の鉛筆画の質感は、最終的な動画には残さないようにしてください。
```
