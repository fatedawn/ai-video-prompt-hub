一个现代极简风格的制作板，展示一位冷静的剑术大师面对五个忍者并逐一击败他们。图板传达固定的庭院地理位置，精确的 C# 连续性，一把携带的剑，空中的红色轨迹，花瓣消失效果，以及一个带有淡淡灵魂轮廓的反手剑击。

[标题]
设计一个艺术性的制作板标题，具有场景感知的排版，细致可读的规则，清晰的层次结构，宽松的间距，以及仅限于面板内部的克制图形处理。
标题必须包含以下两行引号中的文字：
"Petals After Steel"
"Five shadows bloom away from one quiet blade."

[板结构]
使用 AUTO 布局，包含 8 个面板。
使用紧凑的面板标题，格式如下：`P## / shot tag / beat name`。
每个 BEATS 条目绘制一个面板，保持 P## 顺序，并将每个面板保持为一个清晰的视觉动作节拍。

[视觉风格]
面板内部是无声的视觉参考缩略图：简单的开放轮廓剪影，中等亮度的石墨线条，主要是白色纸张，宽广的负空间，仅需锚点以读取姿势、物体接触、屏幕方向和空间结果。
开放轮廓剪影仅显示外部身体质量和肢体轮廓，没有内部解剖学、面部细节、服装细节、纹理或角色设计完成。仅对空中的红色轨迹、彩色花瓣效果和一个淡淡的灵魂轮廓使用克制的颜色。
没有血液、黑色液体、血腥、灰色洗涤、石墨调子、建模或阴影填充。

[参考]
图像 A：仅 C1 剪影、长袍/外套块、头发质量、剑的存在和红色强调态度。

[连续性]
保持 C# 剪影身份、道具状态、效果来源、屏幕方向、固定庭院地理位置和从头到尾的空间结果一致。
被击败的 C2-C6 继续作为相同 ID 的花瓣云或消退的痕迹，而不是额外的身体或额外的忍者。P04 的灵魂轮廓是来自 C4 的效果，而不是第七个角色。
每个分镜板面板是一个冻结的瞬间：对每个 C#/物体使用一个姿势/状态，避免使用 `then`、`after`、`before`、`first`、`next`、`later` 或 `remains ... then` 等词。

[计数锁定]
P01 精确保留六个一次性角色：C1 剑术大师，C2 远左，C3 左前，C4 中前，C5 右前，C6 远右。后续面板不再添加重复的忍者；消失的角色仅作为相同 ID 的花瓣痕迹出现。P08 显示 C1 加上 C2-C6 车道中的五个消退的花瓣痕迹。
每个面板使用一个 C1 剑和一个空中剑轨状态。C1 始终携带一把剑；P04 使用相同剑的剑柄，而不是第二把武器。

[文本规则]
可见文本：仅限两行引号中的标题和紧凑的面板标题。

[约束]
避免标志、水印、覆盖、额外面板、插图、完成插图、密集细节、重复/幽灵实体、前后复制和不一致的计数。

[节拍]
每个视觉 BEAT 绘制一个分镜板面板：
节拍：
P01 / overhead wide / five-shadow gate: 高空俯视宽幅的干净湿石庭院；C1 站在中心，剑垂下，C2 远左，C3 左前，C4 中前，C5 右前，C6 远右站立成半圆。
P02 / low front medium / first petals: 低前中景；C1 站在 C2 的攻击线外，剑伸出形成一条直的空中红色轨迹，C2 保持一个左后破裂的姿势，彩色花瓣从击中处展开，C3 左前，C4 中前，C5 右前，C6 远右保持直立。
P03 / side wide / second bloom: 侧视宽幅；C1 保持一个向前滑动的姿势穿过车道，一条直的空中红色轨迹穿过 C3 的路径，相同的 C2 是远左的消退花瓣痕迹，C3 向后折叠成彩色花瓣，C4 中前，C5 右前，C6 远右保持直立。
P04 / three-quarter medium / hollow spirit: 三分之四中景；C4 压入 C1 的后四分之一并重叠 C5 的脸和武器车道，C1 的躯干大部分向前，C1 同一携带剑的剑柄向后插入 C4 的胸部，一个淡淡的灵魂轮廓从 C4 的背后移出，C4 的躯干边缘破裂成彩色花瓣，相同的 C2 和 C3 是左侧的花瓣痕迹，C6 保持远右。
P05 / overhead wide / crescent bloom: 高空俯视宽幅；相同的 C4 是中心车道的彩色花瓣云，C1 站在 C5 的车道和中心之间，剑附近有一个细的空中红色新月，C5 向右后退缩成彩色花瓣靠近画面边缘，相同的 C2 和 C3 是左侧的花瓣痕迹，C6 站在远右。
P06 / low rear wide / last standing: 低后宽幅从 C1 后面；C6 站在远右孤立直立，而四个消退的花瓣痕迹标记了 C1 后面的用尽车道。
P07 / frontal long / final contact: 正面长景；C1 站在中心左近，剑低垂，一条短的空中红色对角线明显穿过 C6 的躯干，C6 在 C1 后面失去平衡，彩色花瓣从接触处展开，相同的 C2-C5 仅作为消退的花瓣痕迹留在他们的车道中。
P08 / high wide / empty half-circle: 高空宽幅返回到相同的庭院，距离更远；C1 站在中心，剑垂下，五个消退的花瓣痕迹保持 P01 的原始半圆车道。
