# Create an artistic 16:9 CHARACTER IDENTITY BOARD.

## 提示词（English）

```text
Create an artistic 16:9 CHARACTER IDENTITY BOARD.

[SUBJECT]:
Design [CHARACTER NAME], a [CHARACTER ROLE / ARCHETYPE].
The character should feel designed for future AI video generation, with a clear face, readable silhouette, consistent outfit, strong posture language, and expressive emotional range.
VISUAL MEDIUM:
[STYLE TYPE], premium animation concept art, cinematic character study, clean artbook layout.
BACKGROUND:
Pure white / soft off-white background.
No environment.
No logo.
No watermark.

DESIGN DIRECTION:
Do not create a standard technical character reference sheet.
Create a cinematic identity board that feels like a high-end animation studio character study mixed with an artbook layout.
The layout should be asymmetrical, elegant and visually memorable.
Use large empty space, varied image scale and intentional imbalance.
Avoid rigid grid layout, blueprint design, catalog layout, repetitive turnaround presentation, or crowded composition.

IMPORTANT LAYOUT RULE:
Do not overlap any character images.
Every pose and view must have clear separation and breathing room.
Keep all bodies, portraits, silhouettes and detail studies visually distinct.
No cropped faces.
No hidden limbs.
No stacked figures.
No merged poses.
No duplicated unreadable bodies.
MAIN COMPOSITION:
Place one large hero full-body view slightly off-center as the visual anchor.
Around it, arrange smaller supporting studies with clean spacing:
neutral full-body view,
back view,
profile view,
seated pose,
leaning pose,
crouching pose,
top-down body angle,
low-angle body angle,
2–3 expressive portrait studies.
Each view should feel like a separate clean character study, not a frame from one scene.
IDENTITY LOCK:
Preserve strict identity consistency across all views:
same face,
same facial proportions,
same hairstyle,
same outfit,
same body proportions,
same posture language,
same visual personality,
same age range,
same color logic,
same silhouette.

CHARACTER DETAILS:
Name: [CHARACTER NAME]
Role: [CHARACTER ROLE]
Core mood: [CORE MOOD]
Visual signature: [VISUAL SIGNATURE]
The character must have:
[DESIGN TRAIT 1],
[DESIGN TRAIT 2],
[DESIGN TRAIT 3],
[DESIGN TRAIT 4],
[DESIGN TRAIT 5],
[DESIGN TRAIT 6],
[DESIGN TRAIT 7],
[DESIGN TRAIT 8].
USEFUL REFERENCE DETAILS:
Make the character readable for future image and video generation:
clear face shape,
clear hair silhouette,
clear outfit silhouette,
clear body shape,
clear hands,
clear footwear,
clear posture,
clear expression range,
clear costume layers,
clear color separation.

ARTISTIC SECTIONS:
Include a small silhouette study area with 2–3 simplified black character silhouettes.
Include a small expression study area with subtle emotional variations.
Include a small detail study area showing key visual features of the face, hair, outfit, hands, accessories and footwear.
TEXT DESIGN:
Add one stylish CHARACTER ID block.
Keep it minimal, bold and art-directed.
Use only:
NAME
ROLE
CORE MOOD
VISUAL SIGNATURE
Use small handwritten-style labels only where helpful.
Subtle editorial arrows and annotation marks are allowed, but keep them minimal and elegant.

STYLE:
[STYLE DESCRIPTION],
minimal,
cinematic,
premium,
artbook-like,
clean,
expressive,
high readability,
useful for production,
strong silhouette clarity,
consistent character identity.
NEGATIVE RULES:
No environment.
No action scene.
No fight scene.
No random props unless specified.
No alternate costumes.
No redesign between poses.
No inconsistent face.
No inconsistent hairstyle.
No inconsistent body proportions.
No logo.
No watermark.
No messy layout.
No overlapping figures.
The final image should feel like an artistic character identity board designed to help an AI model understand the character’s face, silhouette, outfit, posture, movement language and emotional range.
```
