# VTuber 风格烹饪直播视频

*VTuber Style Cooking Live Video*

> 一份全面的提示词，用于生成带有 VTuber 风格角色叠加层和黑椒牛肉真实烹饪画面的烹饪解说视频。

## 提示词（日本語）

```text
参照画像のキャラクターを VTuber 風のライブ実況アバターとして使用してください。緑色のポリゴンマスク、黒い縁取り、細い目、黒い眉、大きな紫色の舌、白い頭部、黒い服という印象を維持してください。キャラクターは画面右下に小さな 2D/Live2D スタイルのストリーマーアバターとして重ね合わせ、背景の調理映像を邪魔しないように配置します。アバターは上半身のみを表示し、軽く上下に揺れながら、瞬き、リップシンク、表情の変化、ウィットに富んだコメントやリアクションを行います。動画は「青椒肉絲（ピーマンと牛肉の黒胡椒炒め）」の調理過程を示す料理実況です。メイン画面は実写またはシネマティックな調理映像とします。まな板の上でピーマン、タケノコ、牛肉（または豚肉）を薄切りにする様子を映します。包丁の音、油が跳ねる音、中華鍋を振る音、食材を炒めるリアルな音を含めてください。調理工程は、肉の下味付け、片栗粉のコーティング、ピーマンとタケノコのカット、強火での肉の炒め、野菜の追加、オイスターソース・醤油・酒・砂糖での味付け、そして最後にツヤが出るまで炒めて盛り付ける流れです。画面レイアウトはゲームや料理配信のスタイルにします。メインの調理映像をフルスクリーンにし、VTuber アバターを右下に固定します。左上に小さな「COOKING LIVE」風の UI を表示しても良いですが、実在のサービスロゴは使用しないでください。字幕やコメントを入れる場合は、架空の UI として控えめに配置します。不要な場合は UI は不要です。アバターのセリフ：「みんな、今日は青椒肉絲を作るよ」「まずはピーマンを薄切りに。ここで雑になるとすべてが台無しだからね」「肉に下味をつけて、片栗粉で旨味を閉じ込める。これが地味に重要」「中華鍋は強火が命。この音だけで勝ったも同然だね」「ピーマンを入れた瞬間、一気に料理らしくなるね」「オイスターソースを入れるのは鉄板。この香りは反則だよ」「完成！ 白米、逃げないで待っててね」。アバターのリアクション：カットが完璧に決まったら目を細めて頷く。強火で炒める時は少し身を乗り出して興奮気味にリップシンクする。ソースを加えて湯気が上がると、紫色の舌を強調して驚き、「これ美味しそう」と言う。完成時には右下で小さく拍手し、満足げに頷く。動画スタイル：高品質な料理映像、清潔なキッチン、自然光または温かみのある照明。食材の色を鮮やかに見せる。油の照り、湯気、ソースのツヤ、ピーマンの緑を強調する。カメラは手元のアップ、真上からの調理面ショット、中華鍋のローアングルショット、盛り付けのアップを切り替える。VTuber アバターは常に右下に固定し、サイズと位置を一定に保つこと。調理映像を遮らないようにする。禁止事項：キャラクターの顔やマスクのデザインを変更しないこと。舌の色を変更しないこと。別のキャラクターに変えないこと。アバターを実在の人物にしないこと。実在の配信サービスのロゴを使用しないこと。調理工程を大幅に省略しないこと。手とアバターが不自然に重ならないようにすること。途中で食材が別の料理に変化しないこと。完成品は、薄切り肉、ピーマン、タケノコ、茶色のツヤのあるソースが特徴の青椒肉絲であると明確に認識できること。
```
