# 电影感动漫动作序列

*Cinematic Anime Multi-Attack Sequence*

> 一个高度精细的日式动漫风格动作提示词，主角是一位拥有淡紫色头发的角色，在星象宫殿中与多名敌人进行电影般的战斗。

## 提示词（日本語）

```text
[メタデータ]
尺：15 秒
テンポ：約 128 BPM
構成スタイル：シネマティックな連続攻撃フィニッシュ / エクストリーム・クローズアップとワイドショットの交互切り替え
カット数：12 カット
クオリティ：劇場版アニメスタイル / 超ハイエンド / 4K / 劇場版アニメ、高精細、シネマティックライティング、レイトレーシング、芸術的な構図、ドラマチックな被写界深度、ローアングル・アクション撮影、誇張された遠近法、制御されたモーションブラー、正確な人体構造、手足の重複なし。

[衣装 / 主人公]
@[image1] を使用して完全に固定。主人公はラベンダー色のツインお団子ヘア、紫色の瞳、小柄でちびキャラのような体型。黒と紫を基調とした星の飾りがついたドレス風のコート、リボン、金の装飾、紫と黒の縁取りのソックス、紫色の靴を着用し、全カットで一貫させること。顔立ち、髪型、衣装、装飾、色、シルエットは決して変更しないこと。

[身体の一貫性ルール]
主人公と敵は常に自然な人体構造を維持すること。腕と脚は必ず左右 1 本ずつ。高速回転、キック、ジャンプ、着地、宙返りの最中であっても、脚が増えたり、腕が重複したり、足が分裂したり、物理的な残像が発生したりしないこと。モーションブラーは身体の外側に薄く流れる程度に留めること。すべての攻撃は、骨盤の回転、肩のひねり、ステップ、重心移動に基づいていること。

[世界観]
星読みの貴族が遺した廃墟の宮殿。巨大な円形ホール、アメジストの柱、金細工の階段、星座模様の大理石の床、壊れた天窓から差し込む月光、舞い上がる塵、背景には機械式の天球儀。背景は、主人公の黒紫と金の衣装に合わせ、冷たい青紫の月光と金属的な反射で統一されていること。

[敵]
仮面をつけた複数の処刑人が、様々な方向から絶え間なく攻撃してくる。長身で黒灰色の戦闘服を着用し、銀色の仮面をつけ、短剣や警棒を所持している。主人公とは完全に差別化し、同じキャラクターに見えないようにすること。

[ムード]
最初は、包囲された静かな緊張感。主人公は腕を組み、無表情で眠たげな視線を向けた後、瞬時に加速する。フィナーレは、敵を空中に吹き飛ばす宙返りキックで、何事もなかったかのように軽やかに着地する。

[音楽]
低いドローン音、鋭い和太鼓風のパーカッション、金属的なクリック音。各攻撃に合わせて短いヒット音を入れる。最後の宙返り直前に一瞬の静寂、キックと同時に弦楽器が鋭く高まり、着地と同時に音が即座に消える。

[カメラ / 演出]
エクストリーム・クローズアップとワイドショットを極端に交互に配置。クローズアップでは目、口、靴の裏、リボン、衝撃の瞬間を誇張する。ワイドショットでは、複数の敵との位置関係と空間全体を明確に示す。ローアングル、魚眼レンズのような誇張されたパースペクティブ、ドリーイン、スピードランプ、マッチカットを多用する。

カット 1：0.0-1.3 秒 / ワイド。廃墟の宮殿の円形ホール中央、主人公が腕を組んで無表情で立っている。8 人の仮面の処刑人に半円状に囲まれている。天窓からの月光が、紫の髪と金の星の飾りを縁取っている。カメラは超ローアングルからゆっくりと旋回し、空間の広大さと包囲の様子を見せる。

カット 2：1.3-2.2 秒 / エクストリーム・クローズアップ。主人公の半開きの紫色の瞳。瞳の中に近づいてくる敵の影が映り込む。口元がわずかに苛立ちで歪む。リボンの星の飾りがわずかに揺れ、完全な静寂の瞬間が訪れる。

カット 3：2.2-3.4 秒 / ワイド。主人公は右前方からの警棒による一撃を最小限の動きで回避し、横を向く。小さな体を沈め、ステップと同時に腹部へ前蹴りを叩き込む。敵は大理石の床を滑っていく。カメラはキックの軌道に合わせて水平にドリー移動する。

カット 4：3.4-4.3 秒 / クローズアップ。靴の紫色の裏が画面いっぱいに迫る。靴の金の装飾が輝き、衝撃の直前に短いスピードランプがかかる。敵の仮面の端が衝撃波で震える。モーションブラーは薄く、片脚のみが鮮明に映る。

カット 5：4.3-5.7 秒 / ワイド。2 人の敵が左から同時に攻撃。主人公は 1 人目の腕をパリィし、回転しながらサイドキックで膝を崩す。続けて後ろの敵に肘打ちを食らわせ、肩のカウンターで柱に押し付ける。カメラは円形レール上で 360 度回転する。

カット 6：5.7-6.8 秒 / エクストリーム・クローズアップ。主人公の小さな手が敵の袖を掴む。金の星のチャームが鋭く揺れる。生地のシワ、指先の力、敵の重心が崩れる瞬間を極端なクローズアップで描写。背景は強い被写界深度で溶けている。

カット 7：6.8-8.2 秒 / ワイド。主人公は敵の腕を引き寄せ、足払いで 1 人を転倒させる。倒れた敵を足場にして低く飛び上がり、回転しながら別の敵の肩にヒールドロップを叩き込む。小柄な体格ながら鋭い重量感。カメラは床レベルから見上げ、誇張されたパースペクティブで靴と敵の距離を強調する。

カット 8：8.2-9.2 秒 / クローズアップ。回転による遠心力で、主人公のお団子ヘアとリボンが遅れて柔らかく流れる。半開きの目の表情は変わらない。背後を敵の短剣が切り裂き、鋭い金属音だけが響く。

カット 9：9.2-10.7 秒 / ワイド。背後から迫る大柄な処刑人に対し、主人公は回転しながら胸部にバックキックを叩き込む。着地と同時に膝を引き、低い姿勢から別の敵の顎に掌底を打ち込む。星座模様の床に敵が次々と倒れる。カメラは一気に引き、一連の処理の全貌を見せる。

カット 10：10.7-11.8 秒 / エクストリーム・クローズアップ。最後の大柄な敵の足が床を砕く。次のカットで主人公の紫色の瞳、続いて靴の先に高速で切り替わる。主人公は低く沈み込み、宙返りの予備動作に入る。音楽が一瞬止まり、髪飾りの星だけが輝く。

カット 11：11.8-13.5 秒 / ドラマチックなワイド + スローモーション。最後のアクション。主人公が地面を蹴り、完璧で美しい弧を描いて宙返りキックを放つ。紫色の靴の先が、下から正確に強敵の顎を捉える。月光を背にしたシルエットで、スカートとリボンが円形に広がる。敵は垂直に吹き飛び、背後の天球儀の光と重なる。回転中も左右の脚 2 本のみを厳密に維持し、人体構造を保つ。

カット 12：13.5-15.0 秒 / 望遠レンズによる引き。主人公は片足で軽やかに着地し、すぐに両足を揃える。再び腕を組み、半開きの目のまま小さく息を吐く。周囲の敵が遅れて崩れ落ち、アメジストの塵が月光に舞う。カメラは望遠レンズでゆっくりと引き、廃墟の宮殿の広大な静寂と、主人公の小さくも圧倒的な存在感を残したままフェードアウトする。
```
