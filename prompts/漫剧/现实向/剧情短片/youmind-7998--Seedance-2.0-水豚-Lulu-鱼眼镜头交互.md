# Seedance 2.0 水豚 Lulu 鱼眼镜头交互

*Seedance 2.0 Capybara Lulu Fisheye Interaction*

> 一份详细的 Seedance 2.0 技术提示词，旨在通过鱼眼镜头将 2D 动漫贴纸角色与现实环境融合，创作一段视频。

## 提示词（中文）

```text
[基础设置] 生成一段 10 秒的 9:16 竖屏幽默视频。将真实的住宅区环境与 Q 版扁平 2D 动漫贴纸角色进行合成。固定鱼眼镜头，一镜到底，无剪辑、转场或缩放。无音乐或 UI。[核心情节] 水豚 Lulu 跑到门柱前。听到“请刷脸”后，它抱住柱子并将脸贴近鱼眼镜头。在两次尝试失败并出现“识别失败”提示后，它表现出困惑并更加努力地尝试。[场景] 现代住宅入口，自然日光，右侧为绿色柱子。无其他行人或车辆。[摄像机] 模拟固定鱼眼镜头，带有桶形畸变和暗角。角色面部靠近时占据画面的 70-85%。[角色] 水豚 Lulu：Q 版拟人化卡通水豚，黄色圆润身体，穿着橙色短裤，戴着黄色围兜，头上顶着一个橙子。[风格] 纯扁平 2D 贴纸风格，带有深色轮廓线，无 3D 质感。[构图] Lulu 从右侧远处跑到柱子旁，根据系统语音提示与镜头交互。[时间轴] 跑到门口 -> 等待扫描 -> 抱住柱子并贴脸 -> 第一次失败并缩回 -> 第二次尝试并失败。[声音] 环境住宅噪音、脚步声，以及清晰的中文机械系统语音：“请刷脸”和“识别失败”。[强制约束] 保持 2D 风格一致，接地稳定，与柱子的遮挡关系正确，并与语音同步。[负面提示词] 写实动物、3D CG、毛发质感、镜头移动、背景音乐或角色变形。
```
