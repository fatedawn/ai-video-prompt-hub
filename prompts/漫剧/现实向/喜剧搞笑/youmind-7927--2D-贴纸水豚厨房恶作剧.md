# 2D 贴纸水豚厨房恶作剧

*Capybara Sticker Cooking Comedy*

> 一个为 Seedance 2.0 设计的混合媒体视频提示词，结合了写实的第一人称厨房视角与 2D 动画水豚贴纸角色，演绎一场撒盐恶作剧。

## 提示词（中文）

```text
真人实拍 + 2D 动漫贴纸合成趣味短视频 [风格] 真人实拍 + 平面 2D 贴纸合成趣味短视频。第一人称烹饪视角，写实的厨房质感与扁平的卡通贴纸风格形成强烈对比。整体为真人实拍 + 平面 2D 卡通贴纸的混合效果。画面为真实的厨房拍摄，角色为 Q 版卡通形象，全程保持纯粹的 2D 平面贴纸质感。8K 超清，竖屏，轻微手持晃动，节奏明快、笑点直接的短视频。 [时长] 10 秒 [比例] 9:16 竖屏 I. 场景设定 [场景] 真实的家庭厨房第一人称视角。炉灶上放着一口黑铁锅，锅里正在翻炒牛肉和青菜，油花滋滋作响，蒸汽升腾。背景包括：白色瓷砖墙、墙壁插座、靠墙摆放的酱油和油瓶、右侧的不锈钢水槽，侧面窗户透进自然光。要求：整体环境要真实且有生活气息，厨房质感要可信，不能变成卡通厨房。镜头为第一人称 POV，轻微手持晃动，但不能过于杂乱。 II. 角色设定 [角色] Q 版动漫贴纸角色：水豚 Lulu。设定要求：圆润可爱的拟人化卡通水豚，站在画面中下部，高度约为铁锅的一半，平面 2D 贴纸质感，明显的卡通线条，强烈的纸质感，不能变成三维写实动物，不能被真实环境光重塑为写实的 3D 光影。外观锁定：浅黄色身体，穿着橙色短裤，脖子上系着黄色小围裙，头顶一颗小橙子，四肢短爪圆润如豆，头脸占比大，整体像一个软萌的纸贴纸角色。角色性格：平时禅意慵懒，但非常擅长捣乱，表情调皮，恶作剧感强。 [真人部分] 真人手部为写实风格，从画面右侧入镜。要求有真实的皮肤细节，可见毛孔，与 2D 角色形成鲜明对比。 III. 镜头设计 [镜头 1 | 00:00–00:03] 盐崩开场 [镜头] 第一人称俯视 POV [画面动作] 真人手部正用锅铲在锅中翻炒牛肉和青菜。水豚 Lulu 坐在炉灶旁的小木凳上，眯着豆豆眼，脸红加深，嘴角勾起调皮的坏笑。它用两只短爪举起一个比头还大的玻璃调料罐，趁真人翻炒时，将整罐白盐倒入锅中。盐应像真实的瀑布一样倾泻而下，清晰地落入锅中，并在蔬菜上堆积成夸张但可见的“小白盐山”。 [角色表情] 豆豆眼眯起，调皮坏笑，恶作剧成功。 [音效] 食物滋滋声，盐倒入锅中的密集沙沙声。 [本镜头唯一主要动作] 水豚 Lulu 将整罐盐倒入锅中。 [镜头 2 | 00:03–00:05] 锅铲敲头 [镜头] 保持第一人称近景 POV [画面动作] 真人手部迅速从它怀里夺走玻璃盐罐。另一只手举起锅铲，用平整面轻轻敲了一下水豚 Lulu 的头顶。注意这是卡通式的轻敲，而非写实的暴力感。敲击后，它头上立刻弹出一个明显的红色卡通大包。它整个圆滚滚的 2D 贴纸身体剧烈上下晃动，两只短爪立刻抱住头，豆豆眼瞬间瞪大。 [角色表情] 震惊、委屈、懵圈一瞬。 [音效] 锅铲“Duang”的一声，轻微金属碰撞声，卡通弹簧音效。 [本镜头唯一主要动作] 真人用锅铲敲它的头顶。 [镜头 3 | 00:05–00:08] 哭泣与投喂 [镜头] 第一人称近景 POV，聚焦角色脸部与锅沿 [画面动作] 水豚 Lulu 捂着头上的红肿大包，豆豆眼瞬间变成旋转的蚊香眼。它张大嘴巴“嗷嗷”大哭，蓝色的卡通眼泪像喷泉一样夸张地从两侧喷出。头顶的小橙子也随着哭泣颤抖。与此同时，真人手部立即用锅铲从锅里的盐山中铲起满满一勺“白盐混合咸菜”，在它哭泣时精准地塞进它嘴里。它的嘴瞬间被塞满，左右脸颊像两个半球一样鼓起。 [角色表情] 蚊香眼，哭泣，被塞满嘴后的震惊呆滞。 [音效] 夸张的卡通哭声，铲盐的沙沙声，塞入嘴里的“啵”声。 [本镜头唯一主要动作] 真人在它哭泣时将一勺咸菜塞进它嘴里。 [镜头 4 | 00:08–00:10] 咸味 K.O. 结尾 [镜头] 第一人称固定近景，最终定格 [画面动作] 水豚 Lulu 脸颊通红，被迫咽下嘴里的盐。瞳孔突然缩成两个小点，浅黄色的身体瞬间变白了一个色号，整个角色僵硬并抽搐了半拍。随后，豆豆眼变成两个“X”，身体直挺挺地从木凳上向后倒去，四脚朝天平躺在炉灶上。一只短爪在空中无力地划拉一下后垂下。一圈旋转的小星星缓慢绕着头顶的红肿大包转动。一缕灵魂状的白烟从它方形鼻头前缓慢飘出。画面定格在它“咸到升天”的瞬间。 [音效] 僵硬的“哐当”声，向后倒下的“咚”声，轻微卡通升天音效结束。 [本镜头唯一主要动作] 水豚 Lulu 被咸到后向后倒下。 IV. 执行要求 [视觉要求] 厨房环境必须真实写实。水豚 Lulu 必须始终保持纯粹的 2D 贴纸感。2D 角色与真实的厨房、真实的人手形成强烈对比。不要将水豚 Lulu 做成 3D 写实毛绒动物。不允许角色受到复杂的写实光影影响。角色轮廓始终清晰，就像贴在实拍素材上的卡通贴纸。 [动作要求] 每个镜头只保留一个主要动作。动作节奏要短、平、快。角色表情夸张，但动作逻辑清晰。盐、锅铲、蒸汽、倒下应有明确的物理反馈。 [表演要求] 水豚 Lulu 的捣乱感要强。真人不露全身，只露手部。真人的反应要干脆，像熟练处理捣乱者一样。整体为无对白喜剧，无需角色说话。 [镜头要求] 全片保持第一人称 POV，轻微手持晃动，不要切换到第三人称视角，不要添加无关角色，结尾定格要干脆。 V. 负面词汇 模糊，质量差，低质量，低分辨率，噪点，JPEG 伪影，水印，字幕，文字，Logo，错误；变形，变异，解剖结构错误，多余肢体，断手，毁容，构图糟糕，出画；写实动物毛发，3D 写实水豚，贴纸角色上过度的渲染光影，角色不一致，换装，变色，更换头饰；背景偏移，道具消失，厨房连续性破坏，物体漂浮，POV 错误，多余人员，多余手部，剪辑故障
```
