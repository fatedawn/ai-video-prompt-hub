# 动漫“愤怒值”恶搞梗

*Anime Anger Meter Gag*

> 一个高质量的 2D 动漫动画提示词，用于日本教室背景下的喜剧“愤怒值”恶搞梗。

## 提示词（日本語）

```text
[動画スタイル]
15 秒間。日本のアニメ風フルカラー映像。5 億円規模の予算を想定した高密度な 2D アニメーション。緻密な背景美術、滑らかな中割り、映画品質のポストプロセッシング。構図、カメラアングル、画面サイズ、キャラクターとの距離を変化させ、視覚的な単調さを避けて魅力的に展開すること。字幕なし、ウォーターマークなし、BGM なし。環境音は含めること。

[視覚構成] 主人公の頭上に「怒り」メーターが出現し、前の席の人物の言動によって針が上昇する。針は限界を超えて一周し、メーターが火花を散らして爆発する。主人公は驚くほど静かなままで、そのギャップが笑いを誘う。メーター上のテキストはすべて正しい日本語で表記すること。

[ハイライト（ショット 5 ～ 7 に必ず含めること）] 爆発した針が黒板に突き刺さり、ちょうど「怒」という漢字の総画数を指し示し、授業へと切り替わる。

ショット 1（メーターの導入）：放課後の教室。主人公の頭上に「怒り」メーターが浮かび、針がゆっくりと上昇し始める。主人公の眉がピクリと動く。
ショット 2（原因）：前の席の人物が話したり動いたりするたびに、針が跳ね上がる。主人公の笑顔が引きつり始める。
ショット 3（警告）：メーターが赤く点滅し、小さな警告音が鳴る。周囲の人が気づき始める。主人公は必死に笑顔を保とうとする。
ショット 4（我慢）：主人公は笑顔のままだが、針は限界の一歩手前で震えている。こめかみに汗をかき、目だけが笑っていない。
ショット 5（限界突破）：針が限界を超えて一周する。メーターのガラスにひびが入る。主人公の笑顔が完全に凍りつく。
ショット 6（爆発）：メーターが火花を散らして爆発する。部品が紙吹雪のように舞い散る。主人公は呆然とした表情で立ち尽くす。
ショット 7（再起動）：頭上に新しいメーターが再び現れる。主人公が呆然と「測定不能と言われた」とつぶやく。
```

```text
[视频风格]
15 秒。日本全彩动漫。5 亿日元预算级别的超高密度 2D 动画。精细的背景美术、流畅的中间帧以及电影级的后期处理。通过变换构图、摄像机角度、画面尺寸和角色距离来提升吸引力，避免视觉重复。无字幕，无水印，无背景音乐。包含环境音。

[视觉构图] 主角头顶出现一个“愤怒”仪表，指针因前方的人而上升。指针超过极限并转满一圈，仪表伴随火花爆炸。角色保持惊人的安静，形成喜剧反差。仪表上的所有文字均为正确的日语。

[高光时刻（必须包含在第 5-7 镜头中）] 爆炸的指针扎入黑板，精准指向汉字“怒”的总笔画数，并以此过渡到课堂教学。

镜头 1（仪表引入）：放学后的教室。主角头顶浮现一个“愤怒”仪表，指针开始缓慢上升。主角的眉毛抽动了一下。
镜头 2（起因）：每当前方的人说话或行动时，指针就会跳动。主角的笑容开始抽搐。
镜头 3（警告）：仪表闪烁红光并发出轻微的警告蜂鸣声。周围的人开始注意到。主角拼命试图维持笑容。
镜头 4（忍耐）：主角依然保持微笑。然而，指针在极限边缘颤抖。太阳穴流汗；只有眼睛没有在笑。
镜头 5（突破）：指针超过极限并转满一圈。仪表玻璃出现裂纹。主角的笑容彻底僵住。
镜头 6（爆炸）：仪表伴随火花爆炸。零件像纸屑一样飞散。主角露出呆滞的表情。
镜头 7（重启）：一个崭新的仪表再次出现在头顶。主角呆呆地说：“他们告诉我这无法测量。”
```
