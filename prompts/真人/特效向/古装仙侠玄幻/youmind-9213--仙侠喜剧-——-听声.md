# 仙侠喜剧 —— 听声

*Xianxia Comedy - Hearing a Sound*

> 一部以精致古风仙侠美学为核心的喜剧电影短片提示词，展现一场因误解引发的剑术对决挑战，强调自然的人物表演与默片喜剧节奏。

## 提示词（中文）

```text
电影级写实感，正宗古风仙侠美学。
整体风格：高级冷幽默，优雅清晰的武侠动作调度，默片式的反应节奏，社交尴尬带来的幽默感，以及克制的荒诞感。
视觉质量：Arri Alexa 电影质感，清晰稳定的面部微表情，细腻的胶片颗粒感，自然的体积光。
该喜剧片段的核心结构必须严格遵循：史诗般的期待 → 自信但完全错误的理解 → 极其平凡的真相 → 权威人物画龙点睛。

幽默逻辑吸收了“假装听懂、礼貌回应、听而不闻随机应变”的机制，并将其完全转化为古风人物的行为模式。

II. 参考控制
1. 角色锚点：@Image 1 严格锁定角色 ID A（剑修师姐）。@Image 2 严格锁定角色 ID B（小师妹）。
2. 环境：使用上传的背景参考图来确定统一的环境 DNA，包括地形、建筑语言、空间尺度、纹理、植被、水体、天气和光照方向。不要机械复制；保持环境的新鲜感、真实感与连贯性。

III. 角色设定
角色 A（剑修师姐）：25-30 岁，冷静、克制、庄重，严肃得近乎刻板。她的笑点不在于轻浮，而在于“真诚地做出完全错误的解读”。
角色 B（小师妹）：20-25 岁，聪明、反应快，克制但意识到荒诞感。她的笑点在于“比任何人都更快意识到事情的荒谬”。
配角：敌对宗门宗主（庄重傲慢）、长老（稳重沉着）及弟子们。

IV. 核心分镜（0-15 秒）
0-5 秒 | 全景：敌方宗主发出一场庄重且节奏紧凑的生死挑战。白衣师姐认真聆听并点头一次。众人以为对决已定。
5-10 秒 | 中景：敌方精神上大获全胜。师姐自然地转向小师妹问：“他刚才说了什么？”全场死寂。她解释说只是因为对方说了太久，她必须给个回应。
10-15 秒 | 特写：敌方被冒犯并询问对决是否作数。师姐说：“不，我只是表示我还在听。”小师妹强忍笑意。长老庄重地补充道：“至少她非常有礼貌。”精准黑屏。
```
