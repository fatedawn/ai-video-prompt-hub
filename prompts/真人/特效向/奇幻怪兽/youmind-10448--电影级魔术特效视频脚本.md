# 电影级魔术特效视频脚本

*Cinematic Magic Trick Video Script*

> 一份详尽的导演级提示词，用于生成高质量魔术表演视频，展示巴洛克舞台上的专业丝绸快换特效。

## 提示词（中文）

```text
时长：18 秒
比例：9:16
参考：魔术师 = @，身着纯黑色燕尾服、白衬衫、黑色领结；女演员 = 一位 20 岁左右的年轻美女，留着棕色长波浪卷发，身穿修身亮红色亮片吊带礼服，高开叉设计，搭配金色高跟鞋；两位角色的外貌和服饰在整个视频中保持严格一致。
音频：大剧院混响；高速红绸运动带来的持续风声；垂直丝绸升起的魔幻呼啸声；女演员出现时观众雷鸣般的欢呼和掌声；无对白、无旁白、无音乐、无字幕。
整体风格：8K 超写实剧院舞台纪录片风格，高对比度专业舞台聚光灯，逼真的丝绸物理效果，隐形身体重组魔术奇观，无动漫或低质量 CG 特效。

全局连贯性
场景：欧洲古典巴洛克剧院舞台，配有深红色天鹅绒幕布。道具包括复古镀金烛台和雕花道具桌。深色硬木地板反射光线。可见前排观众剪影。
主体：魔术师作为操控者，女演员作为搭档。身体比例、面部特征和服装质感保持一致。
道具：高密度、高光泽红色宽幅缎面丝绸，垂坠感极佳。
动作引擎：从礼服中抽出丝绸 -> 螺旋缠绕并消失 -> 像瀑布一样向上拉动丝绸 -> 丝绸聚集成茧 -> 茧破裂显现出女演员 -> 最后鞠躬。
镜头连贯性：模拟前排手持视角，中景全景，一镜到底，带有自然的对焦锁定和呼吸感抖动。
负面提示：服装改变、肢体重复、场景切换、卡通渲染、闪烁、水印。
```
