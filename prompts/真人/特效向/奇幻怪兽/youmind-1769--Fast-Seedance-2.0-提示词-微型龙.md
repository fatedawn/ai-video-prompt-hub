# Fast Seedance 2.0 提示词：微型龙

*Fast Seedance 2.0 Prompt for a Miniature Dragon*

> 一个详细的提示，用于生成一段视频：一只微型、虹彩的龙，眼睛发光，紧紧抓住一条深灰色运动裤，并喷射出铺满屏幕的巨大火焰流。该提示要求高质量、8K 超高清、电影级灯光、与参考图像精确匹配的定位、流畅的 24fps 动态运动，并且没有抖动或跳帧。参考图像在评论中提及。

## 提示词（中文）

```text
杰作，最佳品质，8K 超高清，照片级真实感，电影级布光，与参考图完全一致，一只超微型珠光虹彩小龙，金色发光的大眼睛，带有细小的闪烁鳞片，小小的尖角和半透明的翅膀，前爪紧紧抓住深灰色运动裤的裤腿，位置与参考图完全一致，活泼好玩的状态，身体和尾巴自然摆动，头部面向镜头，向屏幕喷射出巨大的、充满画面的凶猛火焰洪流，火焰几乎覆盖整个画面，具有极强的视觉冲击力和热浪扭曲效果，火焰动态流畅连贯，室内场景，人物服装和灯光氛围与参考图完全一致，主体清晰不模糊，24fps 流畅动态，画面无抖动，无跳帧，无崩溃。
```
