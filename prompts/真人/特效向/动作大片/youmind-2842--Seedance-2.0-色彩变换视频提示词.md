# Seedance 2.0 色彩变换视频提示词

*Seedance 2.0 Color Transformation Video Prompt*

> 一个用于生成 15 秒高质量真人风格特效短片的 Seedance 2.0 提示词。核心概念是一位年轻女性通过滑动浮动 UI 色轮，实现场景和服装的无缝切换。提示词详细说明了角色特征、带有时间戳的场景与动作逻辑，以及确保平滑过渡和情感一致性的特殊控制指令。

## 提示词（中文）

```text
生成一部 15 秒高质量真人风格特效短片，主要展示一位年轻女性通过滑动浮动 UI 色轮，实现场景和服装的无缝、平滑切换。注意镜头构图和转场节奏。画面必须具备出色的景深效果，且角色面部清晰，光影立体。 [角色特征锁定] 全程锁定核心角色特征：年轻女性，标志性的金黄色短发，佩戴圆形金属框眼镜。 [镜头构图与动作设计] 00:00-00:05：室内卧室夜景，背景为暖黄色星形光斑串灯。角色头发微盘，身穿浅米色长袖居家睡衣，坐在床上。一个完整的半透明渐变色轮（UI 交互元素）悬浮在屏幕正前方。角色对着镜头微笑，自然地伸出手，将发光的色轮向右滑动。 00:05-00:07：随着色轮转动，无缝切换至明亮的室内窗边日景，伴有暖阳。角色短发自然垂下，瞬间换成鲜艳的亮橙色无袖紧身上衣和白色休闲裤，单手托腮，笑容灿烂。色轮悬浮在屏幕右侧，光标高亮显示黄橙色区域。 00:07-00:09：无缝切换至户外公园日景，背景为高曝光的翠绿树木。角色靠在粗壮的树干上，换成薄荷绿方领泡泡袖短款上衣和浅色高腰短裤，右手戴着黑色半指皮手套，对着镜头俏皮眨眼，手指轻触嘴唇。色轮悬浮在右侧，光标高亮显示亮绿色区域。 00:09-00:11：无缝切换至开阔的户外草地，背景为蓝天白云。角色靠在灰白色混凝土矮墙上，身穿简约的深蓝紫色细肩带上衣，单手托下巴，表情慵懒酷飒。色轮移至屏幕左侧，光标高亮显示深紫色区域。 00:11-00:13：无缝切换至阳光明媚的户外樱花林，背景是盛开的粉色樱花。角色换成粉色细肩带上衣，单手轻触头顶发丝，露出甜美治愈的笑容。色轮悬浮在左侧，光标高亮显示粉色区域。 00:13-00:15：无缝切换至传统户外中式建筑前，背景为虚化的红色柱子和古建筑檐角。角色身穿深红色焦糖色调露肩改良中式旗袍上衣（带有传统盘扣），姿态优雅大方，单手置于锁骨处，双眼微微下垂看向镜头。色轮悬浮在左侧，光标高亮显示红色区域。 [特殊控制指令] 必须确保每一次场景和服装切换都平滑无缝（smooth transition），保持角色动作的连贯性。在每次切换过程中，角色的情绪和微表情必须与当前服装色彩氛围完美匹配。视频可自动生成带有轻科幻 UI 音效和动态节奏的背景音乐，以配合色彩切换。
```
