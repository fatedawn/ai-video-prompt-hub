# 武侠剑阵逻辑喜剧

*Wuxia Sword Array Logic Comedy*

> 一个电影感武侠喜剧提示词，讲述了一位小师妹利用字面逻辑绕过传统剑阵，让对手陷入绝望的故事。

## 提示词（中文）

```text
核心定位：电影级写实质感，纯正古典中国仙侠美学。整体基调：高级冷幽默，优雅清晰的武侠角色调度，视觉误导，以及不断升级的逻辑荒诞感。视觉质量：Arri Alexa 质感，稳定的面部细节，自然的体积光。

喜剧结构：庄重挑战 → 荒诞捷径 → 语义反杀 → 权威终结。

叙事逻辑：
1. 严肃挑战：敌方阵法大师要求他们在与其对决前先破掉他的基础剑阵。
2. 荒诞捷径：小师妹直接沿着阵法边缘走到他身边，提出不破阵直接开打。
3. 反杀：当被指责“作弊”是邪修时，她欣然接受并将其视为赞美。
4. 权威终结：大师裁定规则是破阵才能对决，但并未禁止完全不打。随后她收剑离场。

角色 ID 和调度与白/绿汉服原型保持一致。
```
