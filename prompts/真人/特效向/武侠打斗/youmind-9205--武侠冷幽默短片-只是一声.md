# 武侠冷幽默短片《只是一声》

*Wuxia Deadpan Comedy "Just a Sound"*

> 一份详尽的武侠风格冷幽默短片提示词，侧重于角色一致性以及基于误会展开的四幕式叙事结构。

## 提示词（中文）

```text
核心定位：电影级写实质感，纯正古典中国仙侠美学。整体基调：高级冷幽默，优雅清晰的武侠角色调度，默片式的反应节奏，社交尴尬式幽默，克制的荒诞感。视觉色调：Arri Alexa 电影质感，清晰稳定的面部微表情细节，细腻的胶片颗粒感，自然的体积光。

喜剧结构：史诗般的期待 → 自信但完全错误的理解 → 极其平庸的真相 → 权威的最终一击。

叙事逻辑：
第一阶段：史诗期待。敌方首领庄重且语速极快地发起挑战。所有人以为一场传奇对决即将展开。
第二阶段：自信误会。师姐严肃地点头，但实际上完全没听懂对方在说什么。
第三阶段：平庸真相。她转头问师妹对方说了什么，揭示出她点头仅仅是为了礼貌。
第四阶段：权威一击。师父总结道，至少她表现得非常有礼貌。

角色 ID A：师姐（白色刺绣丝绸汉服，高发髻，冷静，严肃，过度礼貌）。
角色 ID B：师妹（绿色麻布汉服，编发，机灵，敏捷，努力憋笑）。

场景细节：黄昏，古建筑，云雾缭绕的山峦，Arri Alexa 电影感，高动态范围。
```
