# 武侠情感剧《信任与尊严》

*Wuxia Emotional Drama "Trust and Dignity"*

> 一个以信任与身份为核心的电影感武侠剧 Prompt，讲述了一位师姐在面对外界对其师妹出身的偏见时，依然坚定站在师妹身边的故事。

## 提示词（中文）

```text
Seedance Prompt | 身份、信任与尊严 I. 核心定位 电影级写实画质，纯正中国古风仙侠美学。整体基调为克制且成熟的情感剧，运用：高级武侠角色调度、Arri Alexa 电影质感、清晰稳定的面部微表情、细腻的胶片颗粒感、自然体积光。核心反转围绕：身份、信任与尊严。外界试图用血统标签来定义一个人，而剑仙师姐真正做的是拒绝让这个标签决定师妹是谁。 II. 参考控制 1. 角色身份锚点：@Image 1 严格锁定角色 ID A：剑仙师姐；@Image 2 严格锁定角色 ID B：师妹。 2. 环境参考：所有新上传的背景和地点参考图共同决定单一的环境 DNA。在正式构图前，静默推演兼容的：真实地形、建筑语言、空间尺度、材质年代、植被、水体、天气、云层、山雾、主光源方向、反射关系、整体色调、大气深度及真实的移动路径。重新规划为一个独特、完整且统一的新空间。要求：不可机械复制单张参考图；必须保持相同的世界观身份；三个镜头共享一致的地理关系；空间逻辑清晰；视觉世界必须生动、可信且连续。 III. 环境原则 背景必须保持生动，但在叙事上完全中立。流水、浮动的雾气、摇曳的植物、变幻的云层和反射应自然运作。应存在远处的环境音。硬性要求：背景不能制造剧情、推动反转或解决角色冲突；它仅提供真实的空间存在感。 IV. 角色设定 角色 ID A | 剑仙师姐：同 @Image 1。25–30 岁东亚女性，鹅蛋脸，皮肤白皙，深邃杏眼，长发半束，配白玉发簪，身材高挑修长。固定装束：白色绣花丝绸汉服，银色腰封，玉佩，白布靴，单柄银色长剑。气质：冷静、克制、精准、言简意赅、情感表达细腻。在保护对方的同时，尊重对方的选择权。 角色 ID B | 师妹：同 @Image 2。20–25 岁东亚女性，圆脸活泼，黑发编辫，身材娇小。固定装束：蓝绿色亚麻汉服，深色腰带，木簪，黑布鞋，单柄深色钢剑。气质：聪慧、敏感、有尊严。在身份暴露时本能退缩。需要的是尊重和信任，而不是替她做决定。 配角：1. 敌方剑客（战败，跪地，提供外部压力/标签）；2. 年长师父（次要见证者，沉默，通过侧身让路表示认可）；3. 两名弟子（背景见证者，模糊处理，不抢戏）。 V. 核心叙事逻辑 第一幕：敌方揭露师妹手腕上的异族印记。世界试图用血统定义她。师妹本能后退半步。第二幕：师姐拔剑，看似质问或审判，实则站在了师妹身边。第三幕：她说：“我护的是她，而非她的血统。”她将选择权交还给师妹。师妹选择回到她身边，通过行动确认了身份与信任。 VI. 分镜脚本 0–5 秒 | 远景或全景：根据参考图选择合理的对峙区域。敌方指着印记：“她身负异族脉络，你竟还认她？”师妹后退。师姐缓慢拔剑。镜头要求：建立稳定的对峙，使印记清晰可见，展现拔剑的分量。 5–10 秒 | 中景或牛仔景：师姐从师妹身旁走过，将银剑剑尖向下插入敌方与师妹之间，并站在她身侧。她冷静地说：“我早就知道。”敌方：“知道还护着她？”她回答：“我护的是她，而非她的血统。”镜头要求：插剑动作必须是明确的立场宣示；动作要冷静稳重，不可矫情。 10–15 秒 | 特写或大特写：师妹问：“你不问我为何瞒着你吗？”师姐注视她的眼睛说：“我会问。”（停顿）“但等你愿意告诉我的时候。”她示意路径：“回不回去，你选。”师妹选择退回她身边：“那我们回去吧。”师姐露出一个细微的宽慰笑容并收剑。师父侧身让出路径。镜头要求：对话必须稳定；聚焦于选择和细微的笑容。 VII. 角色表演要求 师姐：克制，通过眼神和细微动作传达情感，言语简洁，拔剑作为立场而非威胁。师妹：因暴露而受伤，本能退缩，不歇斯底里，有意识地选择回归。敌方：代表外部偏见，虽败犹具攻击性。师父：沉默，存在感厚重，通过动作表示认可。 VIII. 动作与调度要求 清晰、简单、可读的动作：指印记、后退、拔剑、走过、插剑、示意选择、退回、收剑。原则：空间逻辑，无夸张的戏剧化表演，动作服务于角色关系及身份、信任与尊严的主题。 IX. 摄影要求 16:9 横屏，三个连续清晰镜头，Arri Alexa 质感，镜头稳定。远景用于对峙，中景用于立场，特写用于关系。自然的微细节、胶片颗粒、体积光，稳定的地理关系及自然的视差。 X. 声音要求 原生同步普通话对话，精准口型匹配，自然环境音（风声、水声）。极简背景音乐。包含关键对话锚点。 XI. 技术规格 时长：15 秒。比例：16:9。角色与背景全程一致。利用 Seedance 2.0 功能进行图像/音频/视频参考及表演控制。 XII. 负面标准 负面提示词：模糊、低画质、畸变、角色不一致、衣服变换、面部崩坏、背景位移等。
```
