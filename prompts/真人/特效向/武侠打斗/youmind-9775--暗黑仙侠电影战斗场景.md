# 暗黑仙侠电影战斗场景

*Dark Xianxia Movie Combat Scene*

> 一份全面的 8K 暗黑奇幻战斗电影级视频提示词，以竹林中黑发剑客与魔尊的对决为主题。

## 提示词（中文）

```text
生成一段 10 秒、8K 3D CG 写实风格、PBR 物理材质、16:9 横屏、60fps 的中国暗黑仙侠电影战斗视频。[月光下的怒江与无尽的翠绿竹林，天空中悬挂着一轮巨大的明亮满月]，电影级调色；衣物褶皱、皮肤毛孔、毛发动力学以及飞舞的竹叶均达到超写实效果，布料动态真实。[一位冷峻的黑发剑客，身着深色武侠服饰，腰后横跨剑鞘]，周身环绕着 [青绿色重水流与紧贴盔甲、身体运动轨迹及剑身的狂暴电弧]。[一位人形魔尊，身穿黑红魔袍，佩戴黑金肩甲，手持黑曜石魔剑]，周身环绕着 [血色魔纹、黑色流体墨气以及紧贴黑曜石魔剑、身体运动轨迹及魔尊分身的浓重黑红魔焰]。全片严格仅包含两名角色：剑客与魔尊。角色在战斗中避免静态姿势，保持超高速的破音障机动，拖拽出浓厚的动态墨迹残影；所有招式均叠加强烈的纯手绘水墨笔触。采用快慢动作结合的变速处理（Time Ramp）。武器与肢体碰撞必须匹配三级固定特效：轻度碰撞 = 黑白冲击帧 + 0.05 秒抽帧 + 局部负片效果 + 轴向微震。重度碰撞 = 径向冲击帧 + 0.1 秒抽帧 + 中心负片效果 + 力度感下沉/回弹 + 三层流体爆炸。终极招式 = 全屏冲击帧 + 0.15 秒定格抽帧 + 全屏负片白闪 + 中心鱼眼畸变 + 强 Bloom 光效 + 圆形冲击波。使用 3A 动作游戏惯性跟随镜头，镜头运动伴随基于物理动作的高频变焦与变速；全程纯视觉输出。
```
