# 武侠人质反转动作喜剧

*Wuxia Hostage Reversal Action Comedy*

> 一个电影级的武侠提示词，通过颠覆人质桥段，展现被俘虏的师妹其实才是现场真正威胁的喜剧效果。

## 提示词（中文）

```text
I. 核心定位
电影级写实质感，纯正中国古风仙侠美学。风格：高级“人质身份反转”喜剧。默片式的反应节奏，英式冷幽默逻辑，克制的港式动作喜剧节奏，三段式递进结构。Arri Alexa 电影质感，清晰稳定的面部微表情，细腻的胶片颗粒感，自然的体积光。核心笑点源于对权力关系的误判：敌人以为成功俘虏了师妹，观众短暂接受这一设定。随着反应展开，观众逐渐意识到真正身处险境的是敌人。拒绝夸张表演。笑点必须源于：角色自信度、停顿、眼神交流、真实的武力差距、敌人逐渐认清现实的过程。

II. 参考控制
1. 角色锚点：@Image 1 锁定为角色 ID A：剑仙师姐；@Image 2 锁定为角色 ID B：师妹。
2. 环境：所有上传的背景/场景图片决定环境 DNA。整合：地形、建筑、空间尺度、材质、植被、水体、天气、雾气、云层、光影、反射、景深、可通行路径。重新规划为一个独特、统一、空间合理、物理连续的新空间。
3. 原则：背景保持生动但中性。元素包括：风、植被、水、雾、反射、远景人物、环境音。严格遵守：背景不能触发剧情、制造笑点、辅助逃脱或打断节奏。

III. 角色设定
角色 ID A | 师姐：同 @Image 1。25–30 岁东亚女性，高挑纤细，鹅蛋脸，深邃杏眼，黑长发配白玉簪。造型：白色刺绣丝绸汉服，半透明宽袖，银色腰封，玉佩，白布靴，银色长剑。气质：冷静、端庄、极度自控。关键要求：听到“放下剑”后立即收剑；收剑不是妥协，而是自信。“松手，她不喜欢别人碰她的头发”必须是一句严肃的提醒。
角色 ID B | 师妹：同 @Image 2。20–25 岁东亚女性，娇小，圆脸，黑色编发。造型：青色麻布汉服，深色腰带，木簪，黑布鞋，深色钢剑。气质：机灵、稳重、不慌乱，实力强悍。比起被当人质，更烦躁头发被碰。关键要求：不要表现出惊慌；第一情绪是“烦躁”。询问“几个呼吸？”时必须冷静。反击动作必须快且干净。
子角色 1 | 敌人：从自信到困惑再到丧失判断力。要求：开场要有真实威胁感。收剑时表现出“计谋得逞”的骄傲。对“两个呼吸”感到困惑。
子角色 2 | 师父：最终包袱。要求：“三两银子”的随意记账感。

IV. 核心道具：银剑（师姐）、钢剑（师妹）、木簪（师妹）。

V. 喜剧结构：
1. 敌人自以为掌控全局。师姐收剑并发出“头发”警告。
2. 观众看到真实危险。师妹问“几个呼吸？”师姐：“两个呼吸，别耽误晚饭。”师妹在两个呼吸内反击。
3. 语义反转。敌人：“她不是你的人质吗？”师姐：“是啊……所以我刚才是在救你。”结尾以发簪价格作为包袱。

VI. 动作设计：简单、清晰、符合物理逻辑，无血腥，无超自然力量。序列：扭腕、转肩、控肘、低扫、缴械。

VII. 分镜脚本：
0-5 秒：远景。敌人俘虏师妹，“放下剑！”师姐收剑。
5-10 秒：中景。师妹问“几个呼吸？”师姐：“两个呼吸。”师妹反击。
10-15 秒：特写。敌人：“她不是你的人质吗？”师姐：“是啊……所以我刚才是在救你。”师父：“三两银子。”

VIII. 表演：师姐过度冷静，师妹因头发被碰而烦躁，敌人困惑，师父冷面。

IX. 镜头：16:9，Arri Alexa 风格，稳定的微表情细节。

X. 音效：中文对白，口型同步，逼真的环境音。

XI. 技术规格：15 秒，16:9，三个镜头，中文，角色/道具一致。

XII. 负面提示词：模糊、质量差、低质量、低分辨率、噪点、JPEG 伪影、水印、文字、错误；变形、变异、解剖结构错误、手部绘制拙劣、构图不佳、出画、残缺；角色不一致、衣服变换、面部崩坏、背景位移、跳帧、道具消失
```
