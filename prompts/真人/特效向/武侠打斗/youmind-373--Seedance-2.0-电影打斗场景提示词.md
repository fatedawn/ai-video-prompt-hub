# Seedance 2.0 电影打斗场景提示词

*Cinematic Fight Scene Prompt for Seedance 2.0*

> 一段详细的电影式提示，旨在生成一场两名男性之间的高强度打斗场景，其中包含带有残影的超高速拳击、戏剧性的镜头运动、慢动作效果以及一记强有力的终结一击，最初由 LLM (Chappy) 撰写。

## 提示词（日本語）

```text
画像に映る2人の男は、まるでジョジョの「オラオララッシュ」のように、残像が見えるほどの超高速パンチを繰り出している。ついに、仮面の男のパンチがスーツの男の頬を捉え、スーツの男はロケットのように後方へ吹き飛ばされ、地面に倒れて意識を失う。パンチの応酬中、カメラは激しい戦いを捉えるため、2人の男の周りを高速で回転する。カメラは、仮面の男がスーツの男の頬に最後のパンチを叩き込む瞬間をスローモーションで捉え、スーツの男が吹き飛ばされた瞬間に通常の速度に戻る。
```
