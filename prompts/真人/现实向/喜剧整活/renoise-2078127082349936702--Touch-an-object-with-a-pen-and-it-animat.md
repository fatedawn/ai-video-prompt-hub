Um pipeline eficiente em tokens com Claude cuida da roteirização, da engenharia de prompt para o modelo de vídeo e das revisões — enquanto uma ferramenta separada de vídeo faz a renderização. A economia em tokens foi reinvestida em mais produção, que virou o negócio de fato.
Aqui está o detalhamento completo.

PARTE 1 — O ponto de partida
Mês 0: cerca de US$ 400/mês em gastos com API, em sua maioria desperdiçados com contexto repetido, prompts verbosos e gerações únicas sem reutilização. Produção de vídeo: inconsistente, sem formato repetível, sem receita.

--- 相关文章：一位独立创作者如何将 Claude 的 token 成本降低 70%，并把它变成每月 3,800 美元的 AI 视频收入 ---
大多数人消耗 API credits 的方式都一样：每个视频都用一个巨大的 prompt，不做缓存，不复用，每次都从头重新生成脚本。账单一路上涨，产出却没有规模化，而“AI 视频生意”始终只是一个花钱比赚钱还多的爱好。
这个方案改变了这一点。一个高 token 效率的 Claude 流程负责脚本撰写、视频模型的 prompt engineering 和修改——而另一个独立的视频工具负责渲染。省下来的 token 成本被重新投入到更多产出中，最终这才变成了真正的生意。
下面是完整拆解。

PART 1 — 起点
第 0 个月：API 支出约 400 美元/月，大多浪费在重复上下文、冗长 prompts，以及一次性生成、无法复用的内容上。视频产出：不稳定，没有可重复的格式，也没有收入。
解决办法不是“少用 Claude”，而是更聪明地用它——减少浪费，保留产出。
PART 2 - 每日 5 条指令（为 token 效率而设计）
复用一个锁定好的模板，而不是每次都重新解释格式：
Using the script template below (don't restate it back to me),
write a 45-second video script on this topic: [insert topic].
Template: [insert reusable template once, reference by name after]
批量生成脚本，而不是一次只调用一个：
Write 5 short video scripts (45 seconds each) on these 5 topics:
[list topics]. Keep format identical across all 5 -
hook, body, CTA - no repeated instructions between them.
压缩发给视频生成模型的 prompts（更少 token，同样输出）：
Take this script and convert it into a single dense video-generation
prompt under 60 words. Cut filler, keep only visual and pacing detail
the video model actually needs.
修改时不要重新发送完整上下文：
Here's just the line that needs fixing:
Rewrite it tighter, same tone as before. Don't reprocess the rest.
每周单位产出成本审计：
Here's this week's token usage and video output count.
Calculate cost per finished video and flag which script type
is most token-expensive relative to performance.
PART 3 - 钱从哪里来


- 面向工具/产品发布的赞助型短视频 AI 视频——主要收入来源
- 一个小型的持续性客户，为每周一批脚本视频付费
- 复用模板意味着每花 1 美元能做出更多视频，也就意味着每周能发出更多提案
5 个 lifehacks
- 锁定一个可复用模板，并用名称引用它——不要在每次调用时都重新粘贴完整说明
- 批量请求，而不是单次调用——一次生成 5 个脚本的成本，低于 5 次分别调用且每次都重复设置
- 压缩传给视频模型的 prompts——那里多出来的字，不只是消耗 token，还会增加渲染时间
- 跟踪“每个完成视频的成本”，而不是“每次调用的成本”——这才是真正能预测利润的数字
- 砍掉任何一种脚本格式：如果每个视频的成本在上升，却没有相应带来互动或客户兴趣的增长
