# 使用 Seedance 2.0 制作的“不小心碰到女朋友”视频脚本

*Video Script for 'Accidentally Touching Girlfriend' using Seedance 2.0*

> Seedance 2.0 的详细视频脚本提示，概述了角色设置、场景细节以及一个完整的 9 秒分镜脚本，其中包含具体的动作、对话和视觉效果，旨在创作一个关于男友不小心碰到女友腿的幽默短视频。

## 提示词（中文）

```text
【人物设定】
• 男：20 岁左右，发型整洁，身穿白色长袖衬衫和黑色长裤。性格看起来有些憨厚老实，眼神中透露着“纯粹的傻气”。
• 女：20 岁左右，长发齐刘海，身穿日式 JK 制服（白色短袖衬衫、深蓝色领结、深蓝色百褶裙、黑色丝袜）。性格有巨大反转，从安静温柔到“霸道总裁”类型。
【场景设定】
• 地点：卧室床边。
• 背景：浅灰色百褶窗帘，整洁的床铺，柔和的灯光。
【剧本内容】
00:00 - 00:01
• 场景：两人并排坐在床上。女生手里拿着一袋零食在吃。
• 标题文字（顶部）：不小心碰到女朋友的时候
• 人物状态：男生呆呆地看着前方（模拟看电视），女生面无表情地咀嚼着。
00:01 - 00:02
• 场景：男生很自然地伸手到女生的零食袋里抓东西吃。
• 字幕：一起看电视~
• 表情：男生神情淡定，心思完全在“电视”上。
00:02 - 00:04
• 场景：男生从袋子里拿出一块零食放进嘴里，津津有味地咀嚼着。
• 字幕：抓零食
• 表情：两人保持着平静的观影氛围。
00:04 - 00:05
• 场景：男生再次伸手去抓，但这次却抓空了袋子，手直接落在了女生的腿上（大腿区域）。
• 字幕：继续抓……
• 动作：男生的手不仅落了上去，还稍作停留，显然还没意识到发生了什么。
00:05 - 00:06
• 场景：画面瞬间定格。女生停止咀嚼，慢慢转头，先是盯着男生的手，然后看向男生的脸。
• 字幕：摸我？
• 表情变化：
    * 女生：眼神瞬间从疑惑转变为“计谋得逞”的狡黠笑容。
    * 男生：瞳孔放大，嘴巴微张，身体僵硬，脸上写满了“我不是故意的，我完了”。
00:06 - 00:07
• 场景：女生突然放下零食袋，以“饿虎扑食”的姿态扑向男生。男生惊慌失措地举起双手防御，身体向后仰。
• 字幕：你先动手的~
• 对白（男生）：“我不是那个意思，我没有……”
00:07 - 00:09
• 场景：背景音乐变得急促/动感。女生跨坐在男生身上（幅度较大，略显霸道），男生无处可退，缩在床角。
• 字幕：真的不想……
• 表情：女生笑容灿烂（带着一丝玩味的压迫感），男生则是一脸惊恐中带着某种无奈的顺从。
• 视觉效果：画面以快速剪辑配合动感音乐结束，营造出“男生要完蛋了”的幽默氛围。
```
