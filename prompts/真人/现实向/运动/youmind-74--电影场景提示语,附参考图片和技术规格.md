# 电影场景提示语，附参考图片和技术规格

*Movie Scene Prompt with Reference Images and Technical Specs*

> 一个详细的提示，用于生成一个电影场景，涉及一男一女两位主角，背景设定在香港足球场的一场利物浦比赛期间，重点是围绕球员范迪克（Van Dijk）的秘密密谋时刻。该提示包括参考图像的占位符、场景描述、技术规格（中景、平视、浅景深）和情感背景。

## 提示词（中文）

```text
男主角：图片；女主角：图片；场景：图片；范戴克：图片；

镜头 1：密谋时刻

视觉描述：男女主角坐在香港足球场的看台上，周围是身穿红色球衣的利物浦球迷。他们头靠在一起，低声耳语。女孩指向远处球场上的范戴克（4 号球员），男孩会意地点了点头。

技术规格：中景，平视视角，浅景深，背景是热闹的体育场氛围。

情感：
```
