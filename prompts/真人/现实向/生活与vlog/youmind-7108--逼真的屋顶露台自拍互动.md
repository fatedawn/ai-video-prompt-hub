# 逼真的屋顶露台自拍互动

*Realistic Rooftop Terrace Selfie Interaction*

> 这是为 Seedance 2.0 Fast 模型设计的专业提示词，用于生成两人在屋顶自拍的视频，包含特定的面部表情、对话提示和风吹效果。

## 提示词（日本語）

```text
人物、服装、場所の参照として @image_1 を使用してください。
@image_1 の 2 人が屋上テラスで自撮りをしています。

アクション：2 人は画面を見ながら微笑んでいます。写真を撮り終えた後、画面を覗き込み、顔を近づけ、写真を見て爆笑します。前髪が風に揺れています。

セリフ：2 人は笑いながら「あ、目をつぶっちゃった」「本当だ、もう一回」と話しています。

サウンド：BGM：なし / 環境音とセリフ：あり（風の音、遠くのテラス席からの話し声）
```

请使用 @image_1 作为人物、服装和地点的参考。

对话：他们边笑边交谈，说着：“噢，我闭眼了”以及“你说得对，再拍一张”。

声音：背景音乐：无 / 环境音与对话：有（风声、远处露台座位的声音）
