# POV 烹饪 Vlog 与 2D 贴纸动画

*POV Cooking Vlog with 2D Sticker Animation*

> 一个适用于 Seedance 2.0 的多场景提示词，旨在创作一段将写实环境与生动的 2D 卡通贴纸角色相结合的第一人称烹饪视频。

## 提示词（中文）

```text
[风格] 真人实拍 + 2D 动漫贴纸合成喜剧短片 (Live-Action + Flat 2D Sticker Composite)，第一人称烹饪视角 (POV Cooking Vlog)，写实厨房质感与扁平卡通贴纸风格形成鲜明对比，8K 超清画质，轻微手持晃动 (Handheld Micro-shake)，竖屏。
[时长] 10 秒
[场景] 真实家庭厨房的第一人称视角：黑铁锅在灶台上翻炒牛肉和蔬菜，油花滋滋作响，热气升腾；背景为白色瓷砖墙，墙上有插座，酱油和油瓶沿墙排列，右侧是不锈钢水槽，侧窗透入自然光。
[角色] Q 版动漫贴纸角色（扁平 2D 贴纸质感，卡通轮廓，纸质感）：长金发配齐刘海，紫色大圆眼，粉色腮红，白色水手服学生装，蓝色发卡，坐在灶台旁的小木凳上，身高约为铁锅的一半，全程保持纯 2D 扁平质感，不受现实光影影响；一只真人的手（写实，可见毛孔）从右侧入画。
[00:00-00:03] 镜头 1：盐崩开场。第一人称俯视视角：真人的手正在翻炒牛肉和蔬菜；贴纸角色眯起眼睛坏笑，腮红加深，举起一个玻璃调料罐，将整罐白盐倒入锅中——真实的盐粒如瀑布般落下，在食物上堆成一座小小的白山。音效：食物滋滋声 + 倒盐时密集的沙沙声。
[00:03-00:05] 镜头 2：铲子敲头。真人的手从它手中夺走玻璃盐罐；另一只手举起锅铲敲击它的头顶——卡通式的敲击，头顶弹出一个红色的卡通肿块 (Cartoon Bump)，伴随着“Duang”的一声，它整个纸片般的身体上下颤动。音效：金属敲击声“Duang” + 卡通弹簧音效。
[00:05-00:08] 镜头 3：哭泣与喂食。贴纸角色捂住头上的肿块，瞬间变成蚊香眼 (Swirl Eyes)，张大嘴巴嚎啕大哭，蓝色的卡通泪水像喷泉一样向两侧飞溅 (Fountain Tears)。真人的手立即从盐堆中铲起满满一勺白盐和蔬菜，塞进角色张开的嘴里，将其填满。音效：夸张的卡通哭声 + 盐粒沙沙声 + 塞入时的“噗”声。
[00:08-00:10] 镜头 4：盐分 K.O. 结尾。它的脸颊鼓成两个亮红色的球，被迫吞咽，瞳孔收缩，脸色变得苍白，身体僵硬颤抖片刻——随后眼睛变成“X”状，直接从凳子上向后倒下，平躺在灶台上，双脚朝天，头顶出现一圈旋转的星星 (Dizzy Stars)，嘴里飘出一缕灵魂般的白烟。画面定格。
音效：僵硬的“咔哒”声 + 倒下的“砰”声 + 卡通升天音效收尾。
```

Sound effects: sizzling food + the dense rustling of salt being poured.
[00:03-00:05] Shot 2: Spatula Bonk. The screen freezes.
Sound effects: stiff "clack" + falling "thud" + cartoon ascension sound effect closing.
