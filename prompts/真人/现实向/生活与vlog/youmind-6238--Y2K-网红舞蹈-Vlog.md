# Y2K 网红舞蹈 Vlog

*Y2K Influencer Dance Vlog*

> 一个用于生成竖屏 TikTok 风格舞蹈 Vlog 的风格化视频提示词，包含 Y2K 美学与霓虹灯光效果。

## 提示词（中文）

```text
参考上传的图片 @ 生成一段网红卧室直播风格的舞蹈视频。

[风格] 抖音/快手网红直播竖屏 Vlog，9:16 比例，iPhone 自拍镜头质感，环形补光灯柔光 + 粉色霓虹氛围灯，Y2K 辣妹甜酷风，真实手机拍摄，带有轻微运动模糊。

[场景] 米白色卧室直播间，米色软包床，环形补光灯支架，粉色 LED 灯带，木质地板。

[节奏] 8 秒单镜头，匹配 120 BPM 的流行电子舞曲节拍，带有轻微的镜头呼吸感。

[舞蹈动作] 跟着节拍在镜子前跳甜美舞蹈：交替摆手 -> 左右扭胯 -> 转身回眸 -> 最后双手比心。表情活泼甜美，眼神偶尔看向镜头。

[镜头] 固定中全景，细微的手持呼吸感，右侧环形灯形成柔和主光，背景中的粉色 LED 灯形成虚化的氛围光斑。
```
