# 男友视角视频提示词，适用于 Seedance 2.0

*Boyfriend POV Video Prompt for Seedance 2.0*

> 一个为 Seedance 2.0 准备的详细多步骤视频提示，用于生成一个超现实、纯真风格的视频。视频内容为一个女孩在舒适的客厅环境中，以她男朋友的第一人称视角拍摄，包括特定的对话和动作，以展现一场俏皮的互动。

## 提示词（中文）

```text
[人物] 纯真无邪风格的女孩 [风格] 超写实居家日常，温馨客厅，柔和室内光线，真实自然，电影质感，第一人称男友视角 [场景] 女孩坐在沙发上看电视吃薯片，男友坐在沙发上看她。 [动作和对话严格按时间顺序，前一句说完后一句才开始，无重叠，无乱序] 1. 镜头里的男生说：我也想吃薯片。 2. 女孩对着镜头调皮一笑，说：叫声妈就给你吃。 3. 镜头里的男生立刻喊道：妈。 4. 女孩瞬间惊讶，害羞地脸红，从袋子里拿出一片薯片，说：哎呀，你还真叫啊，好好好，给你给你。 5. 镜头里的男生轻轻推回她的手，说：我要你亲自喂我。 6. 女孩脸更红了，用嘴巴咬下半片薯片，嘴里含着薯片慢慢靠近镜头，嘴里含糊不清地轻声说：我真是太宠你了。 [要求] 动作流畅自然，表情细腻真实，节奏舒缓，氛围温馨甜蜜，画面稳定清晰。
```
