# Seedance 2.0 旅行视频博客提示 - 威尼斯

*Seedance 2.0 Travel Vlog Prompt - Venice*

> 一个用于 Seedance 2.0 的提示，用于生成一个以男朋友视角在威尼斯拍摄的旅行 Vlog 视频，其中包含特定角色和浪漫氛围。

## 提示词（中文）

```text
以 [Image 1] 中的角色为主角，营造甜蜜的约会氛围，生成一个在水城威尼斯拍摄的、男朋友手机视角的 Vlog；她在一个街角茫然地看着一匹路过的白马；在水城的运河中乘船；在民宿的床上嘟嘴捏脸的特写，以及其他适合在威尼斯旅行拍摄的地点，用手机拍摄她。
```
