# Seedance 2.5 Time Travel Lovers 电影提示词

*Seedance 2.5 Time Travel Lovers Film Prompt*

> 这是一份为 Seedance 2.5 设计的复杂电影提示词，用于短片《Time Travel Lovers》。该提示词详细刻画了年轻妻子与年长丈夫之间深厚的情感弧线，设定了婚礼前夜的精确场景，并制定了严格的机位与运动规则，以确保叙事的连贯性。

## 提示词（中文）

```text
【角色情感弧线】 年轻妻子：婚前焦虑 → 习惯性在第一次敲门后开门 → 陌生人的声音准确说出她的第一个习惯 → 短暂发愣 → 礼貌的防御 → 老人预言了她的第二个微小动作 → 发生画外音 → 第一次受到冲击 → 意识到对方比现在知道得更多 → 困惑 → 警觉 → 观察老人 → 半信半疑 → 从他的眼神、举止和表情中捕捉到熟悉感 → 猜测他与自己的未来有关 → 不敢置信 → 轻声试探“……是你吗？” → 得到“只是老了点”的确认 → 震惊转为对未来的紧张 → 害怕答案 → 询问“过得好吗？” → 在听到“有时很难”时心头一沉 → 在听到“但依然很好”后放松 → 最终确认了婚姻 → 在听到“明天。以及此后的每一天”后安定下来 → 对明天的恐惧消散。年长丈夫：门外的不安 → 门比第二次敲门更早打开 → 看到年轻时的她，短暂失神 → 怀念 → 恢复克制 → 以习惯开启对话 → 因未被认出而略感遗憾 → 预言她的第二个动作 → 看到她意识到异常 → 不故弄玄虚 → 用最少的信息让她自己得出答案 → 看到她认出自己的脸 → 心软 → 被她认出 → 用“只是老了点”确认 → 停止讨论时间旅行 → 被问及婚姻时回想起几十年的生活 → 想到困难、平凡、真实且值得的日子 → 给出一个不加修饰的答案 → 看到她不再恐惧 → 下意识地做出几十年的婚姻习惯动作 → 意识到关系尚未开始 → 停止 → 默默接受这种距离。【角色与基础设定】 年轻妻子：必须遵循参考图 {{Mixed 1}}。年长丈夫：必须遵循参考图 {{Mixed 2}}。【场景设定】 地点：婚礼前夜的住宅入口。年轻妻子在内，年长丈夫在外。外部必须是真实的户外空间，而非走廊。可选场景：安静的街道入口或带有夜间空气的建筑外墙。必须保留：安静、通透、优美、写实，具有清晰的纵深感。外部：保留稀疏的夜灯、模糊的墙壁、栏杆、远处的窗灯、树影、建筑暗部、轻微的气流，以及大光圈下清晰的空间纵深。内部：略显温暖。隐约可见门厅、家具轮廓、外套、玄关桌、模糊的杯子、柔和的暖光和生活痕迹。不要堆砌婚礼用品。背景由剧情和对话建立。【氛围与质感】 保持原始氛围、质感、色调和通透感。灯光：自然、柔和、克制。主光来自角色上方偏左。均匀地铺在脸上。避免硬阴影、锐利的边界或舞台灯光。内部：低强度的柔和暖色环境光。外部：写实的夜间中性偏冷环境光。暖光轻微泄露到外部。老人的脸同时接收两种光。视觉色调：写实、低饱和度。【可见表演细节】 焦点优先对准离镜头最近的眼睛。必须看到虹膜、睫毛根部、瞳孔运动、眼睑变化、泪光、鼻翼呼吸、嘴唇开合/紧绷、吞咽、下颌运动、视线重新聚焦、微表情变化以及呼吸恢复。无需出现把手操作画面。手不是焦点。第二个习惯的关键：不是看到她触碰两次，而是男人预言，随后伴随两声微弱的画外音，瞳孔收缩，以及她视线的转移。【镜头规则】 大多为 OTS（过肩镜头）反打。严禁越轴。摄像机保持在表演轴线的一侧。【固定轴线与方向】 年轻妻子在左，看向右侧。年长丈夫在右，看向左侧。严禁交换方向。【OTS 年轻妻子过年长丈夫肩】 老人的右肩/耳朵/头部在极右侧作为极度虚化的前景（8%-15%）。年轻妻子在左至中心，看向右侧。前景不得遮挡眼睛、嘴唇或微表情。【OTS 年长丈夫过年轻妻子肩】 年轻妻子的左肩/头发/侧脸在左侧作为虚化前景。年长丈夫在中心偏右，看向左侧。前景必须保留质感，而非黑色块。【允许的微调】 缓慢推拉、10-20cm 平移、被动后退、15° 角度修正。运动必须产生真实的视觉变化（门框比例、前景比例、灯光视差、结构位移）。禁止数字变焦。【前景设计】 利用门框、肩膀、头发、玄关桌边缘、栏杆、墙壁边缘、远处灯光构建真实的空间层次。结构：前景 → 角色脸部 → 门槛 → 另一个人 → 通透的户外纵深。把手可以存在，但在第二个习惯期间不需要出现在画面中。不要特写把手。【英文对话】 放松、自然、真实语速。留出呼吸、停顿和反应的空间。建议对话：OLD MAN: "You still open the door before the second knock." YOUNG WOMAN: "...Sorry?" OLD MAN: "And you'll touch the handle twice." (停顿。两声微弱的画外音。女人的表情变化)。 YOUNG WOMAN: "Who are you?" OLD MAN: "I've had a lifetime to notice." (停顿。她观察他)。 YOUNG WOMAN: "...You?" (老人的嘴微微抽动)。 OLD MAN: "Just older." (停顿)。 YOUNG WOMAN: "Was it good?" OLD MAN: "Hard sometimes." (停顿)。 OLD MAN: "Still good." (她看着他)。 YOUNG WOMAN: "So... we got married?" OLD MAN: "Tomorrow." (停顿)。 OLD MAN: "And every day after that." 【30 秒详细分镜】 0-3.5s | 钩子：第一个镜头只有她，先出现未来的声音。85mm 镜头拍年轻妻子。暂无老人镜头。她心不在焉。第一次敲门。她自然地开门。夜间空气涌入。老人画外音：“你还是会在第二次敲门前开门。”在前 2 秒内开始。“……抱歉？”暂无老人全脸。3.5-7s | 他预言她的下一个动作。保持 OTS 拍女人。老人是模糊的瘦削前景。老人：“而且你会触碰把手两次。”短暂停顿。两声微弱的画外音。女人瞳孔收缩，视线先下移再上移。情绪从困惑转为防御。“你是谁？”声音轻柔。7-10.5s | 丈夫第一次完整露面。70mm OTS 拍女人。老人居右。通透的夜色背景。没有神秘的微笑。他的眼神中带着长久的熟悉感。“我花了一辈子去观察。”简单的事实。女人的呼吸变得浅促。L-cut（声音先行）。10.5-14.5s | 认出。85mm OTS 特写。她观察他的眼睛、眉毛、鼻子、嘴巴。在苍老的脸上寻找年轻时的他。瞳孔震动，呼吸停止。防御的神情软化。轻声：“……是你吗？” L-cut。老人：“只是老了点。”时空关系确立。14.5-18s | 恐惧未来。85mm 拍女人。防御消失，取而代之的是好奇和心痛。“过得好吗？”非常轻。眼眶湿润但没有流泪。18-22.5s | “有时很难。但依然很好。” 85mm OTS 拍老人。他停顿，看向别处。几十年的生活在他眼中流过。没有闪回。只有疲惫、理解和怀念。“有时很难。”非常平静。“但依然很好。”坚定而柔和。22.5-25.5s | 接纳。女人的反应镜头。她在听到“很难”时紧绷，在听到“依然很好”时放松。“所以……我们结婚了？”自然停顿。25.5-30s | “明天。以及此后的每一天。” 85-100mm OTS 特写拍老人。最安静的镜头。他带着心软的笃定看着她。“明天。”（停顿）。“以及此后的每一天。”这不是电影台词，只是事实。他习惯性地伸手去理一缕乱发，然后停住，意识到距离。手垂下。她看到了，然后自己理了理头发。最后一次隔着门槛对视。没有哭泣，没有拥抱，没有告别。结束。【镜头节奏】 总计 30 秒。非等长剪辑。钩子要快，认出要慢，情感落点最慢。前半段：“他是谁？”中间：“真的是他吗？”结尾：“我们以后还好吗？”【连贯性规则】 无机械剪辑。使用 J-cut、L-cut 和反应镜头。声音先行，视觉随后。把手的声音和她的瞳孔变化在不展示把手的情况下完成了信息传递。【摄像机参数】 2.39:1，24fps，180° 快门。镜头：85mm (f/2-2.4) 用于认出/结尾；65-75mm 用于标准 OTS。细微的手持晃动（呼吸、重心偏移）。禁止数字变焦。【声音设计】 无背景音乐，无字幕。仅有写实的环境音：夜间空气、远处的城市嗡嗡声、轻风。无近处的交通噪音。
```
