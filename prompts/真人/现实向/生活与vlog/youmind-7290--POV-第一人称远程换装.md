# POV 第一人称远程换装

*POV First-Person Remote Outfit Swap*

> 一份详细的 POV 视角视频电影感脚本，展示通过遥控器触发的无缝换装，旨在实现高质量的角色和时尚一致性。

## 提示词（中文）

```text
[风格] POV 男友第一人称视角短剧，真实的手机手持质感，带有轻微晃动，室内自然光通透感，遥控器瞬间换装效果，节奏轻快甜美，竖屏 9:16
[时长] 15 秒
[场景] 明亮的客厅/卧室，落地窗自然光，背景简洁温馨
[角色] 女主角（@Image 1，开场穿着初始服装）；男主角为 POV 视角，全程不露脸，仅屏幕下方出现一只握着白色遥控器的男性手部
[道具] 白色简约遥控器，仅有一个圆形按钮，按下时发出清脆的“滴”声并闪烁红光

[00:00-00:03] 场景 1：开场展示
画面：POV 视角，女主角站在画面中央，开心地转了半圈展示服装，轻轻提起裙摆，双眼闪亮地看着镜头
台词：女：“老公，我今天好看吗？”
声音：室内安静的环境音，轻微的布料摩擦声

[00:03-00:06] 场景 2：掏出遥控器
画面：男性的手握着遥控器从下方入画，指向女主角，大拇指按下按钮，红光闪烁
台词：男（画外音，慵懒）：“还行，不过——换一套试试。”
声音：清脆的“滴”声

[00:06-00:08] 场景 3：第一次瞬间换装
画面：“滴”声响起的同一帧，女主角服装瞬间变为 @Image 2 套装，站位、发型和姿势完全不变；她低头看衣服，双眼圆睁，嘴巴微张表示惊讶，不可置信地看向镜头
台词：女（惊讶）：“诶？！”
声音：变装瞬间伴随轻微的“叮”声，细微的布料展开声

[00:08-00:11] 场景 4：第二次瞬间换装
画面：男性的手再次按下按钮，红光闪烁，同一帧女主角变为 @Image 3 套装；这次她有了反应，脸颊微红，手指在身前绞动，害羞地扭动身体，眼神躲闪但忍不住看向镜头
声音：“滴”+“叮”，轻快的音乐开始渐强

[00:11-00:15] 场景 5：第三次瞬间换装 + 结尾
画面：男声画外音结束后，大拇指再次按下，女主角瞬间变为 @Image 4 套装；这次她笑了，向镜头走近，狡黠地眯起眼睛
台词：男（画外音，满意）：“不错，不错。”（按下按钮） 女（微笑着凑近，假装抱怨）：“你真坏——但我喜欢！”
声音：“滴”+“叮”，音乐在女主角台词结束时达到甜美的重拍

[导演笔记] 1. 换装铁律：每次换装必须在“滴”声的精准帧发生，单帧瞬间切换——女主角的位置、姿势、发型和表情在切换帧前后必须完全连贯，仅服装改变；2. POV 铁律：镜头即男性的眼睛，全程保持轻微的手持呼吸感晃动，男性仅以手部和画外音出现；3. 女主角反应必须有递进：惊讶 -> 害羞 -> 大胆喜欢，每阶段配合小动作；4. 服装顺序：初始 = 原装，第 1 次切换 = @Image 2，第 2 次 = @Image 3，第 3 次 = @Image 4；5. 清晰自然的口型同步，并与声音节拍对齐。
```
