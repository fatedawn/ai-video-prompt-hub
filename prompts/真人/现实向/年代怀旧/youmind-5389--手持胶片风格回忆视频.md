# 手持胶片风格回忆视频

*Handheld Film Style Memory Video*

> 将人物参考图像转换为带有轻微晃动、怀旧胶片质感的视频，并加入刻意的模糊效果和面部遮挡。

## 提示词（日本語）

```text
@Image 1 の日本人女性を、友人による自撮りやスナップショットのような、エモーショナルなフィルターのかかったノスタルジックなフィルムクリップとしてアニメーション化してください。激しい手ブレを加え、少しぎこちない雰囲気に仕上げます。顔がほとんどぼやけているか、サングラスや手で隠れている状態にしてください。
```
