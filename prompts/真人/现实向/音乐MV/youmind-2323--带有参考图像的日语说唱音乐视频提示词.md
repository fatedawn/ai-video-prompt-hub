# 带有参考图像的日语说唱音乐视频提示词

*Japanese Rap Music Video Prompt with Reference Images*

```text
ミュージックビデオの中で女性が日本語の歌詞をラップします：「おっと、すぐに現れた。ここで生まれて、飛び出して、地球にいる。あの時から知っていた。あなたに出会って、恋に落ちる。それは運命。」
```
