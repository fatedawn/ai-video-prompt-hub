# Seedream 5.0 超写实影棚肖像提示词

*Seedream 5.0 Photorealistic Studio Portrait Prompt*

> 一个高度详细的提示，用于使用 Seedream 5.0 生成一张时尚东亚年轻女性的超逼真电影级影棚肖像，其中详细说明了构图、服装、背景、灯光、相机设置（85mm, f/2.2）和纹理细节。

## 提示词（中文）

```text
超现实电影工作室肖像，2:3 宽高比，高分辨率，照片级真实感。
一位时尚的东亚年轻女性的半身肖像，身体略微倾斜，头部微微侧向一边，一只手随意地轻触下巴。双眼微垂，目光看向镜头外，表情冷静沉着，眉宇间流露着自信。
服饰与妆容：纯色烧橙色圆领衬衫，剪裁简洁，面料温暖光滑。亮黑色方框太阳镜架在头发上，镜片干净，反射着周围的光影。皮肤呈现自然健康的肤色。
背景：无缝工作室背景，深锈红色从深处背景逐渐向前过渡到暖巧克力色，过渡自然流畅。
灯光：柔和光线为主，强烈而温和；补光极少，右侧保留深阴影以增强对比度；相机轮廓光勾勒出人物边缘。高光流淌过太阳镜镜片，阴影柔和过渡，营造出强烈的深度感。
摄影：平视视角，全画幅相机搭配 85mm 定焦镜头，f/2.2 光圈，浅景深虚化背景，面部和织物质感锐利清晰。居中构图，适度的负空间。
质感：细腻的皮肤纹理，逼真的织物质感，画面干净，极低噪点。
```
