# 每周 OOTD 汽车版视频

*Weekly OOTD Car Edition Video*

> 一个用于“每周 OOTD”展示的电影感视频提示词，通过不同日期对应的穿搭与汽车内饰切换进行呈现。

## 提示词（中文）

```text
[风格] 每周 OOTD 汽车版，16:9 电影级写实摄影，浅景深，变形镜头质感，随车辆切换灯光与氛围，平滑且富有节奏的转场。
[时长] 15 秒。
[场景] 五种不同汽车的内饰。摄像机位于副驾驶位，面向女主角。窗外景色模糊且处于移动状态；内饰、灯光和环境随每次穿搭更换而完全改变。
[角色] 女主角 @Image 1（脸部和发型与角色卡保持一致，黑色长发披肩）。
[镜头锁定] 全程构图保持一致：摄像机固定在副驾驶侧，拍摄女主角驾驶时的中景侧脸。手部和身体朝向在各片段间保持连贯。每个片段包含一个标志性的小动作，并以硬切方式切换至下一套穿搭和车辆。

[00:00-00:03] 周一：德国轿车 x 商务风。黑色真皮内饰，侧窗晨光，仪表盘散发琥珀色氛围灯。白衬衫配灰色马甲，一手扶方向盘，另一手喝咖啡。字幕：“周一”。
[00:03-00:06] 周二：复古车 x 赫本风。米色布艺座椅，木质方向盘，温暖午后阳光。黑色连衣裙，丝巾，猫眼墨镜。字幕：“周二”。
[00:06-00:09] 周三：越野车 x 工装风。机械感内饰，正午阳光，车身轻微颠簸。卡其色背心，牛仔短裤，棒球帽，转动方向盘。字幕：“周三”。
[00:09-00:12] 周四：日落敞篷车 x 度假风。敞篷，金红色夕阳，头发随风飘动。杏色吊带裙，金丝边墨镜，伸手探出窗外。字幕：“周四”。
[00:12-00:15] 周五：夜间超跑 x 红色礼服压轴。碳纤维内饰，红色氛围灯，窗外霓虹流光。红色深 V 礼服，推动档杆，对镜头微笑，定格画面。字幕：“周五”。

[音效] 引擎声随车型风格变化（低沉轿车怠速 -> 复古引擎咔哒声 -> 越野胎噪 -> 敞篷风声 -> 超跑轰鸣），叠加轻快背景音乐与点击转场音效。
```
