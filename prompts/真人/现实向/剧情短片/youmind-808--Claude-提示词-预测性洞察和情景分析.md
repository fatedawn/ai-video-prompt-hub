# Claude 提示词：预测性洞察和情景分析

*Claude Prompt: Predictive Insights and Scenario Analysis*

> 一个用于 Claude 的提示模板，可根据用户指定的关键指标生成前瞻性洞察、简单的趋势预测和“假设”情景分析。

## 提示词（中文）

```text
上传您的 Excel/CSV 文件。

关键指标：[例如，收入、流失率、用户数]

请给我前瞻性洞察：

1. 简单趋势预测（如果趋势持续，未来 3-6 个月）

2. 3 种“假设”情景（例如，营销支出 +20%，流失率 -15%...）

3. 数据中的关键驱动因素/相关性

4. 一条建议：“如果我们做 X，预期会发生 Y”

5.
```

## 其他语言版本（上游仓库提供，非本仓库翻译）

### YouMind 提供的English版本（README.md）

[位置](https://github.com/YouMind-OpenLab/awesome-seedance-2-prompts/blob/f95b78f9916dd873aaee1ec6cd36963476563aa2/README.md#L2569)

```text
Upload your Excel/CSV file.

Key metrics: [e.g., revenue, churn, users]

Give me forward-looking insights:

1. Simple trend forecast (3-6 months into the future if trends continue)

2. 3 'what-if' scenarios (e.g., marketing spend +20%, churn -15%...)

3. Key drivers/correlations in the data

4. A piece of advice: 'If we do X, expect Y'

5.
```
