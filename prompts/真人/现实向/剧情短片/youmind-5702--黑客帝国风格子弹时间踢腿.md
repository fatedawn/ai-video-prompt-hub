# 黑客帝国风格子弹时间踢腿

*Matrix Style Bullet Time Kick*

> 一个高动作感的电影级提示词，用于呈现 Agent 在雨中进行 360 度子弹时间旋转回旋踢的画面。

## 提示词（中文）

```text
黑客帝国风格，数字绿色调。画面中的角色是一位身穿黑色风衣的 Agent，正在雨中进行高难度回旋踢。周围所有的雨滴在空中凝固，形成水晶般的水滴矩阵。摄像机以极慢的速度围绕 Agent 进行 360 度旋转，捕捉其踢腿的全过程，风衣和雨水在慢动作中呈现出丝绸般的质感。子弹时间特效，高对比度光影，超写实细节，4K 画质。
```
