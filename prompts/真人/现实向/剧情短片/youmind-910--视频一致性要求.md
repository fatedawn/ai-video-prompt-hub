# 视频一致性要求

*Video Consistency Requirements*

> 一套详细的要求，旨在保持视频片段的视觉一致性，包括统一的视觉风格、一致的色彩基调/纹理、稳定的角色特征（面部、发型、服装、受伤情况）、一致的环境（光照、背景、空间关系），并避免与现有 IP 雷同，专注于原创的东方奇幻世界观。

## 提示词（中文）

```text
整部影片必须保持统一的视觉风格，无风格漂移，色彩基调和纹理始终如一。同一角色必须保持面部特征、发型、服装、武器和受伤位置的一致性，不能换脸或换人。同一场景必须保持环境、光照、背景和空间关系的一致性，不能突然切换。原创东方奇幻世界观和角色设计，避免与任何现有电影、动画、游戏 IP 角色形象或标志性设计雷同。
```
