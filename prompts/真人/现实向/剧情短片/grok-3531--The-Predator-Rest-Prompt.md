# The Predator Rest Prompt

> A narrative prompt for a video showing the Predator character returning home to rest after a hunt.

## 提示词（English）

```text
The Predator returns home from his daily hunt.
He just wants a little rest.
Will it go smoothly?
Good night, Creators.
```
