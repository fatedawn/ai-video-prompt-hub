# Seedance 2.0 提示词通过 VSCode 和 Claude 代码分析生成

*Seedance 2.0 Prompt Generated via VSCode and Claude Code Analysis*

> 这条推文描述了一个复杂的工作流程：用户使用 VSCode、ClaudeCode 和 Opus 4.6 分析了之前的视频概念（喷气式轮滑，最初来自 Sora 2），从而为 Seedance 2.0 生成了一个提示词。目标是将现有视频概念转化为提示词，并稍微延长喷气式轮滑序列的持续时间。

## 提示词（日本語）

```text
約半年前に Sora 2 でランダムに生成されたジェットローラースケートのシーケンスをプロンプトに変換し、ジェットローラースケートの持続時間を少し延長したバージョンをリクエストしました。
```
