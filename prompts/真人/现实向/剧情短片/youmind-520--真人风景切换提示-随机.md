# 真人风景切换提示（随机）

*Live-Action Scenery Switching Prompt (Randomized)*

> 一段超高速的度量蒙太奇提示，每 0.1 秒在世界旅游景点和文化遗产地的实景画面之间切换。序列从东京塔开始，在晴空塔结束，中间的地点随机。

## 提示词（日本語）

```text
世界の観光名所や世界遺産のライブアクション映像が 0.1 秒ごとに切り替わる、超高速メトリックモンタージュ。
東京タワーから始まり、スカイツリーで終わるシーケンスで、中間地点はランダムにシステムに任されます。
```
