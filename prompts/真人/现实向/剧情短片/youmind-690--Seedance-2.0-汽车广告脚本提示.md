# Seedance 2.0 汽车广告脚本提示

*Seedance 2.0 Car Commercial Script Prompt*

> 一个为 Seedance 2.0 设计的详细多场景脚本提示，旨在纯粹通过文本转视频生成电影级汽车广告（TVC 风格），不使用任何参考图像或产品。该脚本概述了六个不同的场景、摄像机运动和画外音。

## 提示词（中文）

```text
场景 1：0–2 秒 特写。
清晨。一双饱经风霜的手缓慢地握住方向盘。窗外薄雾未散，天色将明。画面轻微晃动，积蓄着压抑的能量。

场景 2：2–5 秒 低角度仰拍。
一辆黑色 SUV 突然冲破峡谷公路上的薄雾，逆光剪影，车轮卷起尘土。镜头几乎贴地，营造出震撼的爆发力。

场景 3：5–8 秒 中景，缓慢推近。
男人独自站在悬崖边，俯瞰夜晚的城市灯火。风吹拂着他的衣衫。身后，车灯依然亮着，静静等候。孤独而壮丽。

场景 4：8–11 秒 快速蒙太奇，每帧约 0.5 秒——雨夜漂移，水花四溅 / 冰雪中破冰，坚定前行 / 沙漠日落，车与人融为一体的剪影。强烈的光影对比，史诗般的质感。

场景 5：11–13 秒 汽车缓缓停在一栋老房子前。车门打开，一个小女孩跑出来，笑声先于人到。男人蹲下张开双臂。手持跟拍，温柔落地。

场景 6：13–15 秒 无人机缓慢上升。车、人、家在暮色中融合成一个温暖的剪影。
画面逐渐变暗，白色字幕淡入——画外音：“路，从来不只是一条路。”（停顿）“它是你选择的方向。”

一个虚构的汽车标志出现。黑屏。结束。
```
