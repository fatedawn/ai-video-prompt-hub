# Claude 提示词：数据清洗和转换清单 + 公式

*Claude Prompt: Data Cleaning and Transformation Checklist + Formulas*

> 一个用于 Claude 的提示模板，可生成数据清理和转换的分步计划，包括识别问题、提供修复步骤（Excel/Python 公式）以及定义新的计算列。

## 提示词（中文）

```text
上传您的 Excel/CSV 文件。

请提供一份分步的数据清洗和转换计划：

1. 发现的所有问题（缺失值、重复项、类型错误、异常值等）

2. 解决每个问题的具体步骤（Excel 公式、Power Query 或 Python）

3. 应该创建的新计算列（例如：利润 = 收入 - 成本）

4. 最终清洗后的表格结构（列名）
```
