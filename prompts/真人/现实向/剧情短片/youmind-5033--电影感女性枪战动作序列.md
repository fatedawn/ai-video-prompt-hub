# 电影感女性枪战动作序列

*Cinematic Female Gun Action Sequence*

> 一个高度详细的多镜头动作提示词，描述了一位女性主角与帮派成员进行枪战的场景，并利用动态项目进行精准的动作捕捉。

## 提示词（日本語）

```text
図 1 の彼女によるアクションシーン。図 2 のモーションストーリーボードに従います。図 3 は空間的な位置関係を示しています。A は彼女の動き、B と C はギャングの動きです。(1) 彼女が歩く。(2) 敵（ギャング 2 名）が彼女に気づくカット。彼らが発砲を開始する。(3) 弾丸が画面手前から奥に向かって飛ぶ。彼女は被弾を避けるため、脇の通路に隠れる。(4) 隠れた通路の中で、彼女の体は正面を向き、顔は横を向いている。彼女はハンドガンを取り出す。弾丸が奥から飛んできて、壁の角に当たる。(5) 彼女が隠れた通路から飛び出し、銃を撃つ。正面からのアングル。(6) 敵のカット。敵の銃が彼女の放った弾丸によって弾き飛ばされる。銃は手からわずかに離れ、回転する。男たちは銃を持っていた手を軽くすくめ、驚いて斜め下を見る。(7) 彼女が勢いよく画面手前に向かってくる。(8) 彼女の左拳（右手には銃を持っている）がギャングの顔面にヒットする（比喩的表現で、実際には顔にめり込む）。(9) 後ろに倒れ込む男（下半身のみ、上半身は画面外）、別のギャングの背後からの視点、もう一人のギャングの顔面への彼女の回し蹴り。(10) 彼女が倒れ込むギャングにハンドガンを向けている。ローアングルからの視点。
```
