# LLM 提示词 4：组件逻辑构建器

*LLM Prompt 4: Component Logic Builder*

> 此提示指示 LLM 充当前端架构师，设计复杂组件（如多步表单和动态计算器）的逻辑，要求输出详细内容，包括状态机、数据流、错误处理和 React 结构。

## 提示词（中文）

```text
你是一名前端架构师。请为以下内容设计逻辑：

多步表单、动态定价计算器、带筛选功能的搜索、用户仪表盘、认证流程

对于每个组件：状态机、数据流、错误处理、加载/空状态、边缘情况

输出 React 结构。
```
