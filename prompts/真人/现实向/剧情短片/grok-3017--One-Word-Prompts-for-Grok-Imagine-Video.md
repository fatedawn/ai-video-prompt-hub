# One-Word Prompts for Grok Imagine Video Generation

> A set of single-word prompts tested with Grok Imagine for video generation. The user notes that simple one-word prompts can yield interesting results.

```text
horror
visceral
instinctive
euphoric
beastly
instinctive
rapturous
savage
feral
primal
visceral
palpable
sublime
engrossing
refractive
```
