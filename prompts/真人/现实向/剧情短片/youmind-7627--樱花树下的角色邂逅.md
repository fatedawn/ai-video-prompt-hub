# 樱花树下的角色邂逅

*Sakura Tree Character Encounter*

> 这是一个充满诗意的 Seedance 2.0 提示词，描绘了两个角色背靠樱花树两侧的场景，包含花瓣飘落和羞涩互动的细节。

## 提示词（日本語）

```text
BGM なし、字幕なし。

[Background Image] の桜の木の両側に、[Female Character] と [Male Character] が寄り添っているシーン。[Male Character] は木の右側に、[Female Character] は左側に寄りかかっています。お互いの姿は見えませんが、相手の存在を意識し、探り合っている様子です。桜は満開で、花びらがひらひらと舞い散っています。

恥ずかしがり屋の2人が、お互いの顔をちらりと見たり、そわそわしたりして、意識し合っている様子を表現してください。
```
