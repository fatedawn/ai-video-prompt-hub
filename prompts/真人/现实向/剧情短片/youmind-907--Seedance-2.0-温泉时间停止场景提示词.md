# Seedance 2.0 温泉时间停止场景提示词

*Seedance 2.0 Prompt for Time Stop Scenario in Hot Spring*

> 一个 Seedance 2.0 提示，描述了这样一个场景：用户在一个温泉中激活了一个时间停止装置，此时有两位迷人的女性（一位亚洲人，一位白种人）正在交谈。用户在恢复时间之前与被冻结的角色进行互动。

## 提示词（中文）

```text
在一个温泉池里，两位身材姣好的美女，一位是黑发东亚女孩，一位是金发碧眼的白人女孩，她们都穿着比基尼，一边泡温泉一边和我聊天。我启动了时间停止，两位女孩瞬间静止不动。我伸手捏了捏东亚女孩的脸，然后又捏了捏白人女孩的胳膊，最后拿出遥控器恢复时间，两位女孩继续聊着天。
```
