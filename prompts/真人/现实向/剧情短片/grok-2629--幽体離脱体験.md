# 幽体離脱体験

*Out-of-Body Experience*

> 天井付近に浮かんでいる子供の頃の幽体離脱体験を描写した Grok Imagine 用のプロンプト。

## 提示词（日本語）

```text
小学 3 年生の時、眠っていたはずが、気づくと天井から 3 cm ほど下の位置で仰向けに浮いていました。父親に名前を呼ばれた瞬間に体が戻りましたが、ひどい吐き気に襲われました。（幽体離脱体験）
```

## 其他语言版本（上游仓库提供，非本仓库翻译）

### YouMind 提供的English版本（README.md）

[位置](https://github.com/YouMind-OpenLab/awesome-grok-imagine-prompts/blob/75bbc31525a213f7298e38583e3975f0a898ceb6/README.md#L1666)

```text
When I was in the 3rd grade of elementary school, I was sleeping, but when I realized it, I was floating facing upwards about 3cm below the ceiling. My father called my name and I returned. I felt very sick. (Out-of-body experience)
```

### YouMind 提供的中文版本（README_zh.md）

[位置](https://github.com/YouMind-OpenLab/awesome-grok-imagine-prompts/blob/75bbc31525a213f7298e38583e3975f0a898ceb6/README_zh.md#L1665)

```text
我上小学三年级的时候，当时正在睡觉，但当我意识到时，我正脸朝上漂浮在距离天花板约 3 厘米的地方。父亲叫了我的名字，我就回到了身体里。我感到非常不舒服。（灵魂出窍体验）
```
