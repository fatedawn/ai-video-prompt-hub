# Topview Agent v2 借助 Seedance 2.0 生成电影预告片

*Topview Agent v2 Generates Movie Trailer with Seedance 2.0*

> 用户利用 Topview Agent v2，通过 Seedance 2.0 生成了一部 30 秒的电影预告片。该 Agent 将一个简单的创意自动转化为多镜头提示词，最终制作出一部名为“CRYPTOMAN”的好莱坞风格预告片。

## 提示词（日本語）

```text
ハリウッド映画の予告編。平凡なアメリカの高校生がヒーローに変身して戦う、マーベルスタイルのアクション映画。マルチカットで様々なシーンを作成したい。タイトルは『CRYPTOMAN』
```
