# Claude Prompt：深度 KPI 和趋势仪表板生成器

*Claude Prompt: Deep KPI and Trend Dashboard Generator*

> 一个用于 Claude 的提示模板，可根据上传的 Excel/CSV 文件生成全面的 KPI 和趋势分析仪表板，要求用户指定关键列。

## 提示词（中文）

```text
上传您的 Excel/CSV 文件。

关键列：[列出关键列，例如日期、收入、用户、成本]

创建完整的 KPI/趋势分析：

1. 5-8 个最重要的 KPI（包括公式/解释）

2. 环比或周环比趋势（关键数据 + 变化百分比）

3. 3-5 个最大的成就/预警

4. 可视化建议（图表类型及其应显示的内容）

5.
```
