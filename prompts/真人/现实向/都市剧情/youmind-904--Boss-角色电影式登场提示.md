# Boss 角色电影式登场提示

*Cinematic Entrance Prompt for a Boss Character*

> 一个用于生成强大“Boss”角色电影级入场场景的提示，场景特点包括冷色调室内照明、烟雾、低频音效和复杂的镜头运动（低角度推镜头、侧面跟随、特写、广角俯拍）。

## 提示词（中文）

```text
@图片，电影级老板登场，室内夜晚冷色调光影，烟雾弥漫，尘埃飞扬；皮鞋回响 + 低频鼓点音效，以一声深沉的咆哮结束；低角度推镜头 → 推至腰部 → 侧面跟随镜头，人物转头 → 面部特写 → 拉回俯视镜头，最后下属齐声高喊“老板好！”，整体压迫感拉满。
```
