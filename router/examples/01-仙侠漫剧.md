# 制作方案：仙侠漫剧：废柴少女觉醒灵根，宗门大比一剑逆袭

> 由 `router/cli.mjs recommend` 生成。题材识别为 **仙侠 / 玄幻 / 武侠剧**（drama-xianxia）；媒介 **漫剧** · 方向 **特效向** · 9:16 · 约 60 秒 · 预算：有云端视频模型 API key（按量付费）

## 1. 路线

**主路线：路线②：videogen 视频生成 + prompts/ 提示词（本仓库）**

- 「仙侠 / 玄幻 / 武侠剧」需要漫剧角色表演与镜头运动，用视频模型生成，提示词与模板来自本仓库 prompts/ 和 templates/
- 有 API key：路线② 直接 videogen gen 批量生成（按秒计费，先 --dry-run 估算）

备选：路线①：animator 手绘动画（本仓库）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. 第 1 镜：3 秒内立冲突（谁、想要什么、被谁挡住）
2. 第 2–3 镜：冲突升级 / 误会加深
3. 第 4 镜：反转或爽点
4. 第 5 镜：留钩子（下一集悬念）

要点：
- 先锁角色 4 视图与场景母版（资产图模板），再写镜头
- 法术/打戏用「三段式」：起势 → 交锋 → 余波；每段一个明确动作
- 只写「镜头1/2/3」，不要逐秒卡点（Seedance 2.0 官方说明精确秒级时序不稳定）

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线②：videogen 视频生成 + prompts/ 提示词（本仓库）（主路线）**

2. **剧本与分镜** — 按下方模板写：[全局]（画风/角色/场景锁定）+ 镜头1/镜头2/…；照着推荐提示词的写法改成你的剧情

   ```bash
   mkdir -p .work/仙侠漫剧-废柴少女觉醒灵/refs && $EDITOR .work/仙侠漫剧-废柴少女觉醒灵/分镜.md
   ```

3. **角色与场景资产（一致性）** — 同一角色全剧用同一张参考图；分镜里用 @角色名 引用

   ```bash
   # 用 templates/ 里「角色 4 View」「场景母版」模板出参考图，存到 .work/仙侠漫剧-废柴少女觉醒灵/refs/
   ```

4. **拆成镜头清单**

   ```bash
   node videogen/cli.mjs plan .work/仙侠漫剧-废柴少女觉醒灵/分镜.md --out .work/仙侠漫剧-废柴少女觉醒灵/shots.json --aspect 9:16 --refs .work/仙侠漫剧-废柴少女觉醒灵/refs
   ```

5. **生成镜头（云 API）** — 先 --dry-run 只打印请求；provider 还可选 kling / minimax / veo / fal / replicate / runway / luma

   ```bash
   node videogen/cli.mjs providers
   node videogen/cli.mjs gen .work/仙侠漫剧-废柴少女觉醒灵/shots.json --provider seedance --dry-run
   node videogen/cli.mjs gen .work/仙侠漫剧-废柴少女觉醒灵/shots.json --provider seedance
   ```

6. **配音 + 字幕 + 合成** — 台词交给本地 Kokoro TTS（需先 cd animator && npm run setup:tts），自动逐字字幕；--bgm 加你有版权的音乐

   ```bash
   node videogen/cli.mjs assemble .work/仙侠漫剧-废柴少女觉醒灵/shots.json --out .work/仙侠漫剧-废柴少女觉醒灵/final.mp4
   ```

**路线①：animator 手绘动画（本仓库）（备选/升级）**

7. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

8. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/仙侠漫剧-废柴少女觉醒灵 && $EDITOR .work/仙侠漫剧-废柴少女觉醒灵/台词.txt
   ```

9. **选画风** — 推荐画材 --media ink；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show ink-wash
   node animator/src/cli.mjs styles --search 水墨
   ```

10. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/仙侠漫剧-废柴少女觉醒灵/台词.txt --out .work/仙侠漫剧-废柴少女觉醒灵/仙侠漫剧-废柴少女觉醒灵.mp4 --character tianji --media ink
   ```

11. **精修（可选）** — 在 project.json 里加 "stylePreset": "ink-wash"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/仙侠漫剧-废柴少女觉醒灵/仙侠漫剧-废柴少女觉醒灵.work/project.json
   node animator/src/cli.mjs preview .work/仙侠漫剧-废柴少女觉醒灵/仙侠漫剧-废柴少女觉醒灵.work/project.json
   node animator/src/cli.mjs make .work/仙侠漫剧-废柴少女觉醒灵/仙侠漫剧-废柴少女觉醒灵.work/project.json --out .work/仙侠漫剧-废柴少女觉醒灵/仙侠漫剧-废柴少女觉醒灵.mp4
   ```

12. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
