# 制作方案：都市甜宠真人剧：契约闪婚的霸总和实习生

> 由 `router/cli.mjs recommend` 生成。题材识别为 **甜宠 / 恋爱 / 霸总剧**（drama-romance）；媒介 **真人** · 方向 **现实向** · 9:16 · 约 60 秒 · 预算：用即梦/可灵/海螺等网页端手动生成（会员或免费额度）

## 1. 路线

**主路线：路线②：videogen 视频生成 + prompts/ 提示词（本仓库）**

- 「甜宠 / 恋爱 / 霸总剧」需要写实画面与真人表演，用视频模型生成，提示词与模板来自本仓库 prompts/ 和 templates/
- 网页手动：videogen export 导出逐镜头生成包，网页生成后 import 收回

备选：路线①：animator 手绘动画（本仓库）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. 第 1 镜：3 秒内立冲突（谁、想要什么、被谁挡住）
2. 第 2–3 镜：冲突升级 / 误会加深
3. 第 4 镜：反转或爽点
4. 第 5 镜：留钩子（下一集悬念）

要点：
- 每集结尾留钩子（反转/误会/心动瞬间）
- 情绪戏用近景 + 对白节拍；男女主各一张参考图锁脸
- 真人题材不要用真实明星的脸和名字

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线②：videogen 视频生成 + prompts/ 提示词（本仓库）（主路线）**

2. **剧本与分镜** — 按下方模板写：[全局]（画风/角色/场景锁定）+ 镜头1/镜头2/…；照着推荐提示词的写法改成你的剧情

   ```bash
   mkdir -p .work/都市甜宠真人剧-契约闪婚/refs && $EDITOR .work/都市甜宠真人剧-契约闪婚/分镜.md
   ```

3. **角色与场景资产（一致性）** — 同一角色全剧用同一张参考图；分镜里用 @角色名 引用

   ```bash
   # 用 templates/ 里「角色 4 View」「场景母版」模板出参考图，存到 .work/都市甜宠真人剧-契约闪婚/refs/
   ```

4. **拆成镜头清单**

   ```bash
   node videogen/cli.mjs plan .work/都市甜宠真人剧-契约闪婚/分镜.md --out .work/都市甜宠真人剧-契约闪婚/shots.json --aspect 9:16 --refs .work/都市甜宠真人剧-契约闪婚/refs
   ```

5. **生成镜头（网页手动）** — 网页端费用以平台为准

   ```bash
   node videogen/cli.mjs export .work/都市甜宠真人剧-契约闪婚/shots.json --site jimeng --out .work/都市甜宠真人剧-契约闪婚/packages
   # 按生成包逐镜头在网页端生成，下载文件名保持 S01_shot01… 前缀
   node videogen/cli.mjs import .work/都市甜宠真人剧-契约闪婚/shots.json --from ~/Downloads
   ```

6. **配音 + 字幕 + 合成** — 台词交给本地 Kokoro TTS（需先 cd animator && npm run setup:tts），自动逐字字幕；--bgm 加你有版权的音乐

   ```bash
   node videogen/cli.mjs assemble .work/都市甜宠真人剧-契约闪婚/shots.json --out .work/都市甜宠真人剧-契约闪婚/final.mp4
   ```

**路线①：animator 手绘动画（本仓库）（备选/升级）**

7. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

8. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/都市甜宠真人剧-契约闪婚 && $EDITOR .work/都市甜宠真人剧-契约闪婚/台词.txt
   ```

9. **选画风** — 推荐画材 --media colored-pencil；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show emotional-watercolor-sketch
   node animator/src/cli.mjs styles --search 彩铅
   ```

10. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/都市甜宠真人剧-契约闪婚/台词.txt --out .work/都市甜宠真人剧-契约闪婚/都市甜宠真人剧-契约闪婚.mp4 --character tianji --media colored-pencil
   ```

11. **精修（可选）** — 在 project.json 里加 "stylePreset": "emotional-watercolor-sketch"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/都市甜宠真人剧-契约闪婚/都市甜宠真人剧-契约闪婚.work/project.json
   node animator/src/cli.mjs preview .work/都市甜宠真人剧-契约闪婚/都市甜宠真人剧-契约闪婚.work/project.json
   node animator/src/cli.mjs make .work/都市甜宠真人剧-契约闪婚/都市甜宠真人剧-契约闪婚.work/project.json --out .work/都市甜宠真人剧-契约闪婚/都市甜宠真人剧-契约闪婚.mp4
   ```

12. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
