# 制作方案：高中物理课件转视频：把牛顿第二定律的 PPT 做成讲解视频

> 由 `router/cli.mjs recommend` 生成。题材识别为 **课件 / 微课 / PPT 转视频 / 论文讲解**（courseware）；媒介 **其他** · 方向 **现实向** · 16:9 · 约 120 秒 · 预算：免费 + 普通电脑（CPU）

## 1. 路线

**主路线：路线⑥：slides2video PPT 式科普（本仓库）**

- 「课件 / 微课 / PPT 转视频 / 论文讲解」是「讲清楚一件事」：路线⑥ slides2video 把 deck.md 做成 PPT 式讲解片——要点按旁白逐词出现、公式逐项点亮、图表按讲解升起、同一元素跨页变形，免费、CPU、无需 API key
- 需要高度定制的动效时，改用路线③ 代码动效

备选：路线③：代码动效（Remotion / HyperFrames / Manim）；路线①：animator 手绘动画（本仓库）；路线④：外部开源项目（catalog/）
- PPT 式：路线⑥ slides2video（deck.md 或 import 现成 .pptx），一页一个想法，要点按旁白逐条出现

## 2. 台词 / 分镜骨架

1. 封面：这节课解决什么问题
2. 知识点 1：定义 + 例子（要点逐条出现）
3. 知识点 2：图示 / 公式 / 代码
4. 易错点：对比页（左右分栏）
5. 小结 + 一道思考题

要点：
- 已有 PPT：node slides2video/cli.mjs import 课件.pptx（备注即旁白，兼容 pptx2video 的 ## [handle] / [[Spotlight]] 写法）
- 课件默认 16:9；同一页内用 build 逐条出现代替翻页
- 论文讲解：一页一个图 + 一句结论，公式用 \term{} 逐项点亮

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线⑥：slides2video PPT 式科普（本仓库）（主路线）**

2. **准备（只需一次）** — KaTeX / Shiki / Mermaid 只装在 slides2video/node_modules（KaTeX 字体为 OFL，渲染时从 node_modules 加载，不进仓库）；setup:tts 下载本地 Kokoro 配音（可跳过：静音 + 按字数计时）

   ```bash
   cd slides2video && npm install && cd ..
   cd animator && npm install && npm run setup:tts && cd ..
   node slides2video/cli.mjs doctor
   ```

3. **写 deck.md（或导入现成 PPT）** — 一页一个想法；`> say:` 一句一条字幕；要点行尾写 {at: 词} 让它在说到该词时出现，{mark: circle} 圈注，{id: x} + transition: morph 跨页变形；公式 $$…\term{…}…$$ + terms 逐项点亮；画幅 aspect: "16:9"，主题 tianji（天机）

   ```bash
   node slides2video/cli.mjs init .work/高中物理课件转视频-把牛
   $EDITOR .work/高中物理课件转视频-把牛/deck.md
   # 已有 PPT：node slides2video/cli.mjs import 课件.pptx --out .work/高中物理课件转视频-把牛  （备注 = 旁白）
   ```

4. **配图（可选，ChatGPT 出图）** — 提示词已要求画面不含文字（文字由视频叠加）；不出图也能做：纯排版页 + 图表 + 公式

   ```bash
   node slides2video/cli.mjs prompts .work/高中物理课件转视频-把牛/deck.md --out .work/高中物理课件转视频-把牛/出图提示词.md
   # 按提示词出图，存为 .work/高中物理课件转视频-把牛/images/01.png、05.png…（页号命名）
   ```

5. **检查时间轴与版式** — 看每条要点 / 圈注的出现时刻；lint 检查语速、要点数、长时间静止、溢出、压字幕区

   ```bash
   node slides2video/cli.mjs plan .work/高中物理课件转视频-把牛/deck.md --voice
   node slides2video/cli.mjs lint .work/高中物理课件转视频-把牛/deck.md --qa
   ```

6. **一条命令出片** — 同时输出 .srt、每页样张拼图和 720p 预览；--from/--to 只渲染一段做快速检查

   ```bash
   node slides2video/cli.mjs make .work/高中物理课件转视频-把牛/deck.md --out .work/高中物理课件转视频-把牛/final.mp4 --sheet --preview
   ```

**路线③：代码动效（Remotion / HyperFrames / Manim）（备选/升级）**

7. **安装 Remotion skills 并新建工程** — Remotion License：个人/≤3 人公司免费；更大的营利公司需商业许可（否则换 HyperFrames / Motion Canvas / Revideo）

   ```bash
   npx skills add remotion-dev/skills
   cd .work/高中物理课件转视频-把牛 && npx create-video@latest
   ```

8. **配音与字幕（复用本仓库本地 TTS）** — 会同时生成 .work/高中物理课件转视频-把牛/voice-preview.voice.*（音频 + SRT + 字级时间戳），导入代码动效工程即可逐字对齐

   ```bash
   node animator/src/cli.mjs make .work/高中物理课件转视频-把牛/台词.txt --out .work/高中物理课件转视频-把牛/voice-preview.mp4 --scale 0.25
   ```

9. **预览与渲染** — 字幕可用 remotion-subtitles；数据视频可用 DataMagic 配方

   ```bash
   npx remotion studio
   npx remotion render
   ```

10. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
