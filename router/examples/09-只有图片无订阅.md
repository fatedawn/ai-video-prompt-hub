# 制作方案：只有 ChatGPT 出的 5 张图、没有视频订阅：做一条 20 秒仙侠氛围短片

> 由 `router/cli.mjs recommend` 生成。题材识别为 **仙侠 / 玄幻 / 武侠剧**（drama-xianxia）；媒介 **漫剧** · 方向 **特效向** · 9:16 · 约 60 秒 · 预算：免费 + 普通电脑（CPU）

## 1. 路线

**主路线：路线⑤：stills2video 静图成片（本仓库）**

- 你手上是现成的图片（例如 ChatGPT Images 出的图），不需要视频会员：stills2video 把图片按编号排成镜头，自动运镜 + 配音 + 字幕 + 转场成片
- 硬件档位：无独显 / 核显 / <6GB → 后端 cpu；真实物体运动做不到；需要的话用云端 key（cloud）或网页端手动（manual）补关键镜头。
- 「仙侠 / 玄幻 / 武侠剧」需要漫剧角色表演与镜头运动，用视频模型生成，提示词与模板来自本仓库 prompts/ 和 templates/

备选：路线①：animator 手绘动画（本仓库）；路线②：videogen 视频生成 + prompts/ 提示词（本仓库）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. 第 1 镜：3 秒内立冲突（谁、想要什么、被谁挡住）
2. 第 2–3 镜：冲突升级 / 误会加深
3. 第 4 镜：反转或爽点
4. 第 5 镜：留钩子（下一集悬念）

要点：
- 先锁角色 4 视图与场景母版（资产图模板），再写镜头
- 法术/打戏用「三段式」：起势 → 交锋 → 余波；每段一个明确动作
- 只写「镜头1/2/3」，不要逐秒卡点（Seedance 2.0 官方说明精确秒级时序不稳定）

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线⑤：stills2video 静图成片（本仓库）（主路线）**

2. **准备（只需一次）** — setup:depth 下载 Depth-Anything-V2-Small（Apache-2.0，26MB，校验 sha256）；setup:tts 下载本地 Kokoro 配音；doctor 自动检测显卡档位

   ```bash
   cd stills2video && npm run setup:depth && cd ..
   cd animator && npm install && npm run setup:tts && cd ..
   node stills2video/cli.mjs doctor
   ```

3. **写台词 + 生成出图提示词** — 一行台词 = 一个镜头；行首可写【晨雾竹林推进】等配方名（node stills2video/cli.mjs recipes 查看）

   ```bash
   mkdir -p .work/只有-chatgpt-出/stills && $EDITOR .work/只有-chatgpt-出/台词.txt
   node stills2video/cli.mjs prompts --script .work/只有-chatgpt-出/台词.txt --out .work/只有-chatgpt-出/出图提示词.md
   ```

4. **在 ChatGPT 里出图** — 默认手动出图（会员不含 API 额度）；有 OPENAI_API_KEY 可选 node stills2video/cli.mjs images（按量计费）

   ```bash
   # 按 .work/只有-chatgpt-出/出图提示词.md 逐镜出图，下载后命名 01.png、02.png… 放进 .work/只有-chatgpt-出/stills/
   ```

5. **一条命令出片（cpu）** — CPU：深度视差 + 运镜 + 雾/光/粒子叠层 + huashu 转场 + Kokoro 配音字幕；同时输出封面和缩略图

   ```bash
   node stills2video/cli.mjs make --images .work/只有-chatgpt-出/stills --script .work/只有-chatgpt-出/台词.txt --aspect 9:16 --out .work/只有-chatgpt-出/final.mp4 --backend cpu
   ```

**路线①：animator 手绘动画（本仓库）（备选/升级）**

6. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

7. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/只有-chatgpt-出 && $EDITOR .work/只有-chatgpt-出/台词.txt
   ```

8. **选画风** — 推荐画材 --media ink；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show ink-wash
   node animator/src/cli.mjs styles --search 水墨
   ```

9. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/只有-chatgpt-出/台词.txt --out .work/只有-chatgpt-出/只有-chatgpt-出.mp4 --character tianji --media ink
   ```

10. **精修（可选）** — 在 project.json 里加 "stylePreset": "ink-wash"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/只有-chatgpt-出/只有-chatgpt-出.work/project.json
   node animator/src/cli.mjs preview .work/只有-chatgpt-出/只有-chatgpt-出.work/project.json
   node animator/src/cli.mjs make .work/只有-chatgpt-出/只有-chatgpt-出.work/project.json --out .work/只有-chatgpt-出/只有-chatgpt-出.mp4
   ```

11. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
