# 制作方案：知识科普口播：为什么熬夜会让人变笨

> 由 `router/cli.mjs recommend` 生成。题材识别为 **知识科普 / 口播讲解**（explainer）；媒介 **其他** · 方向 **现实向** · 9:16 · 约 90 秒 · 预算：免费 + 普通电脑（CPU）

## 1. 路线

**主路线：路线①：animator 手绘动画（本仓库）**

- 「知识科普 / 口播讲解」以讲清楚/讲好故事为主，本仓库 animator 手绘逐笔动画免费、CPU 可跑、画面与台词逐词对齐

备选：路线⑥：slides2video PPT 式科普（本仓库）；路线③：代码动效（Remotion / HyperFrames / Manim）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. （钩子）一句话抛出反常识结论或痛点
2. （是什么）用一个生活化比喻解释「关键词」
3. （为什么）第 1 个原因 / 第 2 个原因
4. （怎么用）给一个马上能照做的方法
5. （结尾）一句话总结 + 引导关注

要点：
- 按语义节拍拆句（一句一个画面），每句 8–20 字
- 每个镜头至少一个主动作，否则 animator check 会警告画面呆板
- 要真人出镜感可加路线④的数字人项目（必须本人或已授权肖像）

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线①：animator 手绘动画（本仓库）（主路线）**

2. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

3. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/知识科普口播-为什么熬夜 && $EDITOR .work/知识科普口播-为什么熬夜/台词.txt
   ```

4. **选画风** — 推荐画材 --media colored-pencil；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show minimal-line-explainer
   node animator/src/cli.mjs styles --search 讲解
   ```

5. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/知识科普口播-为什么熬夜/台词.txt --out .work/知识科普口播-为什么熬夜/知识科普口播-为什么熬夜.mp4 --character tianji --media colored-pencil
   ```

6. **精修（可选）** — 在 project.json 里加 "stylePreset": "minimal-line-explainer"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/知识科普口播-为什么熬夜/知识科普口播-为什么熬夜.work/project.json
   node animator/src/cli.mjs preview .work/知识科普口播-为什么熬夜/知识科普口播-为什么熬夜.work/project.json
   node animator/src/cli.mjs make .work/知识科普口播-为什么熬夜/知识科普口播-为什么熬夜.work/project.json --out .work/知识科普口播-为什么熬夜/知识科普口播-为什么熬夜.mp4
   ```

**路线⑥：slides2video PPT 式科普（本仓库）（备选/升级）**

7. **准备（只需一次）** — KaTeX / Shiki / Mermaid 只装在 slides2video/node_modules（KaTeX 字体为 OFL，渲染时从 node_modules 加载，不进仓库）；setup:tts 下载本地 Kokoro 配音（可跳过：静音 + 按字数计时）

   ```bash
   cd slides2video && npm install && cd ..
   cd animator && npm install && npm run setup:tts && cd ..
   node slides2video/cli.mjs doctor
   ```

8. **写 deck.md（或导入现成 PPT）** — 一页一个想法；`> say:` 一句一条字幕；要点行尾写 {at: 词} 让它在说到该词时出现，{mark: circle} 圈注，{id: x} + transition: morph 跨页变形；公式 $$…\term{…}…$$ + terms 逐项点亮；画幅 aspect: "9:16"，主题 tianji（天机）

   ```bash
   node slides2video/cli.mjs init .work/知识科普口播-为什么熬夜
   $EDITOR .work/知识科普口播-为什么熬夜/deck.md
   # 已有 PPT：node slides2video/cli.mjs import 课件.pptx --out .work/知识科普口播-为什么熬夜  （备注 = 旁白）
   ```

9. **配图（可选，ChatGPT 出图）** — 提示词已要求画面不含文字（文字由视频叠加）；不出图也能做：纯排版页 + 图表 + 公式

   ```bash
   node slides2video/cli.mjs prompts .work/知识科普口播-为什么熬夜/deck.md --out .work/知识科普口播-为什么熬夜/出图提示词.md
   # 按提示词出图，存为 .work/知识科普口播-为什么熬夜/images/01.png、05.png…（页号命名）
   ```

10. **检查时间轴与版式** — 看每条要点 / 圈注的出现时刻；lint 检查语速、要点数、长时间静止、溢出、压字幕区

   ```bash
   node slides2video/cli.mjs plan .work/知识科普口播-为什么熬夜/deck.md --voice
   node slides2video/cli.mjs lint .work/知识科普口播-为什么熬夜/deck.md --qa
   ```

11. **一条命令出片** — 同时输出 .srt、每页样张拼图和 720p 预览；--from/--to 只渲染一段做快速检查

   ```bash
   node slides2video/cli.mjs make .work/知识科普口播-为什么熬夜/deck.md --out .work/知识科普口播-为什么熬夜/final.mp4 --sheet --preview
   ```

12. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
