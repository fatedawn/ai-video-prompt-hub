# 制作方案：产品带货：便携榨汁杯 30 秒种草视频

> 由 `router/cli.mjs recommend` 生成。题材识别为 **产品带货 / 广告**（product）；媒介 **真人** · 方向 **现实向** · 9:16 · 约 30 秒 · 预算：免费 + 普通电脑（CPU）

## 1. 路线

**主路线：路线③：代码动效（Remotion / HyperFrames / Manim）**

- 「产品带货 / 广告」需要写实画面与真人表演，用视频模型生成，提示词与模板来自本仓库 prompts/ 和 templates/
- 预算是「免费 + CPU」：用产品实拍图 + 代码动效/ffmpeg 做带货片（无需 API）；视频模型镜头作为可选升级
- 预算是「免费 + CPU」又需要动态画面：先用 ChatGPT 出图，再交给 stills2video 做 2.5D 视差成片（没有视频模型费用）
- 硬件档位：无独显 / 核显 / <6GB → 后端 cpu；真实物体运动做不到；需要的话用云端 key（cloud）或网页端手动（manual）补关键镜头。

备选：路线②：videogen 视频生成 + prompts/ 提示词（本仓库）；路线⑤：stills2video 静图成片（本仓库）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. 0–3 秒：痛点钩子或效果对比
2. 3–10 秒：产品出场 + 核心卖点 1
3. 10–20 秒：卖点 2/3 演示与证据
4. 20–30 秒：使用场景 + 行动号召

要点：
- 3 秒钩子 → 痛点 → 卖点演示 → 证据 → 行动号召
- 产品外观以实拍图为参考图（--refs），避免模型改形
- 广告法：不用「最/第一/国家级」等绝对化用语，功效类宣称要有依据

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线③：代码动效（Remotion / HyperFrames / Manim）（主路线）**

2. **安装 HyperFrames（HTML→MP4，Apache-2.0）**

   ```bash
   npx skills add heygen-com/hyperframes
   npx hyperframes init .work/产品带货-便携榨汁杯-3/hf
   ```

3. **配音与字幕（复用本仓库本地 TTS）** — 会同时生成 .work/产品带货-便携榨汁杯-3/voice-preview.voice.*（音频 + SRT + 字级时间戳），导入代码动效工程即可逐字对齐

   ```bash
   node animator/src/cli.mjs make .work/产品带货-便携榨汁杯-3/台词.txt --out .work/产品带货-便携榨汁杯-3/voice-preview.mp4 --scale 0.25
   ```

4. **让 agent 写画面、预览、渲染** — 数据图表可 npx hyperframes add data-chart；手绘质感可配 rough.js / rough-notation

   ```bash
   cd .work/产品带货-便携榨汁杯-3/hf && npx hyperframes preview
   cd .work/产品带货-便携榨汁杯-3/hf && npx hyperframes render
   ```

**路线②：videogen 视频生成 + prompts/ 提示词（本仓库）（备选/升级）**

5. **剧本与分镜** — 按下方模板写：[全局]（画风/角色/场景锁定）+ 镜头1/镜头2/…；照着推荐提示词的写法改成你的剧情

   ```bash
   mkdir -p .work/产品带货-便携榨汁杯-3/refs && $EDITOR .work/产品带货-便携榨汁杯-3/分镜.md
   ```

6. **拆成镜头清单**

   ```bash
   node videogen/cli.mjs plan .work/产品带货-便携榨汁杯-3/分镜.md --out .work/产品带货-便携榨汁杯-3/shots.json --aspect 9:16
   ```

7. **生成镜头（网页手动）** — 网页端可能消耗会员/额度，费用以平台为准

   ```bash
   node videogen/cli.mjs export .work/产品带货-便携榨汁杯-3/shots.json --site jimeng --out .work/产品带货-便携榨汁杯-3/packages
   # 按生成包逐镜头在网页端生成，下载文件名保持 S01_shot01… 前缀
   node videogen/cli.mjs import .work/产品带货-便携榨汁杯-3/shots.json --from ~/Downloads
   ```

8. **配音 + 字幕 + 合成** — 台词交给本地 Kokoro TTS（需先 cd animator && npm run setup:tts），自动逐字字幕；--bgm 加你有版权的音乐

   ```bash
   node videogen/cli.mjs assemble .work/产品带货-便携榨汁杯-3/shots.json --out .work/产品带货-便携榨汁杯-3/final.mp4
   ```

**路线⑤：stills2video 静图成片（本仓库）（备选/升级）**

9. **准备（只需一次）** — setup:depth 下载 Depth-Anything-V2-Small（Apache-2.0，26MB，校验 sha256）；setup:tts 下载本地 Kokoro 配音；doctor 自动检测显卡档位

   ```bash
   cd stills2video && npm run setup:depth && cd ..
   cd animator && npm install && npm run setup:tts && cd ..
   node stills2video/cli.mjs doctor
   ```

10. **写台词 + 生成出图提示词** — 一行台词 = 一个镜头；行首可写【晨雾竹林推进】等配方名（node stills2video/cli.mjs recipes 查看）

   ```bash
   mkdir -p .work/产品带货-便携榨汁杯-3/stills && $EDITOR .work/产品带货-便携榨汁杯-3/台词.txt
   node stills2video/cli.mjs prompts --script .work/产品带货-便携榨汁杯-3/台词.txt --out .work/产品带货-便携榨汁杯-3/出图提示词.md
   ```

11. **在 ChatGPT 里出图** — 默认手动出图（会员不含 API 额度）；有 OPENAI_API_KEY 可选 node stills2video/cli.mjs images（按量计费）

   ```bash
   # 按 .work/产品带货-便携榨汁杯-3/出图提示词.md 逐镜出图，下载后命名 01.png、02.png… 放进 .work/产品带货-便携榨汁杯-3/stills/
   ```

12. **一条命令出片（cpu）** — CPU：深度视差 + 运镜 + 雾/光/粒子叠层 + huashu 转场 + Kokoro 配音字幕；同时输出封面和缩略图

   ```bash
   node stills2video/cli.mjs make --images .work/产品带货-便携榨汁杯-3/stills --script .work/产品带货-便携榨汁杯-3/台词.txt --aspect 9:16 --out .work/产品带货-便携榨汁杯-3/final.mp4 --backend cpu
   ```

13. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
