# 制作方案：儿童绘本故事：小兔子学会分享胡萝卜

> 由 `router/cli.mjs recommend` 生成。题材识别为 **儿童绘本故事**（picture-book）；媒介 **漫剧** · 方向 **现实向** · 9:16 · 约 90 秒 · 预算：免费 + 普通电脑（CPU）

## 1. 路线

**主路线：路线①：animator 手绘动画（本仓库）**

- 「儿童绘本故事」以讲清楚/讲好故事为主，本仓库 animator 手绘逐笔动画免费、CPU 可跑、画面与台词逐词对齐

备选：路线②：videogen 视频生成 + prompts/ 提示词（本仓库）；路线④：外部开源项目（catalog/）
- 面向儿童：避免惊吓画面与不安全行为示范

## 2. 台词 / 分镜骨架

1. 从前，有一只「小主角」……
2. 有一天，它遇到了一个难题
3. 它试了一次，没成功
4. 朋友帮忙 / 换了个办法
5. 终于成功了，它明白了一个道理

要点：
- 语速放慢（Kokoro 可用 0.9× 变体），一页一句
- 想要「插画被画出来」的绘本感：先 AI 生插图，再用 whiteboard-stream-animation 或 story-to-handdrawn-video

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线①：animator 手绘动画（本仓库）（主路线）**

2. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

3. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/儿童绘本故事-小兔子学会 && $EDITOR .work/儿童绘本故事-小兔子学会/台词.txt
   ```

4. **选画风** — 推荐画材 --media picture-book；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show sunlit-storybook
   node animator/src/cli.mjs styles --search 绘本
   ```

5. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/儿童绘本故事-小兔子学会/台词.txt --out .work/儿童绘本故事-小兔子学会/儿童绘本故事-小兔子学会.mp4 --character doudou --media picture-book
   ```

6. **精修（可选）** — 在 project.json 里加 "stylePreset": "sunlit-storybook"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/儿童绘本故事-小兔子学会/儿童绘本故事-小兔子学会.work/project.json
   node animator/src/cli.mjs preview .work/儿童绘本故事-小兔子学会/儿童绘本故事-小兔子学会.work/project.json
   node animator/src/cli.mjs make .work/儿童绘本故事-小兔子学会/儿童绘本故事-小兔子学会.work/project.json --out .work/儿童绘本故事-小兔子学会/儿童绘本故事-小兔子学会.mp4
   ```

**路线②：videogen 视频生成 + prompts/ 提示词（本仓库）（备选/升级）**

7. **剧本与分镜** — 按下方模板写：[全局]（画风/角色/场景锁定）+ 镜头1/镜头2/…；照着推荐提示词的写法改成你的剧情

   ```bash
   mkdir -p .work/儿童绘本故事-小兔子学会/refs && $EDITOR .work/儿童绘本故事-小兔子学会/分镜.md
   ```

8. **拆成镜头清单**

   ```bash
   node videogen/cli.mjs plan .work/儿童绘本故事-小兔子学会/分镜.md --out .work/儿童绘本故事-小兔子学会/shots.json --aspect 9:16
   ```

9. **生成镜头（网页手动）** — 网页端可能消耗会员/额度，费用以平台为准

   ```bash
   node videogen/cli.mjs export .work/儿童绘本故事-小兔子学会/shots.json --site jimeng --out .work/儿童绘本故事-小兔子学会/packages
   # 按生成包逐镜头在网页端生成，下载文件名保持 S01_shot01… 前缀
   node videogen/cli.mjs import .work/儿童绘本故事-小兔子学会/shots.json --from ~/Downloads
   ```

10. **配音 + 字幕 + 合成** — 台词交给本地 Kokoro TTS（需先 cd animator && npm run setup:tts），自动逐字字幕；--bgm 加你有版权的音乐

   ```bash
   node videogen/cli.mjs assemble .work/儿童绘本故事-小兔子学会/shots.json --out .work/儿童绘本故事-小兔子学会/final.mp4
   ```

11. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
