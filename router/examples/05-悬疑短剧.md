# 制作方案：悬疑短剧：雨夜失踪的室友留下一段录音

> 由 `router/cli.mjs recommend` 生成。题材识别为 **悬疑 / 推理 / 惊悚剧**（drama-suspense）；媒介 **真人** · 方向 **现实向** · 9:16 · 约 60 秒 · 预算：有自己的显卡（ComfyUI / 本地模型）

## 1. 路线

**主路线：路线②：videogen 视频生成 + prompts/ 提示词（本仓库）**

- 「悬疑 / 推理 / 惊悚剧」需要写实画面与真人表演，用视频模型生成，提示词与模板来自本仓库 prompts/ 和 templates/
- 有自己的显卡：路线② 走本地 ComfyUI（Wan2.2 5B 工作流），没有 API 费用

备选：路线①：animator 手绘动画（本仓库）；路线④：外部开源项目（catalog/）

## 2. 台词 / 分镜骨架

1. 第 1 镜：3 秒内立冲突（谁、想要什么、被谁挡住）
2. 第 2–3 镜：冲突升级 / 误会加深
3. 第 4 镜：反转或爽点
4. 第 5 镜：留钩子（下一集悬念）

要点：
- 信息分层释放：每集只揭一个线索、埋一个新疑问
- 血腥/暴力画面点到为止，平台审核更友好

## 3. 执行步骤

1. **确认需求（intake）** — 题材、媒介、方向、时长、画幅、预算、角色素材、配音逐项确认；不确定就用本方案的默认值

   ```bash
   node router/cli.mjs intake
   ```

**路线②：videogen 视频生成 + prompts/ 提示词（本仓库）（主路线）**

2. **剧本与分镜** — 按下方模板写：[全局]（画风/角色/场景锁定）+ 镜头1/镜头2/…；照着推荐提示词的写法改成你的剧情

   ```bash
   mkdir -p .work/悬疑短剧-雨夜失踪的室友/refs && $EDITOR .work/悬疑短剧-雨夜失踪的室友/分镜.md
   ```

3. **角色与场景资产（一致性）** — 同一角色全剧用同一张参考图；分镜里用 @角色名 引用

   ```bash
   # 用 templates/ 里「角色 4 View」「场景母版」模板出参考图，存到 .work/悬疑短剧-雨夜失踪的室友/refs/
   ```

4. **拆成镜头清单**

   ```bash
   node videogen/cli.mjs plan .work/悬疑短剧-雨夜失踪的室友/分镜.md --out .work/悬疑短剧-雨夜失踪的室友/shots.json --aspect 9:16 --refs .work/悬疑短剧-雨夜失踪的室友/refs
   ```

5. **生成镜头（本地 GPU）** — ComfyUI 需先装好 Wan2.2 TI2V 5B 模型

   ```bash
   node videogen/cli.mjs gen .work/悬疑短剧-雨夜失踪的室友/shots.json --provider comfyui --workflow videogen/workflows/wan22_ti2v_5b_t2v.json
   ```

6. **配音 + 字幕 + 合成** — 台词交给本地 Kokoro TTS（需先 cd animator && npm run setup:tts），自动逐字字幕；--bgm 加你有版权的音乐

   ```bash
   node videogen/cli.mjs assemble .work/悬疑短剧-雨夜失踪的室友/shots.json --out .work/悬疑短剧-雨夜失踪的室友/final.mp4
   ```

**路线①：animator 手绘动画（本仓库）（备选/升级）**

7. **准备（只需一次）** — Node ≥18；setup:tts 下载本地开源 TTS（Kokoro v1.1-zh，CPU、离线、免费）

   ```bash
   cd animator && npm install && npm run setup:tts && cd ..
   ```

8. **写台词** — 一行一句（会成为一条字幕）；空行 = 换镜头；「关键词」说到时会被画出来；「角色：台词」可切换说话人（天机/豆豆）

   ```bash
   mkdir -p .work/悬疑短剧-雨夜失踪的室友 && $EDITOR .work/悬疑短剧-雨夜失踪的室友/台词.txt
   ```

9. **选画风** — 推荐画材 --media ink；画风预设只是提示词配方，渲染本身不调用任何 AI 服务

   ```bash
   node animator/src/cli.mjs styles --show linocut-editorial
   node animator/src/cli.mjs styles --search 彩铅
   ```

10. **一条命令出片** — 先加 --scale 0.5 快速预览；完成后会生成可编辑的工程 project.json

   ```bash
   node animator/src/cli.mjs make .work/悬疑短剧-雨夜失踪的室友/台词.txt --out .work/悬疑短剧-雨夜失踪的室友/悬疑短剧-雨夜失踪的室友.mp4 --character tianji --media ink
   ```

11. **精修（可选）** — 在 project.json 里加 "stylePreset": "linocut-editorial"，调整道具、动作、相机；synccheck 可做图文对齐质检

   ```bash
   node animator/src/cli.mjs check .work/悬疑短剧-雨夜失踪的室友/悬疑短剧-雨夜失踪的室友.work/project.json
   node animator/src/cli.mjs preview .work/悬疑短剧-雨夜失踪的室友/悬疑短剧-雨夜失踪的室友.work/project.json
   node animator/src/cli.mjs make .work/悬疑短剧-雨夜失踪的室友/悬疑短剧-雨夜失踪的室友.work/project.json --out .work/悬疑短剧-雨夜失踪的室友/悬疑短剧-雨夜失踪的室友.mp4
   ```

12. **发布前质检** — 核对字幕错别字与音画对齐；按平台要求标注「AI 生成」；可用 self-media-compliance-review 做违规风险自查
