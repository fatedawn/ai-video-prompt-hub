# 示例分镜：短剧反转（Seedance 2.0 写法，按镜头）

> 来源：本仓库 `docs/skill/SKILL.md` 的「例 2」，为本仓库自写示范（非第三方原文）。用于演示 videogen 路线 C（网页端手动往返）。

```text
竖屏9:16，国产爽剧质感，宴会厅水晶吊灯暖光，高饱和；保持无字幕。
将@图片1中穿黑色礼服、红唇的女人定义为「沈晚」，@图片2中穿白裙的女人定义为「林柔」。沈晚站在画面右侧，林柔站在画面左侧，宾客围成半圈；全程左林右沈，不越轴。
镜头1：中景固定。林柔打翻桌边的花瓶，坐在地上抬手指向沈晚，眼眶泛红，带着哭腔说：{姐姐，你怎么能推我}。宾客转头看向沈晚。
镜头2：切到沈晚近景，微仰拍。沈晚嘴角一侧上提，冷笑，把一份文件甩到林柔面前，冷声说：{戏还没演完吗}。
镜头3：切到文件特写。纸上只有两个大字“鉴定”和一枚红色印章，不要密集小字。
镜头4：切到林柔近景。她的哭声停住，嘴唇微张，愣住一拍，身体后缩。
<花瓶碎裂声> <宾客低声惊呼>；人物面部稳定不变形，礼服不变，同一画面中每个人物只出现一次。
```
