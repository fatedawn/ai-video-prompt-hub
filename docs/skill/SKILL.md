# 漫剧 / 真人剧分镜提示词

把用户的创意、剧本片段或参考素材，写成能直接粘进视频模型的分镜提示词，并附一张简短的分镜表。

## 1. 先确定 6 个参数（能推断就推断，推断不出再问，最多问一轮）

| 参数 | 选项 | 用户没说时的默认 |
|---|---|---|
| 模型 | Seedance 2.0 / Seedance 2.5 / 可灵 / Veo / 其他 | 按 Seedance 2.5 写，并注明“换 2.0 时把秒数改成镜头号” |
| 总时长 | 秒数 | 15 秒 |
| 画幅 | 9:16 / 16:9 / 4:3 / 21:9 | 短剧 9:16；DV 怀旧 4:3；电影感 16:9 |
| 类型 | 漫剧（2D / 3D 国漫 / 水墨…）或真人剧（写实） | 从用户的用词判断 |
| 场景 | DV vlog / 情绪特写 / 反转爽剧 / 甜宠 / 悬疑 / 对话戏 / 带货 / 古风仙侠 / 武侠打斗 / 小说改漫剧 | 从剧情判断 |
| 素材 | 人物图、场景图、运镜参考视频、音频 | 无素材，纯文生视频 |

做了哪些默认假设，要在输出开头用一行写明。

## 2. 单段上限与拆段

| 模型 | 单段时长 | 时间写法 |
|---|---|---|
| Seedance 2.0 | 4–15 秒 | **按镜头**：镜头1 / 镜头2 / 镜头3，按事件顺序写，**不写秒**（官方：2.0 只响应镜头序号，精确时间不稳定，强行限时可能异常） |
| Seedance 2.5 | 4–30 秒 | **按秒**：整数秒区间，首尾相接，总和等于时长；也可以写时间点（“第 5 秒…”）或相对时间（“3 秒后…”） |
| 可灵 Kling 3.0 | 3–15 秒（以平台为准） | 可以写时间码，也可以写编号镜头 |
| Veo 3.1 | 4 / 6 / 8 秒 | 8 秒内写 2–3 个时间码段 |

- **总时长超过单段上限**：按“总时长 ÷ 12–15 秒”拆段，每段单独输出一个代码块。
- **同一场景的文戏**（长对话、情绪递进）优先用“视频延长”；**剧情转折、打斗、追逐、蒙太奇**用分段生成后剪辑拼接。
- 需要卡准某一帧（音乐卡点、广告落版）：拆成多条独立生成，后期对齐。

## 3. 万能骨架（按顺序填，用不上的模块删掉）

```text
[全局] 时长N秒，画幅X；一句话：主体 + 地点 + 事件 + 题材/风格
       风格：真人写器材/年代/胶片（如“2000年代初家用MiniDV”）；漫剧写画风参数 + 排除相邻画风
[角色] 将@图片1中[2–3个稳定特征]的人物定义为「名字」：年龄感｜发型发色｜一个面部标记｜服装逐件｜随身道具
       继承：脸型、五官、发型、服装、身材比例
       不继承：参考图的背景、姿势、构图、原始光线、文字
       全程同一张脸、同一套衣服；转头 / 说话 / 手靠近脸时也不变
[场景] @图片2 或文字：地点 + 时间 + 天气 + 2–3个空间锚点 + 生活痕迹；主光源（有物理来源）
[站位] A（画面左·依托物·朝向·姿态），B（画面右·…）；左A右B，全段不越轴
       说话的人写清视线对象（“目光落在B脸上”）；手拿道具说话时写“视线不落在道具上”
[摄影] 机位高度 + 默认景别 + 运镜习惯 + 镜头缺陷 / 光学特征
[分镜]
  2.5：[0-3秒] … [3-7秒] …　　2.0：镜头1：… 镜头2：…
  每段顺序：运镜或切镜 → 主体动作 + 表情 → 位置变化 → 本段声音 / 台词 → 结束状态
[表演] 情绪 = 一个直白情绪词 + 1–2个看得见的身体锚点；大反应分“僵住→确认→释放”，一镜只走一层
[音频] 台词：角色（语气）：{台词}｜音效 <…>｜音乐 (…)｜环境底噪清单｜是否要BGM / 旁白 / 字幕
[连贯] 全程不变：脸 / 服装 / 道具数量和位置 / 光线方向 / 轴线
       多段时：末帧 = 谁 + 在哪 + 姿态 + 道具状态
[负面] 只放低关联瑕疵：换脸、身份漂移、多余手指、扭曲手部、分身 / 双胞胎、道具漂浮或瞬移、字幕、Logo、水印、UI、乱码文字
```

## 4. 写作规则（逐条检查）

1. **顺序**：先写谁在干什么，再写在哪、怎么拍，最后写风格、画质和约束。
2. **一段一个主要动作、一种运镜**：两个动作挤在一段里会各做一半；推、拉、摇、移不要叠在同一镜。
3. **段长 2–5 秒**：15 秒约 3–5 段，7–10 秒的打斗不超过 4 段。
4. **每个 @素材都写用途**（人物 / 场景 / 运镜 / 动作 / 音色）。只丢图不写，模型会把它当风格图。素材总数控制在 4–5 个。
5. **身份**：开头写一次，再加一句“不继承”声明；特写镜头补一句“与前面同一张脸”。Seedance 2.0 的人物参考用大头照 + 全身照，不用三视图。
6. **情绪要写成看得见的动作**，不写“很悲伤”，也不用成语或比喻（“脸沉下来”可能被直接画出来）。
7. **台词要短**：一拍一个人说一句，中文约 12 字以内；另一个人只给身体反应。全片只用一种语言。易读错的字换成同音常用字，品牌名和数字放到后期字幕。
8. **不要过度精确**：不写毫米、像素、小数秒、角速度，也不写“一秒眨 3 次”这类频次。改成“极轻微”“停一拍”“快速旋转”。
9. **不能自相矛盾**：固定机位不能再写“动态视角”；只写一种主光；“整齐顺滑”和“风吹凌乱”二选一；全局规则不能和分镜内容打架。
10. **否定句只挡低关联瑕疵**。模型天然倾向生成的东西（笑、眼泪、发光、空镜开场、风吹头发），改成在镜头里正向描述想要的状态（例如“泪水在眼眶里打转但没有落下”），不写“禁止××”。
11. **负面清单单独成块，放在最后**。禁止项里不要放正向指令。
12. **真实感靠写清器材缺陷**（手抖、对焦搜索、曝光波动），并写明关掉电影感（无稳定器、无调色大片感、无慢动作）。不要和 4K、电影级打光同时出现。
13. **漫剧必须写风格约束**（“2D 日漫风格”“保持 3D 国漫 CG 风格”）和排除清单（写实、半写实、通用 3D 脸、塑料 CG），否则容易漂成真人。
14. **竖屏更容易自己长出字幕**：写“保持无字幕 / 不要生成水印 / 不要生成 Logo”。
15. **结尾写成剪辑动作**（硬切黑场 / 定格高潮），不写淡出。
16. **群众演员给一个持续的小动作**，不要写“不许动”。
17. **画面里的文字**只保留几个大字，写明内容、时机、位置、方式，并加一句“不要密集小字”。

## 5. 词库（精简）

**景别**：大远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 极致特写。特写只装一个局部主体；全屋级事件至少用中景。
**运镜**：固定、缓推、后拉、左右摇、上下摇、横移、跟拍、环绕、升降、手持晃动、一镜到底、希区柯克变焦、航拍、FPV、甩镜、过肩、正反打、低角度仰拍、俯拍、第一人称。小众术语写成“术语 + 一句解释”。
**转场**：动作连续切、反应镜头切、景别跳切、遮挡转场（烟尘扑镜）、动势匹配切；写清在第几秒、用什么方式。
**光线**：窗光、林间丁达尔光斑、钨丝灯暖黄、频闪日光灯、烛火、霓虹反射、侧逆光勾边、顶光吊灯。白天要冷峻感时写“低饱和、青灰漫射阴影”，不写“冷白光”。
**质感**：
- DV：4:3、MiniDV、手持抖动、构图不完美、自动对焦搜索、曝光和白平衡跳动、柔和数字细节、暗部噪点、笨拙变焦
- 胶片：富士 / Kodak 颗粒、低饱和、轻微过曝
- 港片：高 ISO 颗粒、黄绿偏色、抽帧、慢门拖影
- 日系：百叶窗暖光、浮尘、浅景深
- 3D 国漫：超精细 CG、体积光、双色对比
- 水墨：墨云、笔触拖尾、留白、朱砂点缀
- 2D 日漫：细彩色轮廓线、2–3 段赛璐珞阴影、多层高光

**微表情（只写画面词，不写 AU 编号）**：

| 情绪 | 画面词 |
|---|---|
| 真笑 | 嘴角先扬，约半拍后眼尾眯起、眼下隆起 |
| 假笑 | 只有嘴角上提，眼睛不动，笑僵住或很快消失 |
| 痞笑 | 一侧嘴角斜挑，同侧眉梢轻挑，眼神从容 |
| 强忍悲伤 | 内眉头上挑并聚拢，眼眶湿红，嘴角下压、抿唇 |
| 冷怒 | 眉压低，下眼睑收紧，唇抿成线，几乎不动 |
| 恐惧 | 眉抬起但中心拧住，眼睁大露出上方眼白，嘴角横拉 |
| 惊讶 | 眉平抬，眼睁大，下颌松开；一秒内转成别的情绪 |
| 轻蔑 | 一侧嘴角上提，形成不对称冷笑，半垂眼俯视 |
| 心虚 | 眨眼变密，眼神先躲再看回，吞咽一次，嘴角一绷 |
| 害羞 | 先垂眼错开、半拍后偷看回来，嘴角压不住，耳尖泛红（不写“脸红”） |
| 愣住 | 唇分开一小缝，眉轻抬，身体顿住一拍 |
| 释然 | 眉心舒展，肩膀落下，长呼一口气，嘴角轻扬 |

强度从轻起步；情绪峰值对齐台词重音，金句后留 0.3–0.8 秒无台词反应。

**声音符号**：音乐（ ）、音效 < >、台词 { }、字幕【 】。用官方符号时，段名改用 `[风格]` 或 `风格：`，避免和【 】字幕冲突。
**底噪示例**：社区（脚步、自行车铃、鸟鸣、远处车流）｜室内（空调嗡嗡、布料摩擦、杯碟声）｜雨夜（雨压顶、雨打铁皮、霓虹蜂鸣）｜打斗（剑鸣 → 破空 → 交击 → 气浪，命中后短暂死寂再放余响）。

## 6. 场景速配（选一个作为起点）

| 场景 | 关键写法 |
|---|---|
| DV / vlog 随拍 | 器材缺陷清单 + 关掉电影感；全片只讲一件小事；道具去向要点名；发型等变化要拍出过程；只要环境音，无 BGM；结尾手挡镜头或硬切黑场 |
| 情绪特写 | 固定机位近景；只写两个视线落点；单一光源；3–4 个情绪节拍；每拍写一个情绪词 + 一个锚点；结尾停在情绪临界点 |
| 短剧反转 / 打脸 | 9:16；羞辱 → 反转 → 揭晓三段；反转落在一个看得见的物件或画面上；台词短且有语气；最后定格胜者姿态 |
| 甜宠 | 编号台词序列（“前一句说完再说下一句”），适合 2.0；害羞用行为表达；耳语式低能量台词 |
| 悬疑 / 恐怖 | 第一镜锁脸；每镜只加一个异常；恐怖落在旁人的反应上；结尾不给答案 |
| 对话戏 / 群戏 | 先列分镜表（机位 / 画面内容 / 视线 / 动作 / 光 / 末帧），再写成文字；每镜结尾复述“灯光不变 + 人物外观和位置” |
| 带货 / 广告 | 一把锁锁人、一把锁锁产品；手部接触真实；最后给英雄镜头 + 行动号召；品牌名和数字后期上字 |
| 古风 / 仙侠漫剧 | 画风约束 + 双方固有色不能互换；站位轴线；静 → 极动 → 短蓄力 → 绝杀定格；不用升格慢镜；用光效碎片代替血 |
| 武侠打斗 | 写清流派和生物力学；连招链要写接触点；锁定武器数量和握法；不越轴；每段不超过约 4 个动作 |
| 小说 / 漫画改漫剧 | 用参考视频定画风 + 原文；或漫画页按阅读顺序演绎；或线稿分镜加逐镜文字（多宫格少于 15 格） |

## 7. 输出格式

按顺序输出：
1. 一行假设说明：模型｜时长｜画幅｜漫剧或真人｜场景｜素材。
2. **提示词代码块**（```text），可以直接粘贴；多段时每段一个代码块，标题写“第 N 段（a–b 秒）”。代码块里不放说明文字。
3. **分镜表**（Markdown），列为：段 / 镜号｜时间或顺序｜景别·运镜｜画面动作｜台词 / 音效｜结束状态。
4. （可选）最多 3 条风险提示，例如“台词偏长”“15 秒 5 镜偏紧，可合并镜 3 和镜 4”。

用户给了现成的提示词要求优化时：先列出冲突和问题（矛盾指令、过度精确的数字、时间写法和模型不匹配、正向内容写进了负面项、台词过长），再给修改后的完整版本。

## 8. 示例（以下 3 例均为本 Skill 自写的示范，不是任何第三方原文）

### 例 1：Seedance 2.5｜真人｜DV 随拍｜20 秒 4:3

```text
[全局] 20秒，4:3，高度写实的2000年代初家用MiniDV录像，由朋友随手拍摄，不是广告；只讲一件小事：她第一次学骑自行车。
[角色] 将@图片1中扎低马尾、穿浅蓝条纹衬衫的女生定义为「小雨」：约22岁，黑色低马尾，浅蓝条纹衬衫 + 卡其短裤 + 白色帆布鞋。继承脸型、五官、发型、服装；不继承参考图的背景、站姿和光线。全程同一张脸、同一套衣服。
[场景] 老小区楼下的水泥空地，晾衣绳、几辆旧自行车、墙边盆栽；傍晚自然天光；无广告、无品牌。
[摄影] 手持轻微抖动，构图不完美，偶尔对焦搜索，一次笨拙的小变焦；脸始终清晰；无稳定器、无调色大片感、无慢动作。
[0-4秒] 平视中景：小雨扶着一辆旧自行车，回头看镜头笑，说：{你别拍了}。
[4-9秒] 侧面跟拍：她踩上脚踏，车头左右晃，脚放下撑地，停住。
[9-15秒] 镜头小跑跟随：她再试一次，晃了几米后稳住，向前骑出画面左侧。
[15-20秒] 拍摄者喘气追上，镜头摇过去：小雨停在晾衣绳下，一只脚撑地，回头大笑；硬切黑场。
[音频] 只要环境音：脚步、车链咔嗒、远处孩子嬉闹、拍摄者喘气；DV麦克风轻微底噪；无背景音乐、无旁白、无字幕。
[负面] 换脸、服装变色、发型无故变化、自行车结构变形、多余手指、物品漂浮、日期时间戳、UI文字、Logo、水印。
```

### 例 3：Seedance 2.5｜漫剧｜3D 国漫仙侠｜30 秒拆成 2 段

```text
第1段（0–15秒）
[风格] 16:9，中国仙侠动画电影风格，超精细3D CG，体积光，金青双色对比；保持3D国漫CG风格，不要写实真人。
```
