## 0. 一页速查

### 0.1 万能骨架（Master Template）【整理/改写】

把下面这些来源的分段方案合并、去重成 10 个模块：用户自己的两条示例、YouMind DV vlog、漫剧老李七段式、LearnPrompt「逐秒时间轴」、GoodCase mini DV、ZeroLu / marsoyang1 短剧格式、官方 2.0 进阶公式和 2.5 结构化写法、dexhunter 基本公式、waoowaoo 分段格式。用不上的模块直接删掉。

```text
【① 全局】时长 N 秒｜画幅 16:9 / 9:16 / 4:3｜（模型）｜一句话概述：主体 + 地点 + 事件 + 题材/风格
          风格/质感：器材或胶片年代 + 色调 + 颗粒/画质（漫剧写：画风流派 + 排除相邻画风）
【② 角色锚点】@图片1 = 角色A：年龄感｜发型发色｜五官标记｜服装逐件（上/下/鞋/配饰）｜随身道具
          继承：脸型、五官、发型、服装…  不继承：参考图的背景、姿势、构图、原始光线、文字
          全程同一张脸、同一套衣服；转头 / 低头 / 说话 / 手靠近脸时也保持一致
【③ 场景资产】@图片2 = 场景：地点 + 时间 + 天气 + 关键空间锚点 + 生活痕迹；主光源（窗光 / 台灯 / 霓虹…）
【④ 站位 / 视线】A（画面左·靠××·侧身朝右·持××），B（画面右·…）；轴线：左A右B，全段不越轴
          视线落点：A 看 B 的脸 / 看画外左侧某人（写清高度、方向）
【⑤ 镜头 / 摄影机风格】机位高度 + 默认景别 + 运镜习惯（固定 / 手持 / 跟拍）+ 镜头缺陷或光学特征
【⑥ 分镜时间轴】
   Seedance 2.0 → 镜头1 / 镜头2 / 镜头3（按事件顺序，不写秒）
   Seedance 2.5 / 可灵 / Veo → [0-3秒] [3-7秒] … 整数秒，首尾相接，总和 = 时长
   每段：运镜或切镜方式 → 主体动作 + 表情 → 位置 / 空间变化 → 本段声音 / 台词 → 本段结束状态
【⑦ 表演 / 微表情】情绪 = 一个直白情绪词 + 1~2 个看得见的身体锚点（眉 / 眼 / 嘴 / 呼吸 / 手）
          反应按「僵住 → 确认 → 释放」分层，一个镜头只走一层
【⑧ 音频】台词：角色（语气）：{台词}｜音效 <…>｜音乐 (…)｜环境底噪清单｜无 BGM / 无旁白 / 无字幕
【⑨ 连贯性】全程不变：脸 / 发型 / 服装 / 道具数量和位置 / 光线方向 / 轴线
          末帧（接续状态）：谁 + 在哪 + 什么姿态 + 道具状态（多段拼接时必写）
【⑩ 负面 / 禁止项】只放“低关联瑕疵”：变形、多余手指、换脸、双胞胎 / 分身、字幕、Logo、水印、UI、乱码文字…
          高关联的东西（笑、眼泪、发光、空镜）不要写成“禁止××”，改成在镜头里正向描述
```

### 0.2 动笔前先定 6 件事【整理/改写】

| # | 问题 | 不问清楚的后果 |
|---|---|---|
| 1 | **模型 + 版本**（2.0 / 2.5 / 可灵 / Veo…） | 决定按秒还是按镜头、单段上限、能不能用首尾帧 |
| 2 | **总时长 + 单段上限** | 超过上限就要拆段（2.0：4–15 秒；2.5：4–30 秒；Veo 3.1：4 / 6 / 8 秒；Kling 3.0：3–15 秒） |
| 3 | **画幅** | 竖屏 9:16 更容易自己长出字幕（官方指南），构图和景别阶梯也不一样 |
| 4 | **漫剧还是真人剧** | 漫剧要写画风参数 + 排除清单，否则容易漂成写实（官方「风格漂移」条） |
| 5 | **场景类型**（vlog / 情绪特写 / 反转爽剧 / 打斗…） | 决定套第 4 章哪个模板 |
| 6 | **素材**：有没有人物图、场景图、运镜参考视频、音频 | 决定 @ 引用怎么写；官方建议总共 4–5 个素材，不要用满上限 |

### 0.3 十条铁律（各家结论去重后）【整理/改写】

1. **先写谁在干什么，再写在哪、怎么拍，最后用风格、画质和约束收口**（官方进阶公式的顺序）。
2. **一个镜头只放一个主要动作、一种运镜**（官方：“一个镜头里尽量只指定 1 种运镜方式”；LearnPrompt：两个动作挤一段会“两个都做一半”）。
3. **每张参考图都要用文字绑定用途**：只丢图不说明，模型会把它当风格图（LearnPrompt、dexhunter、官方都这么说）。
4. **身份锁在开头写一次，并补一句“不继承”声明**；每段末尾用相同措辞复述光线、身份和站位（Emily2040 failure-atlas）。
5. **情绪写成看得见的动作**，不写“很悲伤”（官方情绪外化表）；但也别只罗列肌肉，要先点名情绪，再给 1–2 个锚点（Emily2040）。
6. **台词要短**：一个 3 秒的拍子，中文台词大约 12 字以内（LearnPrompt：英文 8 个词左右就会失步；Emily2040：每 12 个汉字算 1 个负载点）。
7. **时间轴首尾相接，总和等于时长**：写 30 秒却只列到 24 秒，模型会把最后一段拉长（LearnPrompt）。
8. **真实感靠写清相机缺陷，不靠堆 4K / 电影感**：手持 DV 和“4K 电影级打光”写在一起会打架，最后出来是塑料感（LearnPrompt）。
9. **否定句只用来挡低关联瑕疵**（字幕、水印、多余手指）。模型本来就倾向画的东西（笑、泪、发光），改写成正向描述（漫剧老李【社区经验】）。
10. **超过单段上限就拆段**：文戏用延长，武戏 / 转折用分段拼接（官方「视频延长 vs 分段拼接」）；拆段时写清末帧，下一段换机位起手。

### 1.1 ① 全局：时长 / 画幅 / 风格

- 时长、画幅最好**在平台参数里设**。提示词开头或结尾可以再写一遍 `时长：15秒，比例：9:16` 加强，但这只是辅助，不是控制（Emily2040 引 ByteDance 排障文档：要用中文“秒”，不写“s”）。
- 一句话概述（官方 2.5）：`主体 + 地点 + 事件 + 题材/风格 + 特殊运镜`。
- 风格写法分两类：
  - **真人写实**：写清器材 / 年代（“2000 年代初消费级 MiniDV”“Arri Alexa 效果”“富士胶片颗粒”），比写 realistic 管用（LearnPrompt：“一个具体型号带着整套光学特征”）。
  - **漫剧**：写清画风流派 + 可量化参数 + **排除相邻画风**（LearnPrompt anime-style-lock；官方：“2D 日漫风格”“3D 国风漫画”这类明确风格约束词）。
- 画质词要克制。官方给的画质示例是“高清，细节丰富，电影质感，色彩自然，光影柔和”。DV / UGC 类别加 4K / 8K（LearnPrompt：画质一上去 DV 味就没了）。

### 1.2 ② 角色锚点

【整理/改写】合并官方、LearnPrompt、漫剧老李、YouMind 的写法：

```text
将 @图片1 中[2–3 个稳定静态特征，如：穿灰色运动服、细框眼镜、黑长发]的女性定义为「林夏」。
林夏：约 25 岁｜黑色长直发、左眼角泪痣｜灰色宽领短袖（右肩外露）+ 灰色高腰短裤 + 白色中筒袜 + 白色运动鞋｜随身：黑色健身包
继承：脸型、五官、发际线、眼镜、发型、身材比例、服装款式和颜色
不继承：参考图的白色影棚背景、站姿、构图、原始光线、图上文字
全程保持同一张脸、同一套衣服；转头、说话、微笑、手靠近脸时也不变成另一张相似的脸
```

要点：
- **用 2–3 个稳定静态特征定义主体，之后一直用同一个标签**（官方：“将图片1中穿红色连衣裙、戴草帽的女人定义为张红”；多主体要分别定义，不能省略指代）。
- 有素材时**多写指代、少复述画面**（官方 2.5：素材本身够准时“建议只做指代、减少画面复述”）。
- **服装逐件写**：只写“同一套衣服”不够（LearnPrompt）。YouMind DV 那条连“露肩方向左右翻转”都写进了负面约束。
- **2.0 人脸参考用“大头照 + 全身照”，不要用三视图 / 多视图**：多视图容易被认成多个主体，引发换脸和双胞胎（官方 2.0 常见问题）。2.5 支持多视图（官方 2.5 差异点 2）。
- 漫剧老李另加了**年龄锚**：特写最容易换脸、变老，所以在核心人物行写“约二十岁”，特写镜行再写“与镜 N 同一张脸”【社区经验】。
- 角色卡别太长：LearnPrompt「电影级叙事短片」建议五格（发型、上衣、下装、鞋、随身物），“够模型认人，又不会吃光身份预算”。
- **素材限制【社区经验 / 以平台为准】**：dexhunter 和漫剧老李都写了 Seedance“不支持上传写实真人人脸参考”（漫剧老李补充：限制的是素材来源，不限制输出画风）。

### 1.3 ③ 场景资产

- 有场景图：`场景参考 @图片2`；多张背景图可以写“重组为统一环境”（YouMind Soran 职场剧 / 仙侠剧写法）。
- 没有场景图：地点 + 时间 + 天气 + 2–3 个空间锚点 + 生活痕迹。DV / 家庭录像类要点名杂物（盆栽、电线杆、晾晒的衣服），并补一句“无地标、无广告、无品牌”（LearnPrompt retro-found-footage）。
- **光源要有物理来源**：窗光、钨丝灯、日光灯、烛火、霓虹。不要写“情绪光”。白天要冷峻感时别写“冷白光”，写成“低饱和、青灰漫射阴影、逆光勾边”（漫剧老李 lighting-and-antifake【社区经验】）。
- 空间关系尽量用参考图表达，少写复杂文字（官方 2.0 注意事项）。

### 1.4 ④ 站位 / 视线（多人戏必写）

【原文摘录】漫剧老李一行式站位声明（MIT）：
> `【站位声明】：@角色A（画面左 · 背靠断裂石柱 · 侧身45°朝右 · 右手垂剑）、@角色B（画面右 · 依托残枪堆 · 正面朝左 · 长枪斜扛）；轴线锁定：左A右B，全段禁越轴；位移仅限本镜声明路径…`
> —— [manju-laoli-skill / model-adapters.md](https://github.com/lixiaoxiao9888-create/manju-laoli-skill/blob/main/short-drama-director/references/model-adapters.md)

规则（漫剧老李 + Emily2040 合并）【整理/改写】：
- 每个人写四要素：**位置**（画面左 / 中 / 右）+ **依托物** + **朝向** + **姿态**；不画坐标图，也不写 ASCII 布局（漫剧老李实测“太复杂，模型理解不了”）。
- **站位里写了的人，本段必须至少出镜一次**，否则写明“段末离画”，避免下一段人物凭空消失或重现。
- **说话镜头必须写视线对象**。手里拿着道具说话时，要写“视线落在对方脸上，不落在道具上”；不写的话，模型默认让角色盯着道具看。
- 用户示例②的视线写法很好，可以直接学：只给两个落点（“画框外左侧与肩齐平站立的人”“胸口中心点”），并写清对方比她高、要抬头。
- 反应镜头要写清**机位在被反应对象那一侧**（Emily2040：主镜头把地标放在角色身后、反应镜头又不写机位，角色会冲着镜头反应）。

### 1.5 ⑤ 镜头 / 摄影机风格

- 运镜直接用标准术语（官方：“中景、特写、全景、缓慢推镜、平稳横移、固定镜头”）。太小众的术语写成“名词 + 解释”（官方 2.5：“移焦，画面焦点发生平滑转变…”）。
- 一个镜头只写一种运镜。2.0 要求“固定镜头”和“环绕镜头”不能同段出现（dexhunter 避坑第 2 条）。
- 真人 UGC / DV：写**器材缺陷清单**，再写**关闭电影感**：无稳定器、无大片调色、无慢动作、无镜头光晕（YouMind DV、LearnPrompt handheld-ugc-vlog）。
- 机位术语可以中英混写：段头括号里用英文原词（Ground-level Low Angle、Dynamic Tracking），正文用中文（LearnPrompt：“混写比全译更稳”【社区经验】）。
- 空间感：中景、全景用 30°–60° 斜角，别用 90° 正侧拍（避免“街机横版感”）；连续两镜不要同景别同机位（漫剧老李 camera-specs【社区经验】）。

### 1.6 ⑥ 分镜时间轴

每段推荐顺序（官方 2.0 原文四步）【原文摘录】：
> “1. 运镜或镜头切换方式 … 2. 主体动作与表情 … 3. 位置或空间变化 … 4. 音频信息”
> —— 火山方舟《Doubao Seedance 2.0 系列提示词指南》

在此基础上补两条【整理/改写】：
- **5. 本段结束状态**：给下一段一个明确的起点（LearnPrompt dialogue-performance-beats，“每一拍以一行结束状态收尾”；Emily2040 的 Last frame 列）。
- **段长**：每段 2–5 秒；纪实跟拍约 2 秒一段，广告约 3 秒一段（LearnPrompt）。漫剧老李的经验是单镜 3–5 秒，一组 3–4 镜，单元 4–15 秒。
- **段数别太多**：7–10 秒的打斗超过四段左右就看不清动作（LearnPrompt combat）；官方 2.0 示例是 15 秒 3 个镜头。

按秒还是按镜头，见第 2 章。

### 1.7 ⑦ 表演 / 微表情

三条原则（官方、Emily2040、waoowaoo、漫剧老李合并）【整理/改写】：
1. **情绪要外化**：官方给了“抽象情绪 → 动作”对照表（见 3.6）。
2. **点名情绪 + 物理锚点**：只列肌肉，会出来生气或做鬼脸，而不是你要的震惊、羞耻或恐惧（Emily2040 failure-atlas）；只写“平静地”说台词，会得到一张死脸。所以要写声音和眼神，以及“说完最后一个字后脸怎么变”。
3. **低幅度更稳**：模型容易把情绪词演过头，“下颌收紧、语速放慢、目光多停一拍”比强烈的情绪副词更可控（waoowaoo video-direction 方法摘要）。重大反应分“僵住 → 确认 → 释放”，一个镜头只走一层。

FACS（面部动作编码）的用法见 3.5。注意：**AU 编号只在内部选型时用，不要写进投喂的提示词**（漫剧老李：“视频提示词里没有这个东西”）。

### 1.8 ⑧ 音频 / 台词

官方符号（Seedance 2.0 指南「特殊字符规范」）【原文摘录】：

| 信息类型 | 符号 | 示例 |
|---|---|---|
| 音乐 | （） | （背景中播放着快节奏的摇滚乐） |
| 音效 | <> | <远处传来狗叫声> |
| 台词 | {} | {你好，世界}；小语种要标注语种：用日语说道{こんにちは} |
| 字幕 | 【】 | 【第一章：启程】 |

> 注：漫剧老李认为 2.0 没有官方声音字符、2.5 才有。但官方 **2.0** 指南 PDF 里确实列了上面这张表，以官方为准。另外，社区格式常用【】当段名（如【风格】），这和“【】= 字幕”冲突。投喂官方模型时，段名建议改用 `[风格]` 或 `风格：`【整理/改写】。

台词写法【整理/改写】：
- `台词：角色名（语气）：{台词}`。语气是对白的第三要素（谁说、说什么、**怎么说**）。漫剧老李引官方英文资料：不写语气会让表情也变扁平。
- 一拍只给一个人说台词，另一个人给身体反应（LearnPrompt）；台词统一用一种语言，不要中英混用（官方）。
- 专有名词、数字、多音字最容易念错：把品牌名和数字挪到后期字幕（LearnPrompt）；多音字和生僻字换成同音常用字（官方示例：“螭龙山”写成“吃龙山”）。
- 环境底噪写成**按事件排列的清单**（脚步、推门、空调嗡嗡声…）。DV 类还要写“家用 DV 麦克风的轻微噪声 / 空间感，无录音室人声”（YouMind DV）。
- 2.5 的负向音频可以拆开控制：`无 bgm，只生成环境音和动作音`、`不要任何声音`（官方 2.5）。

### 1.9 ⑨ 连贯性

- 不变的东西（身份、服装、道具数量、光线方向、轴线）**集中写在固定块里一次**，再加一句“全程不变”。LearnPrompt 认为每段都重写服装反而会诱发外观突变；Emily2040 则建议每个镜头块结尾用**完全相同的措辞**复述光线、身份、站位。两种做法可以合起来用：服装细节写一次，每段结尾只用固定短句复述“同一张脸 / 同一光线 / 站位”【整理/改写】。
- **道具去向要点名**：球踢回去后留在孩子那边，不会回来也不会变成两个（LearnPrompt retro-found-footage）。
- **姿态延续**：前面撑起、坐起了，后面的镜头要写“保持坐起”，不能悄悄回到原来的姿态（漫剧老李）。
- **身体状态单向递进**：汗量只增不减，从“额角第一层汗”写到“衣服全湿”（LearnPrompt handheld-ugc-vlog）。

### 1.10 ⑩ 负面 / 禁止项

两派观点（都列出来，供你判断）：
- **官方**：约束词“十分重要”，常用模板是“保持无字幕 / 避免生成任何文字或字幕 / 不要生成 Logo / 不要生成水印”。双胞胎问题用一条全局约束句：“视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果…”。
- **漫剧老李【社区经验】**：“视频模型对否定不敏感、对词根敏感”。他们实测“玉佩不发光”“面无笑意”“禁空镜开场”全部失效，于是提出三种改法：①换词，让被禁的词根完全不出现；②镜1第一句就写画面主体；③去掉触发动作（例如别把道具举向光源）。禁止项一栏只放画面 / 文字 / 音频类的低关联瑕疵。
- **Emily2040**：持保留意见，认为“否定会召唤物体”没有被证实，有用的字面约束（如“不要剪切”）该保留。

【整理/改写】实操建议：负面清单**单独成块，放在时间轴之后**（LearnPrompt：塞进某一段里只对那段生效）。只放低关联瑕疵。模型天然想画的东西（笑、泪、光效、风吹头发），改成在镜头里写你要的正向状态。负面词表见 3.8。

## 2. 按秒 vs 按镜头

### 2.1 官方原话

**Seedance 2.0**（火山方舟《Doubao Seedance 2.0 系列提示词指南》）【原文摘录】：
> “使用 镜头1 、镜头2 、镜头3 等标识，按事件发生顺序（先主后次）组织内容。不强制限制每段时长，优先让模型根据剧情自然生成节奏。”
> “模型对精确时间（如 0–3 秒）的支持不稳定，强行限制时长可能导致生成结果异常。”

**Seedance 2.5**（火山方舟《Doubao Seedance 2.5 提示词指南》，经第三方 GitHub 镜像获取，见附录 B）【原文摘录】：
> “镜头顺序/时间轴（均可）：用时间戳或「镜头 N」切分，逐段描述画面具体内容、运镜、动作、台词、音效等，尽量使用正向描述。”
> “时间戳可以更好地理清故事剧情发展，以「1 秒」为单位”
> “不建议用时间戳控制频率/频次，比如「一秒摇头 3 次」。”
> “明确的时间区间 [注意时间轴的连续性，避免出现「0-3 秒...5-6 秒...」表达]”
> “响应时间戳：Seedance 2.0 不响应时间戳只响应镜头序号，而 Seedance 2.5 响应整数秒的时间戳。”

2.5 支持的三种时间写法：区间（`0-3 秒…3-7 秒…7-15 秒`）、时间点（`第 5s 快速向左横移转场`）、相对时间（`3 秒后周围的人纷纷摇头`）。

### 2.2 社区做法

| 来源 | 做法 | 备注 |
|---|---|---|
| YouMind DV vlog（收录在 Seedance 2.0 提示词库，30 秒） | `0–3s \| …` 共 10 段 | 30 秒已超过 2.0 的 15 秒上限，原帖可能实际用的是 2.5 或其他平台，结构可以参考 |
| ZeroLu / marsoyang1 短剧 | `[00:00-00:05] 镜头1：…` 每段 5 秒，3 段 | 秒和镜头号一起写 |

### 2.4 建议【整理/改写】

| 情况 | 写法 |
|---|---|
| **Seedance 2.0** | 用 `镜头1 / 镜头2 / 镜头3`，不写秒。需要节奏感就写行为：“停一拍”“话音落下后再…”。时长只在参数里设 |
| **Seedance 2.5** | 用整数秒区间，首尾相接，总和 = 时长；关键转场可以用时间点（“第 5 秒…”）；不写小数秒，也不写“一秒摇头 3 次” |
| 只有一个连续动作 / 一种状态变化（如读信） | 不分镜，写一段话；阶段写成“起初 / 然后 / 最后”（Emily2040 Continuous 形态） |
| 必须卡准某一帧（音乐卡点、广告口播落版） | 拆成多条独立生成，后期剪辑对齐（Emily2040） |
| 有参考音频控制节奏 | 少写时间戳，免得时间戳和音频变成两个时钟互相抢（Emily2040 audio-guide） |
| 纯文生视频 | 精度按 0.5–1 秒算，比这更细的数字只是噪音（LearnPrompt：“纯文生视频的时间分辨率大约在 0.5 秒”【社区经验】） |

### 3.3 运镜 / 机位

- **基础**：固定镜头、推 / 慢推、拉 / 后拉、左右摇、上下摇、横移、跟拍、环绕、升降、手持晃动、一镜到底（官方 2.5 + dexhunter）。
- **热门（可以直接写）**：希区柯克变焦、航拍、FPV、子弹时间、回弹变速、甩镜（官方 2.5）。
- **机位**：低角度仰拍、俯拍 / 鸟瞰、平视、过肩、第一人称主观视角、斜角 45°、正反打。
- **转场**（写清触发点和方式）：`第 5s 快速向左横移转场（向左擦除 + 自然叠化）`【原：官方 2.5】；遮挡转场（飞叶 / 烟尘扑镜）、动作连续切、反应镜头切、景别跳切、动势匹配切（漫剧老李六式）。
- **受击镜头**：短促径向震动（1–2 帧）、受击瞬间焦点急切、方向匹配的动态模糊；不要整段升格慢镜（漫剧老李【社区经验】）。
- **结尾**：写成剪辑动作，比如“硬切黑场”。写 fade out 模型真会淡出，白白浪费最后两秒（LearnPrompt）。

### 3.4 光线

- **有来源的光**：侧面窗棂天光、林间丁达尔光斑、天空散射光、暖黄钨丝灯、频闪日光灯管、烛火、霓虹反射（漫剧老李）。
- **方向 + 位置**：侧逆光、发丝边缘光、顶光吊灯、门外蓝色夜光对比室内暖黄光（Emily2040 寿宴例）。
- **情绪转折绑在光的变化上**：黄金时刻转蓝调时刻，冷蓝外景切到暖色内景（LearnPrompt cinematic-narrative-short）。
- **反光道具别和光源写在同一句**：玉佩、银镯、金属这类，只写材质本色（“玉面呈青玉原色”）。写“映着火光”反而会让道具自己发光（漫剧老李 C20d【社区经验】）。

### 3.5 微表情（FACS → 可投喂画面词）

> 来源：漫剧老李 `facs-emotion-recipes.md`（MIT），按“眉 / 眼 / 嘴”压缩。**AU 列只用于内部选型，不写进提示词。**

| 想要的情绪 | 可投喂画面词（中文） | 内部 AU |
|---|---|---|
| 真心笑 | 嘴角自然斜上扬，约 0.3 秒后笑意到眼：眼尾眯起、眼下隆起、浅鱼尾纹 | 6+12 |
| 假笑 / 皮笑肉不笑 | 只有嘴角上提，眼睛完全不动，略不对称，笑僵在脸上或很快消失 | 12 |
| 玩味 / 痞笑 | 一侧嘴角斜挑，同侧眉梢轻挑，眼神从容不眯，慢起慢收 | 单侧 12+2 |
| 苦笑 | 嘴角想上扬又被往下拉，像笑又像叹气，眼里没有笑意 | 12+15 |

| 紧张 / 心虚 | 嘴角横拉变扁、抿唇又松开，眨眼变密，眼神先躲开再强行看回来，吞咽一次 | 20 / 14+24 |

配套规则（漫剧老李 + LearnPrompt）【整理/改写】：
- 强度从最轻一档起，峰值不超过满格 80%；情绪峰值对齐台词重音字，之后留 0.3–0.5 秒余韵。
- 文戏情绪六阶段：触发 → 身体初识（瞳孔微缩、呼吸一窒）→ 社交压抑（下颌拉紧）→ 局部泄露（喉结吞咽、眼底血丝、指尖发白）→ 控制失效 → 余韵沉淀。
- **脸红别直接写“脸红”**：会得到一层均匀的粉色滤镜。改写成视线短暂移开、嘴角压不住、语速变慢、手部停顿（LearnPrompt）。
- 金句之后留 0.3–0.8 秒无台词的反应；单句超过 18–24 字就拆成正反打（漫剧老李 wenxi）。

### A. 真人剧

#### A1. DV / 家庭录像 / vlog 随拍

**适用**：千禧年 DV、旅拍、健身 / 做饭 vlog、男友 / 女友视角日常。

**填空模板【整理/改写】**
```text
[全局] {30}秒，{4:3}，高度写实的{2000 年代初家用 MiniDV}家庭录像，由{朋友/本人}随手拍摄；不是广告，也不是精致短片；剧情只有一件小事：{一句话}
[角色] 以 @图片1 作为唯一角色参考：{年龄}，{发型}，{服装逐件}，{随身道具}；严格保持脸、发型、服装、身材比例；不复用参考图的背景和站姿

[摄像机] 手持轻微抖动、构图不完美、偶尔对焦搜索、室内外切换时曝光/白平衡短暂变化、柔和数字细节、轻微暗部噪点、一次不熟练的小变焦；瑕疵克制而随机，脸始终清晰可辨；无稳定器、无大片调色、无慢动作、无光晕；DV 设备不入画

[3-6秒] …（每段一件事；台词写在发生的那一拍，一句以内）
[{N-3}-{N}秒] 收尾动作 → 录像式硬切黑场
[音频] 仅环境音：{清单}；家用 DV 麦克风轻微底噪；无背景音乐、无旁白、无字幕
[负面] 身份漂移、换脸、服装变色/变款、发型无故变化、塑料皮肤、美颜、多余手指、道具漂浮/瞬移、重复主角、日期时间戳、UI 文本、Logo、水印
```

**代表例**【原文摘录】YouMind「DV 美学风格的真实健身 Vlog」（作者 [疯狂的田螺君](https://x.com/QtImVCr6WK56152/status/2105888839919427744)，收录于 [YouMind README_zh](https://github.com/YouMind-OpenLab/awesome-seedance-2-prompts/blob/main/README_zh.md)）：

**代表例 2**【原文摘录】GoodCase「mini DV 咖啡 ASMR vlog」（创作者 Strength04_X，GoodCase 中文翻译，[案例页](https://goodcase.ai/cases/seedance-25-minidv-coffee-asmr-vlog)）：
> “→（3 秒，俯拍）磨新鲜咖啡豆，细粉落进粉碗。
> →（3 秒，特写）把粉均匀而结实地压平。”

**要点**
- 发型、道具的**变化要给出动作过程**（散发 → 扎马尾要拍到扎的动作），否则模型会让它凭空跳变。
- 结尾写“手挡住镜头，录制结束”或“硬切黑场”，比淡出更像录像带（GoodCase、LearnPrompt）。
- 男友视角 / POV：机位就是角色本人，运动要从身体推出来；每次剪辑都要手动声明（LearnPrompt pov-continuous-take）。
- 用户示例①的“严格连贯性要求”一节，对应这里的 [角色] 不继承声明 + [负面] 身份类。

#### A2. 情绪特写 / 微表情独角戏

**适用**：克制向情绪短片、告白 / 离别、“意难平”特写。

**填空模板【整理/改写】**
```text
[全局] {15}秒，{9:16}，{固定机位 50mm 近景}，{富士胶片颗粒、低饱和、蓝调}；背景虚化
[人物锚点] @图片1：{发型} {一个面部标记} {服装}；全程同一张脸
[视线] 只有两个落点：①画外{左侧}{比她高的}人的脸（需要{向左上}微抬头）；②{胸口/围巾}中心点
[光] {冬日侧逆光，只在发丝边缘留一道淡金边}（光源只写一种）
镜头1（{幸福}）：{起始视线} → {一个可见变化，如嘴角慢慢扬起，笑意到眼} → 结束：{视线落点}

镜头3（{委屈}）：…
```

**代表例**【原文摘录】用户示例②（来源：@九州文化-奶盖AI，OCR 整理稿）：
> “视线仅存在两个落点：锁定画框外左侧与肩膀平齐水平位置站立的人（对方身高比女生高，向左转头要朝肩膀方向并向上微抬头）/ 下沉落在胸口中心点”

**要点**
- 用户示例②里最值得学的三点：**两个视线落点**、**镜头零运动、全靠微表情推进情绪**、**情绪曲线标签化**（幸福 → 藏得意 → 委屈 → 沉思 → 释怀 → 意难平）。
- 需要修正的地方：在 2.0 上用了亚秒时间点；参数互相矛盾（≤2mm 位移 vs 露 6 颗下齿；眼白面积“始终一致” vs “缩小 1/3”）；光线矛盾；“风吹发丝凌乱” vs “长发整齐顺滑”。详见第 6 章。
- 想要“快哭但不掉泪”，官方情绪表里就有现成说法：“泪水在眼眶里打转但没有落下”。用这句正向描述，比反复写“禁止眼泪”更稳（后者是漫剧老李说的词根风险）。

#### A4. 甜宠 / 心动 / 情侣日常

**填空模板【整理/改写】**
```text
[全局] {15}秒，{9:16}，超写实{居家/校园}日常，{柔和室内光/暖金阳光}，{第一人称男友视角/双人侧面}
```

**代表例**【整理/改写】marsoyang1「居家喂食篇」（视频来源 [X](https://x.com/i/status/2026454987157680591)，见 [marsoyang1 README](https://github.com/marsoyang1/awesome-seedance-prompts)；该仓库未声明许可证，这里只概括写法、不引原文）：用一行方括号说明，要求动作和台词**严格按顺序**进行——上一句说完再接下一句，不重叠、不打乱。

**代表例 2**【原文摘录】YouMind No.1「15 秒电影感日式浪漫短片」（作者 [AIGC｜阳家豪](https://x.com/JiahaoYang_art/status/2033119940216344616)）：
> “口型同步自然精准……对话是低能量的害羞耳语，自然停顿在 200-400 毫秒之间，说话时嘴巴只轻微移动，没有夸张或机械感”

**要点**：甜宠戏的核心是**台词顺序 + 反应**，用编号台词序列（不写秒）就行，适合 2.0。

#### A5. 悬疑 / 恐怖 / 伪纪录

**填空模板【整理/改写】**
```text
[全局] {15}秒，{伪纪录片/固定机位实拍感}，{自然光}；@图片1 锁脸和服装（锁定写在第一个镜头里）
[0-5秒] 日常铺垫：{主角在做的普通事}；关键细节：{此时一切正常的证据}
[5-10秒] 异常：{只发生一个看得见的变化}；{其他人的反应}
[10-15秒] 回马枪：{回头/再看} → {异常消失或升级}；结尾不给答案：{门还在震/烟还在冒}
[音频] {底噪}；异常处 {一个声音} 后全场死寂
```

**代表例**【整理/改写】marsoyang1「镜子悬疑篇」（视频来源 [X](https://x.com/i/status/2020788951678607813)；只概括、不引原文）：主角本人已经转身走出镜子的取景范围，镜中的“倒影”却停在原地不动——异常只来自这一个变化。

**要点**（LearnPrompt horror-suspense）：每一镜只加一个变化；恐怖的落点放在**旁人的反应**上；**结尾不给解决**；一致性锁要写在 Shot 1，不要放到结尾的风格段。

#### A6. 现实题材对话戏（职场 / 家庭 / 寿宴）

**填空模板【整理/改写】**（参考官方“镜头 N”写法 + Emily2040 寿宴例的“每块结尾复述锁定行”）
```text
镜头1：{固定全景}，机位在{A 身后偏高}，越过 A 的肩膀拍向{B 出现的位置}。{群体在做的事}。{B 出现}，{群体反应：一个一个转头，压低声音}。灯光：{单一主光}。A：{外观 + 位置 + 朝向}。B：{外观 + 位置}。
镜头2：反打，机位在{B 方向}，{A 的近景}：{点名情绪 + 一个锚点}。灯光不变。A：{同上措辞}。
镜头3：{插入特写：手/道具的一个物理动作，写清起点和终点}。
镜头4：{B 近景}，眼睛没有离开 A，{语气}说：“{一句台词}”。说完{脸怎么变}。灯光不变。
声音：{按事件排列}；无配乐；保持无字幕。时长：15秒。
```

**代表例**【原文摘录】Emily2040 README「这杯茶」（[Emily2040/seedance-2.0](https://github.com/Emily2040/seedance-2.0)，MIT）：
> “镜头5：……她低头看着画面外坐着的他，眼睛没有离开他，声音很轻，每个字都清楚，说：“这杯茶，我妈等了二十年。”说完她的眼眶红了，没有眼泪，嘴唇抿住。灯光不变：头顶暖黄吊灯，脸在暖黄光里。”

**要点**：Emily2040 的方法是**先填分镜表**（机位 / 画面内容 / 视线 / 动作 / 其他人 / 光 / 末帧），再把每一行写成文字。群众演员要给一个持续的小动作，否则会像一屋子人体模特（failure-atlas）。YouMind Soran 的职场剧还加了“表演原则”一栏：每个角色写情绪路径（准备就绪 → 受挫 → 内疚 → 释然），并写明“无愤怒 / 哭泣”。

#### A7. 电商口播 / 广告

**填空模板【整理/改写】**
```text
[全局] {15}秒，{9:16}，UGC 口播测评 / 电影级产品广告
[人物锁] @图片1 博主：{…}　[产品锁] @图片2 产品：{形状/颜色/标签}，全程不变形、不改标签
[0-3秒] {开场钩子：拿起产品对镜头说一句}
[3-8秒] {上手：涂抹/开箱的近景；手部接触真实}
[8-12秒] {细节特写 + 一个卖点动作}
[12-15秒] {英雄镜头 + 行动号召}；品牌名和数字后期上字
[负面] 产品变形、标签重绘、多余手指、乱码文字
```

**代表例**【原文摘录】ZeroLu「直播带货口播视频」（来源 卡尔的AI沃茨）：
> “要求人物亲手涂手上，给出近景展示，侧脸转动展示细节，镜头从半身到特写切换 3 次。口播要包含卖点，最后给出强行动号召。”

**要点**：一把锁锁人、一把锁锁产品，台词和动作写在一起（LearnPrompt ugc-creator-review）；官方的文字生成模板是 `「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征」`。

### B. 漫剧

#### B1. 古风 / 仙侠对决（3D 国漫）

**填空模板【整理/改写】**
```text
[画幅风格] {16:9}，{中国仙侠动画电影风格，超精细 3D CG，金青双色对比}；保持 3D 国漫 CG 风格，不要写实真人
[角色] A @图片1：{服装色 + 兵器 + 气质}；B @图片2：{…}；双方固有色不能互换
[站位] A（画面左·{依托物}·朝右）、B（画面右·…）；左A右B，全段不越轴
[0-3秒] 大远景对峙：{环境异象}；<低沉雷鸣>
[3-8秒] {A 招式} vs {B 招式}，写清接触点和能量颜色；<金属碰撞与空间破碎声>
[8-12秒] {大招蓄力：1–2 个紧凑镜头}；台词：B（{低吼}）：{一句}
[12-15秒] {爆炸 → 烟尘中定格高潮画面}；不加平缓收势帧
[禁止] 角色变形、武器结构变化、服装变化、分身、双胞胎、廉价游戏特效、过度粒子、过度 Bloom、字幕、水印
```

**代表例**【整理/改写】marsoyang1「仙侠对决篇」（视频来源 [X](https://x.com/i/status/2021591223505662201)；只概括、不引原文）：开场 0–3 秒用大远景，两道流光从画面两侧在虚空中高速对冲，光中只隐约露出人物轮廓，第一次碰撞前不给近景。

**要点**：漫剧老李的节奏是“静 → 极动 → 短蓄力 → 绝杀定格”，并建议默认禁用升格慢镜（他们实测会破坏节奏）。官方古风示例的收尾句可以直接借：“人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿”。

#### B2. 武侠打斗（水墨 / 写实武侠）

**填空模板【整理/改写】**
```text
[风格] {水墨武侠：墨云、笔触拖尾、留白}｜或{写实武侠：冷调低饱和、胶片质感}
[生物力学] {流派}，真实重量和动量；双方持续进攻，不待机、不摆架子、不瞬移
[武器锁] 全场共 {2} 把{刀}，握在{柄}上，刀身和柄始终连在一起
[镜头1] {中景·45°斜拍}：{起手招} → {对方格挡/闪避} → {反击}（写清接触点）
[镜头2] {近景}：{兵刃咬死的特写}；<兵刃高频震颤>
[镜头3] {全景}：{绝杀命中}；命中后 0.3 秒死寂，再放余响
[血腥尺度] 用{火花/气浪/墨点飞溅}代替血
```

**代表例**【原文摘录】YouMind「水墨风格武侠视频提示词」（作者 [Zidan 子丹](https://x.com/liluocheng13/status/2106931613427028260)）：
> “[0–3s] 镜头：从刀光特写快速推进……切入斗笠剪影。视觉：水墨刀光特写，粒子火花向外迸发；斗笠剪影从翻涌的墨云中浮现。特效：运动模糊，水墨笔触拖尾，粒子效果。”

**要点**：这条例子每段都按“镜头 / 视觉 / 特效”三栏写，结构清楚。但原文写了“180°/s”“270°/s”这类角速度，模型大概率不会精确执行，当成“快速旋转”理解就行（见第 6 章）。打斗写**连招链**（直拳 → 勾拳 → 低扫，对方格挡 → 滑步 → 反击），写 epic fight 只会得到“互相挥空”（LearnPrompt combat）。

#### B3. 小说 / 漫画 / 分镜图 → 漫剧

**三种做法**【整理/改写】：
1. **参考视频画风 + 小说原文**（最省事）：`根据下面的小说剧情生成动漫，画风和动作打斗表现严格对齐 @视频1 的风格。{小说段落}`。

3. **线稿分镜图 + 逐镜文字**（官方 2.5 推荐）：素材绑定 → 故事梗概 → 按分镜逐镜写全，至少补齐分镜图里没有的信息。多宫格最好少于 15 格；需要严格按图生成时，改用关键帧参考：“以图片 1 至图片 7 的顺序作为关键帧”。

**代表例 2**【原文摘录】官方 2.5 线稿分镜案例（节选）：

#### B4. 2D 日漫 / 风格化画风锁

## 5. 人物一致性与多段拼接

### 5.1 一致性三层【整理/改写】

| 层 | 做法 | 来源 |
|---|---|---|
| **素材层** | 人脸单独一张大头照（无表情最好）+ 全身照；2.0 不用三视图；重要素材放在提示词靠前的位置；总素材 4–5 个 | 官方 2.0 |
| **文字层** | 用 2–3 个静态特征定义主体标签，并全程沿用；写继承清单 + 不继承清单；转头、遮挡、快速运动时重申同一张脸 | 官方、LearnPrompt |
| **画面层** | 特写镜头复述“与镜 N 同一张脸”；非主体人物复述方位词；站位里写了的人要出镜 | 漫剧老李 |

### 5.2 多段拼接（超过单段上限时）

1. **先决定是延长还是拼接**（官方）：同一场景的文戏（长对话、情绪递进）用**视频延长**；剧情转折、追逐、打斗、蒙太奇用**分段拼接**。
2. **段数尽量少**，按总时长 ÷ 12–15 秒估算（漫剧老李）。火宝短剧的经验值：剧本字数 ÷ 500 字 / 分钟 ≈ 成片时长，台词按 4.5 字 / 秒，再加 2 秒表演余量（工具内部规则，方法摘要）。
3. **每段末尾写【接续状态】**，写成能直接开拍的画面：
   【原文摘录】漫剧老李：
   > “✅ 正确：`【接续状态】：女主立于窗下侧身45°朝左，信件半展于右手，指尖停顿在纸缘；母亲在门口背身垂手——下段自该姿态起手。`
   > ❌ 错误（套话）：`【接续状态】：角色动作与空间位置严格继承`”
4. **段缝换机位**：上一段末镜是中景平视，下一段首镜至少换景别或视角中的一个；文戏慢段可以插 1–2 秒空镜过渡（情绪空镜 / 声音先入的音效桥 / 时空转场），每集不超过 3 处（漫剧老李 segment-splicing【社区经验】）。
5. **尾帧接力**：
   - 2.5 首尾帧模式：上一段尾帧图直接当下一段的 `first_frame`。官方 2.5 说明，用参数 role 设首尾帧会锁定宽高比；在 prompt 里写“图片 1 为首帧”不会锁定。
   - Emily2040：保存实际生成的最后一帧作为下一段的首帧锚点；**按实际观察到的末态写下一段**，不要按计划中的末态；已经发生的动作标记“已完成”，未来的动作不要提前写进来。
   - 漫剧老李提醒：不要把参考图直接当首帧（动作会僵、构图会复刻）；只用上一段尾帧截图硬拼也会跳切，要配合【接续状态】文字。
6. **接缝修补**（官方 2.0）：剪辑时前一段末尾删 6 帧、后一段开头删 1 帧；续写尽量在转场切镜的时刻结束。多次延长会让画质劣化：先把原视频转成白模再续写，或者控制续写次数。
7. **跨段音色**：同一角色在两个以上独立生成的镜头里说话时，先绑定一个稳定音色（2.5 用参考音频；waoowaoo 方法摘要）。音色跑偏时，在提示词里补音色描述，例如官方例句：“使用@音频1低厚温润带细碎颗粒感中年男声的音色说”。

### 5.3 负载估算（单段塞多少内容）【社区经验】

Emily2040 的“负载点”启发式（作者自己标注为未经测量的经验值）：每个镜头算 1 拍；镜内运镜 +0.5；每 12 个汉字台词 +1；多一个有动作的主要人物 +1；身体或道具接触 +1；换场景 +2；音效卡点 +0.5；反应镜头 / 插入镜头只算 0.5 拍。
**每负载点秒数 S = 时长 ÷（拍数 + 负载）**：S ≥ 3 宽松；2–3 紧（台词和接触有风险）；< 2 建议拆成两条生成。官方 2.0 示例（15 秒 3 镜、每镜一个运镜）S ≈ 3.3。

## 6. 常见坑

### 6.1 通用坑（各家去重）

| 坑 | 为什么 | 改法 | 来源 |
|---|---|---|---|
| 在 2.0 上写 `0-3秒` | 官方：2.0 不响应时间戳，强行限时可能异常 | 改成镜头 1/2/3 | 官方 2.0 / 2.5 |
| 毫米、像素、小数秒、角速度（“≤2mm”“1px”“9.2s”“270°/s”） | 纯文生视频时间精度约 0.5 秒，更细的数字只是噪音；模型画不出“2mm” | 改成相对幅度：“极轻微”“一拍”“快速旋转” | LearnPrompt【社区经验】 |
| 用时间戳控制频次（“一秒摇头 3 次”“睫毛 1 次/秒 颤 3 次”） | 官方 2.5 明确不建议 | 写“睫毛轻颤几下” | 官方 2.5 |
| 时间轴不连续或总和不等于时长 | 模型会自己补或拉长 | 首尾相接，总和 = 时长 | 官方 2.5、LearnPrompt |
| 一段两个动作 / 一镜多种运镜 | 时间被平分，两个都做一半；画面不稳 | 一段一个动作、一种运镜 | 官方、LearnPrompt |
| 只上传图不写用途 | 模型把它当风格图 | 每个 @ 都写清用途 | 官方、dexhunter |
| 用三视图做人物参考（2.0） | 被认成多个主体，出现双胞胎 | 大头照 + 全身照 | 官方 2.0 |
| 把完整剧本当提示词 | 内容冗余，导致理解混乱和双胞胎 | 精简到这一段要发生的事 | 官方 2.0 |
| 竖屏自带字幕 | 竖屏生成字幕的概率明显更高 | 写“保持无字幕”；能接受的话横屏生成再裁切 | 官方 2.0 |
| 手持 DV 和 4K 电影级打光写在一起 | 两套光线逻辑打架，出来是塑料感 | 二选一 | LearnPrompt |
| 正向指令写进【禁止项】 | 既不被当成禁令，也不被当成执行指令 | 正向要求放回镜头行 | 漫剧老李【社区经验】 |
| “这只手与她的脸同框” | 并列主体句式可能生成两张脸 | “她的一只手搭在…”（部位写成从属） | 漫剧老李【社区经验】 |
| 比喻 / 成语（“脸沉下来”“津津有味”） | 可能被直接画出来 | 用描述性句子 | 官方 2.5、Emily2040 |
| 结尾写淡出 | 真会淡出，浪费最后两秒 | 写硬切黑场或定格 | LearnPrompt |
| 群演“不许动” | 像一屋子人体模特 | 给群演一个持续的小动作 | Emily2040 |
| 台词太长 / 多人同拍说话 | 口型失步 | 一拍一人一句短台词 | LearnPrompt、Emily2040 |
| 意外动作写成结果（衣角被门夹住、滑倒） | 角色会像故意做出来的 | 写有意动作，或把结果放在画外 | Emily2040 |
| 漫剧没写风格约束 | 参考图偏写实时会漂成真人 | “2D 日漫风格”“保持 3D 国漫 CG 风格”+ 排除清单 | 官方、LearnPrompt |

### 6.2 用户示例②（Seedance 2.0 情绪表达）自查清单【整理/改写】

这条提示词的结构很专业（视线落点、情绪曲线、负面词都写了），但有不少**内部冲突**。模型遇到冲突只能二选一，抽卡失败率会上升：

| # | 冲突 / 问题 | 原文位置 | 建议 |
|---|---|---|---|
| 1 | **风吹发丝凌乱 vs 发丝整齐顺滑** | 全局：“风吹动发丝，发丝凌乱美，动态” vs 人物锚点：“黑色长发整齐顺滑” | 选一个。要克制的特写，就删掉“风吹 / 凌乱 / 动态” |
| 2 | **固定机位零位移 vs 动态、独特视角** | “固定机位 50mm 定焦近景，镜头零移位” vs “动态，独特视角” | 删掉“动态，独特视角” |
| 3 | **冷调侧逆光 1px 金边 vs 耀眼大阳光、斑驳树影** | 同一段全局里两种光 | 只留一种光源 |
| 4 | **背景全幅虚化 vs 斑驳树影** | 同上 | 树影只作为背景光斑，或者删掉 |
| 5 | **0.1 秒瞬变、没有慢过渡 vs 笑肌 2 秒内极慢抬升** | 全局 vs 0-2s | 全局规则别和分镜打架；删掉全局那句 |
| 6 | **面部位移 ≤2mm vs 露出全部 6 颗下齿笑、快速向左后抬头** | 全局 vs 0-2s | 去掉 mm 数字，写“幅度很小的笑” |
| 7 | **眼白面积从始至终一致 vs 露出的眼白缩小 1/3** | 2-5s vs 7-11.5s | 删掉“始终一致” |
| 8 | **全程禁止眼泪（重复 8 次） vs 13-15s 眼眶积满泪光、下一秒就要落泪** | 全局和各段 vs 结尾 | 改成一句正向描述：“泪水在眼眶里打转但没有落下”（官方原句）；去掉反复的“眼睛无泪”（漫剧老李认为反复出现“泪”这个词根反而可能招来眼泪【社区经验】） |
| 9 | **负面“眼部全范围泛红” vs 13-15s“眼周全是淡淡的薄红”** | 负面 vs 结尾 | 负面改成“眼白大面积充血” |
| 10 | **在 2.0 上写秒和亚秒（9.2s、12.3s、0.3 秒、0.5s）** | 全段 | 2.0 改写成镜头 1–6；或者换 Seedance 2.5 并改成整数秒 |
| 11 | **频次控制**（“1 次/秒 颤 3 次”） | 7-11.5s | 官方 2.5 不建议；写“睫毛轻颤几下” |
| 12 | **超细微的不可见量**（鼻孔扩张 0.2mm、围巾晃动不超过 2 像素、虹膜上沿盖住 35%） | 11.5-13s | 改成可见的动作：“轻轻叹了口气，肩膀落下” |
| 13 | 15 秒里 6 段情绪 + 大量微动作 | 全段 | 负载太高；建议 3–4 个情绪节拍，或拆成两条 |
| 14 | “脚本专业解读”这类说明文字 | 末尾 | 只给人看，不要粘进投喂的提示词 |

> 说明：任务描述里提到“示例②同时禁止并列出了风吹发丝”。OCR 整理稿里**没有找到**明确禁止“风吹发丝”的句子（截图开头可能有缺失），实际存在的冲突是第 1 条（风吹凌乱 vs 整齐顺滑）。

### 6.3 用户示例①（Seedance 2.5 千禧年 DV）检查要点【整理/改写】

（手边没有该提示词全文，只按结构给检查点。）
- 30 秒在 2.5 的单段上限内；按秒分镜在 2.5 上可行，用**整数秒、首尾相接、总和 30**。
- 「摄像机与视觉风格」里别出现 4K、电影级打光、浅景深奶油虚化这类和 DV 冲突的词。
- 「严格连贯性要求」最好拆成**继承清单 + 不继承清单 + 道具去向**；负面词单独放在最后。
- 「音频」写明“无背景音乐、无旁白、无字幕”，再加上 DV 麦克风底噪。
