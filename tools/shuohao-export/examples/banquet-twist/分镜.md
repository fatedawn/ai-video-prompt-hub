# 示例分镜：宴会厅反转（短剧冷开场）

> 本仓库自写示范，用于演示：`videogen plan` → `validate` → `shuohao-export`（H3 / Seedance）。
> 角色名仅出现在「角色定义」行；镜头正文用动作与称呼，便于通过 `prompt-no-names` 门（演示包里的 shots.json 仍保留人名以便对照门的失败样例）。

```text
竖屏9:16，国产爽剧质感，宴会厅水晶吊灯暖光，高饱和；保持无字幕。
将@图片1中穿黑色礼服、红唇的女人定义为角色A，@图片2中穿白裙的女人定义为角色B。角色A站在画面右侧，角色B站在画面左侧，宾客围成半圈；全程左B右A，不越轴。
镜头1：中景固定。角色B打翻桌边的花瓶，坐在地上抬手指向对面，眼眶泛红，带着哭腔说：{姐姐，你怎么能推我}。宾客转头看向右侧。
镜头2：切到角色A近景，微仰拍。角色A嘴角一侧上提，冷笑，把一份文件甩到对面面前，冷声说：{戏还没演完吗}。
镜头3：切到文件特写。纸上只有两个大字“鉴定”和一枚红色印章，不要密集小字。
镜头4：切到角色B近景。她的哭声停住，嘴唇微张，愣住一拍，身体后缩。
<花瓶碎裂声> <宾客低声惊呼>；人物面部稳定不变形，礼服不变，同一画面中每个人物只出现一次。
```
